研究截止与访问日：2026-10-18。范围：公开网站、节目说明、本人教学、媒体报道、社区讨论与第三方代码；未付费、未联系本人或税务机关、未运行新回测。本文是方法与证据研究，不构成投资建议。完整来源、日期、可支持范围与缺口见同目录 `source-ledger.md`。来源条目数不是独立核验次数；覆盖矩阵见账本开头。

## 1. 核心判断

1. 最值得研究的是“高动量股票 + 紧风险入口 + 极不对称收益分布”的完整执行流程，而非一个万能突破指标。官方教学提供规则骨架，但大量选股、市场状态与执行判断没有唯一机械定义。[S01–S04](source-ledger.md#s01)
2. 其生涯与成绩有多层证据：本人历史陈述、书作者明确称取得其记录、具名访谈、独立媒体交易事件报道、媒体收入榜转引、匿名税务抄录。它们不能合并成“完整独立审计交易记录”。本轮没有取得审计意见、全账户现金流调整净值、完整逐笔成交或比赛主办方证明。[S02–S03](source-ledger.md#s02)、[S06](source-ledger.md#s06)、[S09–S15](source-ledger.md#s09)、[S37–S38](source-ledger.md#s37)
3. 2021材料不能当作2026现况。2026书评谈到2021峰值后的巨额回撤；2024/2025社区税务帖子也讨论后续亏损，但数字的口径与独立性不足。官网仍展示早年的连续盈利叙事，需加历史标签。[S02–S03](source-ledger.md#s02)、[S13–S16](source-ledger.md#s13)
4. 第三方实现明显会改造方法：把盘中开盘区间改成日线收盘突破、把当时日低止损改成整个底部低点、加入自行设定的量能和评分阈值。无论正负回测，首先检验的是实现者的模型，不是本人完整策略。[S23–S28](source-ledger.md#s23)

### 为什么不同金额不能直接对账

以下为研究方法判断：
- 账户权益、已实现资本利得、税后财富和累计收入是四个不同量
- 税务期间不一定与峰值至谷值回撤期间相同；已实现税务盈亏不包含所有未实现波动
- 现金追加、提现、税款、不同账户及货币换算都会影响增长率
- 将逐年税务金额相加当作当年初本金，再算“收益率”，并不成立
- 新闻称“收入最多者”不能自动写成“缴税最多者”；论坛中已实际出现将收入误读为税额的例子[S19](source-ledger.md#s19)
- 书作者看过账单即使得到确认，也不自动等价于会计师出具全账户审计报告

因此本档案既不声称“收益虚假”，也不声称“已经审计证实”。现有证据支持其有公开、长期的交易实践及高额收入线索；不足以复原可投资的完整绩效序列。未查得本人比赛冠军的可靠主办方来源，不能把他受访、被冠军引用或拥有追随者改写成他夺冠。

## 4. 三种原始设置：精简规则卡

下列为2021年1月8日、页面同时标示4月28日的官方指南摘要，属于本人教学规范，不代表全部真实成交。[S01](source-ledger.md#s01)

| 设置 | 候选与触发 | 风险与退出 |
|---|---|---|
| Breakout | 近1/3/6月强势股；此前大涨后，抬高低点、收窄整理约2周至2月；突破开盘区间高点 | 当时日低止损，距离不超过ADR/ATR；3–5天减1/3至1/2，余仓10/20日线跟踪 |
| Episodic Pivot | 重大意外催化、约10%以上高开与异常量，优先此前数月未涨；开盘区间高点入场 | 日低止损；均线接过止损；文中同时存在较快与较慢均线退出建议 |
| Parabolic short | 大幅加速、连续多日上涨；等开盘区间低点破位、首次转弱或VWAP反抽失败 | 日高或VWAP重新站回止损；关注10/20日线回归区；禁止仅凭“涨太多”提前猜顶 |

术语：ORH/ORL=开盘区间高/低；ADR%=平均日内高低幅度；ATR=含跳空的真实波幅均值；二者不能在代码中不加单位转换地互换。官方也提到极端下跌后的反向parabolic long，但它不是普通趋势突破。[S01](source-ledger.md#s01)、[S03](source-ledger.md#s03)

## 5. EP进阶：2021年11月版本与原文差别

11月原文将异常成交量放在首位：理想情况开盘约15–20分钟已达到通常整日量；1分钟高点可先买，5分钟确认可加，亦可等更晚入口。止损距离写为通常1倍、最多1.5倍ADR/ATR；这与早期突破规则的上限必须按设置和日期区分。EP最稀少，集中于每季财报窗口。作者同时承认AFRM两次EP均被止损后股票继续上涨，并因容量放弃部分不够流动的候选。[S04](source-ledger.md#s04)

研究解释：EP的“事件”不是新闻正负打分。需要同时检验市场是否被信息真正意外、价格是否接受更高估值、买盘能否持续。更高增长率不能自动替代价格确认；反过来，没有盈利的小公司也不能因EPS缺失就被机械排除。这里是结构解释，不是提出新的已验证盈利条件。

## 6. 风险、仓位、频率、容量与盈亏分布

官网FAQ给出的常见风险为单笔账户的0.3–0.5%、少有超过1%；仓位通常约10–15%，2019胜率自报25%。ADR使用20日高低比平均；工具分为TC2000图表、Sterling执行，并提到IB与Centerpoint及较好的借券能力。FAQ偏好的止损是市价止损，而非止损限价。[S03](source-ledger.md#s03)

另一个2021教学页面的风险区间更宽（0.25–1%）、典型持仓10–20%，单一股票隔夜仓位上限30%；这是同一作者不同说明中的区间，不应强行归一成精确固定配比。[S01](source-ledger.md#s01)

同期访谈笔记给出2020胜率35%、流动性筛选门槛从约2000万美元提高至1.5亿美元日均成交额，并记录重复入场、过度交易与过早出售的自我批评。它没有给出可核验的平均盈亏比或统一年度交易笔数。[S07](source-ledger.md#s07)

### 研究者的数学与执行说明

设账户权益E、计划风险比例r、买价P、止损S，则基本股数上限为 floor(E×r/(P−S))；还应分别受名义仓位与成交容量限制。这只是风险计算，不证明有正期望。

若平均亏损为1R、胜率为p，忽略成本时平均盈利须高于(1−p)/p才收支平衡：25%胜率要求平均盈利超过3R。将文章展示的10R/20R大赢家当作“平均盈利”是常见错误。部分止盈会改变整个头寸的实际R倍数；剩余小仓位上涨20R不等于整笔赚20R。

仓位百分比也不等于风险百分比。用20%仓位、5%价格止损，计划风险约1%账户；但是隔夜跳空、停牌和借券回补可以突破计划值。多个同板块仓位一起失效时，单笔限额不保证组合损失限额。

交易频率应依市场有无合格形态，不能反向设定“每天必须交易几次”。公开证据未提供经核验的每年笔数；EP季节性与breakout高失败率不等于可给出稳定月交易量。

扩容问题具有方向性：账户变大后，要在高ADR与高美元成交额之间取舍。低流通盘大涨幅不一定容纳大资金；盘口冲击会使纸面紧止损变成更大的实际亏损。第三方的小账户扫描器无需机械复制他大账户的美元量门槛。

## 7. 市场环境与策略演化的边界

2020年末本人在推文索引中将当年机会与1999年比较；FAQ也承认泡沫环境对当时成绩有利。[S03](source-ledger.md#s03)、[S05](source-ledger.md#s05) 这比“任何市场、任何时间同样有效”更符合原始材料。

2026书评称其2022年未遵守市场过滤，累积亏损；但本轮只核验到书评，不以此重建某条指数均线过滤器的全部历史规则。[S15](source-ledger.md#s15) 2025社区帖子声称他“breakout不再有效、转向EP”，评论却争论视频其实来自2022熊市。[S31](source-ledger.md#s31) 缺少明确视频日期与原话上下文时，不把它升级为永久策略转型。

需要区分三件事：
1. 某环境中候选数量不足
2. 候选仍多但突破后延续率下降
3. 交易者执行偏离、仓位过大或生活状态变化

它们对改进措施的含义不同。把所有亏损解释为“没有纪律”，会让方法不可证伪；把所有亏损解释为“策略死亡”，也忽略执行与样本噪声。

## 10. 第三方证据和批评：谁真正增加了新信息

### 相对独立、但仍有边界

WSJ具体失误事件比一般成功故事更有核验价值；但可读预览不包含所有金额和账单，不跨越付费墙补全。[S09](source-ledger.md#s09) 媒体收入名单比匿名夸赞强，但当前找到的是转引/镜像，尚未核验Expressen底稿。[S10–S11](source-ledger.md#s10)

2026出版社页确认《Market Wizards: The Next Generation》出版与“保安出身、5千变逾1亿”人物简介，但公开简介未具名；明确第一章对应Qullamaggie来自书评，Schwager本人另一采访也直接谈到他的入选与记录。两者不能合并后把书中每个数字当作本轮已读原文。[S14–S15](source-ledger.md#s14)、[S37–S38](source-ledger.md#s37)

### 重复自述与宣传

同一CWT采访经Maoxian、Substack、瑞典交易网站重述，不是三份独立收益证据。[S07–S08](source-ledger.md#s07)、[S22](source-ledger.md#s22) 网站“不卖课程”可解释激励结构，但不能证明账户真实或风险调整后的优越性。2022关联业务节目还提醒研究者，不应将早年“不出售服务”绝对化为一生没有商业角色。[S21](source-ledger.md#s21)

### Reddit的适当用途

匿名讨论可用于发现待验证问题：原始税单在哪里、2022亏损口径、2024逆风或执行变化、收益是否集中于2020–2021。不能用票数、游艇照片或“他免费教，所以肯定真实”替代财务证据。[S12–S13](source-ledger.md#s12)、[S16](source-ledger.md#s16)、[S30](source-ledger.md#s30)

追随者收益帖同时有成功、持平与亏损故事；没有完整参与者分母、统一风险与离场者样本，不能估计学习成功率。[S32](source-ledger.md#s32) 这也意味着“某个学生成功”最多说明影响路径，不能单独验证可普遍复制。

## 12. 可程序化部分与必须预注册的主观定义

以下是本研究建议的验证规范，不是声称Qullamaggie实际使用这些精确实现。

| 环节 | 可直接量化 | 研究者必须另外明确 |
|---|---|---|
| 强势筛选 | 1/3/6月收益分位数、ADR、美元成交额 | 股票池历史成员、复权、退市与新股、盘前数据质量 |
| 整理结构 | 高低范围、回撤、波动收缩、均线斜率 | “orderly/tight/linear”何种阈值，是否视觉挑选 |
| EP | 跳空、分时相对量、财报时间 | 意外程度、指引变化、行业催化、无分析师覆盖处理 |
| 入口 | 当时可知ORH/ORL | 1/5/60分钟选择、交易时段、开盘首小时特殊bar定义 |
| 止损 | 入场时已知日低、风险距离 | 不能偷看收盘后最终日低；同bar进出顺序和停牌处理 |
| 加仓/重入 | 各笔订单及累计R | 是新交易还是原交易追加，失败后最多重试次数 |
| 退出 | 部分止盈、均线收盘信号 | 信号收盘价成交还是次日开盘；分红、拆股、跳空 |
| 组合 | 单笔风险、总风险、流动性上限 | 相关行业拥挤、同时触发优先级、不可借券与回补 |
| 市场状态 | 指数/市场宽度/近期策略表现 | 具体过滤规则应在样本外前冻结，不能见亏损后改规则 |

尤其不要在日线回测中用“最终日低”决定早盘股数，又假设早盘已经按该股数成交；这会让未来信息进入仓位。若无法获得分时数据，应明确标成日线代理策略。

## 13. 主要失效路径与反证设计

- 趋势中断：大量假突破使小亏累积；测试不同市场阶段，而不是只挑2020–2021
- 尾部利润依赖：少数大赢家贡献大部分收益；检查去除最优交易后的稳健性，但不要把趋势策略尾部依赖本身误判为无效
- 主观挑图：仅研究后来涨最大的股票会漏掉外观相似的失败者；建立当日全部候选及拒绝理由
- 紧止损幻觉：更紧不必然更好，可能提高重复止损与摩擦成本；比较真实成交后的R分布
- 极端空头风险：借券费、召回、停牌、强制回补与无法及时买回；没有历史可借券数据就不能承诺可执行
- EP事件数据泄漏：使用后来修订的财报/分析师预期会把未来信息带入；保存公告当时可见版本
- 容量衰减：总收益漂亮但下单规模超过可承受成交量；必须做容量分层而非统一滑点
- 执行偏离：同样图形在不同交易者手中可能表现不同；应记录规则内与规则外订单，而非一概归咎心理

这些是针对原法结构与上述证据缺口的研究推导，尚未经过本轮新回测验证。

## 14. 未决问题与下一轮最有价值的材料

1. 合法取得2026书章原文或出版社授权节选，核对账单核验方法、净值口径、2022回撤与2024表现；不能以AI译文或疑似全文转载代替
2. 找到具名收入榜原始报道及其税务定义；本轮不联系税务机关、不付费购买个人税务信息
3. 对官方视频建立逐段可核验字幕索引；当前只保留可证链接与作者提供的时间定位
4. 若未来评估可复制性，应选择一个日期版本、一个设置与一个股票池，先冻结规范，再做数据和成本审查；不把所有变体拼成回看最优规则
5. 取得全账户现金流、日度权益和成交数据之前，不制作“审计收益曲线”、Sharpe、真实最大回撤或确切年交易量

## 15. 收集结论

Qullamaggie的价值在于公开展示了一套对“低胜率、少数大赢家、严控单次风险”高度一致的方法思路，并且留下真实错误与规则演化的研究线索。研究价值不等于收益承诺；最应避免的两个极端，是把传奇账户增长当作可直接复制的算法，或者拿一个改造后的机械回测失败就宣布本人长期交易全无优势。下一步应该先完成证据对账与定义冻结，而不是继续堆叠未经核验的成功故事。
