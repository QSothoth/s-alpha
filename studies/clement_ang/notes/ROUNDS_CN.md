# Clement Ang 各轮结果

全部是样本内（美股研究面板 2024-01-02 → 2026-10-16）。每轮的预登记在 `PREREG_R*.md`，原始数字在 `reports/r*.json`，记分板 `SCOREBOARD_CN.md`，否定登记表 `NEGATIONS_CN.md`。所有轮次用收盘买、当日低点止损（Flanders 研究的 5 分钟复核）。

## R1 形态（2026-10-18）

五个候选（加回踩、加 EP、只做回踩、宽筛 2000 万）都没跑赢同池随机入场中位数，参照 D0c（初版精选 + 收盘买）也没跑赢：全段 −2.0%（2024 +2.7% / 2025 −4.2% / 2026 −0.3%），100 次安慰剂中位 +4.1%。D0c 一年 178 笔、胜率 20%、赢 +18% / 亏 −3.9%、赢单拿 23 天——离他（一年 800–1300 笔、胜率 30%、+5.4% / −2.1%、赢单约 3 天）很远。

基线（D0c）的三层对照（`three_r1_D0c.json`）：他 21 笔有日期多头，他的票 + 我们的执行平均 +5.5R、中位 +1.75R、胜率 63%；我们的系统一笔也没买到他的。逐笔诊断（`diagnose_r1_D0c.json`）：17 笔没信号（都在池里，卡在精选），3 笔满仓，1 笔有信号但收盘没站上触发价（没生成入场）。**差距在选股，执行不是问题。**

## R2 离场与容量（2026-10-18）

带入 **K2：他的离场（2R 卖 1/3 并保本、离 50 日线 8 ATR 再卖 1/3、余仓跌破 10 EMA）+ 同时 20 只、每天 3 笔**：全段 +1.6%（+5.4% / −4.5% / +0.9%），100 次安慰剂中位 −5.6%、排位 0.70；行为差距 1.29 → 0.81（胜率 32%、赢 +8.2% / 亏 −3.9%、赢单 11 天 / 亏单 2.6 天、一年 302 笔）。K5（K2 + 回踩 + 指数在 20 EMA 上方）全段 +19.7%（+14% / +8% / −3%）收益最高、也跑赢安慰剂，但行为差距 0.84 略大，按预登记目标没选；K4（再加 EP）没跑赢安慰剂。

他的离场让持有期从 23 天降到 11 天，但离他的 3 天还远；选股仍只命中选择段 4 / 12、验证段 0 / 9。

## R3 精选里的研究者取值（2026-10-18）

带入 **F1 精选离 52 周高放宽到 25%（Minervini 趋势模板的值）**：全段 +57%（2024 +12% / 2025 +34% / 2026 +5%），100 次安慰剂中位 −5%、排位 0.97；命中选择段 4 → 5，验证段仍 0 / 9；实际买到 1 笔。F3（再放宽 5 日振幅到 3 ADR）+43%、排位 0.98，验证段命中 3，但选择段命中与 F1 并列、收益较低，按目标没选。F4、F5（加回踩）命中翻倍（8 / 6）却只买到 1–2 笔；F2（只放宽振幅）没跑赢安慰剂。

## R4 形态组合与排序（2026-10-18）

五个候选都被“每天信号中位数 ≤ 30”挡下（回踩每天中位 58 个信号），沿用 R3。其中 G2（回踩 + 每天 5 笔）买到他 2 笔、全段 +26%、跑赢安慰剂，只是宽度不合格；G1、G4 没跑赢安慰剂。宽度说明我们的回踩比他看的范围宽得多，R5 把回踩限定在精选名单。

## R5 回踩只做精选名单上的股票（2026-10-18）

五个候选都没多买到他的票（都是 1 笔），沿用 R4（即 R3 的 F1）。回踩限定在精选名单后宽度合格了，验证段命中从 0 升到 4–5 笔，H2（再要求 RS ≥ 80）全段 +33%、排位 0.92；但实际买到的仍只有 PLTR 一笔。他的票有信号的那天常排在第 4–10 位。

## R6 当天候选的排序（2026-10-18）

带入 **I3：当天候选按前 20 日平均成交额从大到小 + 精选名单内的回踩 + 每天 5 笔**：全段 +117%（2024 +26% / 2025 +69% / 2026 +2%），100 次安慰剂中位 +6%、排位 1.00；买到他 3 笔（PLTR、NFLX、NBIS），原来 1 笔；命中选择段 5 / 12、验证段 5 / 9；一年 582 笔、胜率 34%、赢 +10% / 亏 −4.2%、赢单 11.6 天 / 亏单 2.7 天。五个候选都跑赢了安慰剂，成交额排序本身（I1）已让收益和买到的笔数都上升——与他“最大的赢家是流动性好的”一致。

仍差他的：持有期（他赢单约 3 天）、2024 年收益（+26% 对 +79%）、2025 年（+69% 对 +140%）。

## R7 回踩的收盘确认与每日名额（2026-10-18）

按预登记目标（实际买到最多）带入 **J4：J3 + EP**，买到他 6 笔（R6 是 3 笔），但全段从 +117% 降到 +73%（2024 +10% / 2025 +20% / 2026 +31%），100 次安慰剂排位 0.91。**这是行为更像、收益退步的取舍**：J3（每天 8 笔 + 回踩盘中越过前高即按收盘买，不加 EP）买到 5 笔、全段 +114%（+36% / +19% / +33%）；R6 参照 +117%。回踩不要求收盘站上（J2）让持有期从 11.6 / 2.7 天降到 9.8 / 1.9 天、平均赚亏 +8.8% / −3.4%，行为差距 0.78 → 0.62，更接近他。

从 R8 起目标改为他的分年收益，买到的笔数改作门槛，避免继续用收益换笔数。
