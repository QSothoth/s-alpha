# 事件与盘前异动：统计证据与工程可行性

研究日期：2026-10-27。结论为可行性与描述性试验，不是策略冻结。对应入口为 [opportunity-research](../../../skills/opportunity-research/SKILL.md)。

## 已得到的判断

OpenD 可以承担当前候选发现。历史盘前行情也可取得，困难主要在完整历史候选范围、当时股本与流通盘、消息公开时间及借券记录。需要把实时发现与历史验证分开实现，避免用今天榜单的股票回填历史。

解禁有实证支持，但已有论文不能决定今天应提前 1 天还是 3–5 天参与。盘前异动有价量筛选价值，直接追随或反向尚不能由本次试算确认。先保留事件机制、信息来源和价格分布，当前发现命令不给交易方向。

## 1. 解禁的实证证据

| 原始研究 | 样本与结果 | 本次阅读边界 |
|---|---|---|
| Field 与 Hanka，2001，Journal of Finance | 1,948 份锁定协议，事件附近三日异常收益约 −1.5%，平均成交量长期增加约 40%；VC 支持公司的效应更强 | 已读[期刊摘要](https://onlinelibrary.wiley.com/doi/abs/10.1111/0022-1082.00334)，未取得可读全文表格；不能据此填造提前 5 天、3 天、1 天的分别收益 |
| Röyskö，2024，Aalto 本科学位研究 | 2004–2023 年美国 IPO 的 1,914 次解禁，三日异常收益约 −0.7%；事件后第一日量峰约高于长期均量 90% | 已读[大学原始摘要](https://aaltodoc.aalto.fi/items/094e1d37-2114-4480-b6a2-54416f60a25f)，全文需校内权限；属于学位研究，不能当作与期刊论文同等验证 |

两份结果支持把解禁加入发现范围。它们的样本时期与定义不同，−1.5% 和 −0.7% 不能直接解释成同一策略收益下降了一半。异常收益也不等于做空净利润。实际卖压取决于可售量、持有人、流通盘和成交量，日期已知仍不意味着能在个人可成交的时点取得收益。

本仓库目前没有完整的解禁事件历史表，因此还没有本项目自己的解禁窗口收益或市值分组统计。下一项解禁研究应先取得带当时公开时间、分批及提前释放条款的事件表，再比较参与窗口。SKHY 涉及 ADS 股份单位和可能的跨市场转换机制，单列，不能自动并入普通美国新股样本。

## 2. 盘前异动不能只按涨跌分方向

Chan 的[作者会议论文](https://users.nber.org/~confer/2001/bfs01/chan.pdf)区分有新闻与无可识别新闻的异常波动，发现前者有后续漂移、后者有反转迹象，小公司效应较强，且卖空限制影响结果。该版本考察月度形成与后续收益，不是 09:20 到当日收盘的统计，不能直接变成盘前下单规则。

这支持在工程中保留“消息来源、首次公开时间、类别与未找到消息”字段，再分别研究财报、融资、并购、生物医药结果、行业共振与无消息异动。只按大小市值分组仍可能把真实信息与临时流动性混在一起。当前未得到可核实且能直接迁移到本机成交条件的“小盘必反转、大盘必延续”统计。

仓库[旧盘前研究总结](../../archive/README.md)另有直接经验：S22 在 34 只热门中小盘中，跳空或盘前放量筛选的当日绝对开收收益为同日准入池的 1.25 倍或 1.32 倍，但不给方向；方向规则曾落在 48%–52%，Top 3 后续排序版本扣成本后失败。这是支持异动发现、要求另验方向的已有证据，不将旧失败概括成所有事件策略无效。

## 3. EP0：已复算的历史盘前描述统计

先保存[预登记](../notes/EP0_PLAN_CN.md)，再运行 `research.py pilot`。使用本地真实行情，不取新数据、不调参。区间为 2020-02-03 至 2023-07-31，11 只固定股票、879 个交易日。信号是美东 09:00 半小时 bar 收盘相对上一交易日收盘绝对位移至少 5%，成交量必须为正。开盘参与，收盘退出；两项政策是顺向与逆向。

共得到 185 个股票日、103 个独立日期。平均数区间用整个交易日网格上的循环 5 日块重采样，同日各股一起取，2,000 次、固定种子 20261027。以下都是每个股票日的价格收益，未建立组合或验证个人开盘竞价成交。

| 条件 | 股票日／日期 | 顺向平均毛收益 | 顺向胜率 | 顺向均值 95% 区间 | 逆向平均毛收益 |
|---|---|---:|---:|---|---:|
| 合计 | 185／103 | +0.429% | 54.59% | −0.897% 至 +1.495% | −0.429% |
| 盘前上涨 | 101／70 | +0.433% | 53.47% | −0.879% 至 +1.495% | −0.433% |
| 盘前下跌 | 84／37 | +0.424% | 55.95% | −1.923% 至 +1.845% | −0.424% |

合计顺向中位数 +0.310%，10% 与 90% 分位数分别为 −4.230% 和 +5.984%。顺向同方向 SPY 的平均超额约 −0.00012%，接近零。仅做往返 20bp 成本情景时，顺向均值为 +0.229%；50bp 时为 −0.071%。这些成本没有报价与历史借券支持，不称可执行净收益。

当前不能确认简单追随有优势，也不能据逆向均值为负就否定消息或小盘条件下的反转。固定名单偏科技和大盘幸存股，无当时市值及消息分组，日期已被旧研究使用，均值区间很宽。这里只验证数据链与量出一个粗规则的分布，不选择获胜策略、不称样本外。

输入检查包含逐行流式读取、无效价格与重复输入检查、09:00 精确时间及正成交量要求。11 股共 9,669 个应有观察，仅 AVGO 一日零成交未入有效样本。另用独立保存的 K5 开收端点核对日 K，共 19,283 个端点，19,281 个在相对差 1e−5 内相同。两处差异是 AMD、AVGO 的 2021-01-04 收盘，最大约 0.0306%，均非入选股票日。这支持日 K 尺度一致，未独立验证盘前成交及可成交性。

## 4. OpenD 实测与已经实现的部分

本机 Python SDK 为 10.11.7108，OpenD 报 server_ver=1011，行情登录有效。以下结果来自本次只读调用，不用 SDK 有同名方法代替服务端实测。

| 接口 | 实测结果 | 工程用途和边界 |
|---|---|---|
| `get_us_pre_market_rank` | 上下两侧调用成功，总范围返回 18,194，单侧取 10 条 | [官方定义](https://openapi.futunn.com/futu-api-doc/quote/get-us-pre-market-rank.html)有价格、涨跌幅、盘前量和成交额；没有指定历史日期，不能回放当年榜单；总数不是所有股票都有有效盘前成交 |
| `get_market_snapshot` | 成功取得市值、流通股、盘前字段和买卖价 | 补分组与报价质量；盘前涨跌的参考要核对 `last_price`，不能无条件拿上一常规日的 `prev_close_price` 重算；[字段说明](https://openapi.futunn.com/futu-api-doc/quote/get-market-snapshot.html) |
| `get_top_movers_rank` | 美股调用成功，返回盘中排行 | 可用于后续盘中发现；不能在盘前拿留存的常规时段排行当此刻异动；[官方说明](https://openapi.futunn.com/futu-api-doc/hk/quote/get-top-movers-rank.html) |
| `get_search_news` | 搜索 SKHY 成功，返回标题、发布时间、来源和 URL | 资讯候选入口；没有历史截止参数，当前最新若干条不能代表历史时点完整新闻 |
| `get_technical_unusual` | AAPL 返回成功，近 7 日 MA、MACD、KDJ 等文字提示 | 技术标签，不是可直接评测的瞬时异常成交事件流；本次只核到 SDK 文档及真实响应，未找到对应可访问官方网页 |
| `request_history_kline` | 预先确认 AAPL 已在已用明细，取得 2020-02-03 04:01–04:03 三根分钟线 | `extended_time=True, session=ALL` 可取盘前；[文档](https://openapi.futunn.com/futu-api-doc/quote/request-history-kline.html)提示不同年份覆盖可能不足，单次成功不替全部标的背书 |

一分钟历史试验只请求 AAPL 三根，没有扩大股票范围。按[额度官方定义](https://openapi.futunn.com/futu-api-doc/quote/get-history-kl-quota.html)，元组前两项是已用和剩余；调用前后为 `(97,203)→(96,204)`，期间有净释放，不能把全局计数变化归因于单一调用。没有调用交易接口，没有新增后台采集。

已实现一次性命令 `research.py discover`：上下两侧有限榜单 → 去重 → 快照 → 数值、参考价、日期、报价质量及市值标签 → 最多三只补新闻 → 保存带采集时间与源码 SHA 的 JSON。`direction` 固定为空，`evidence_status=UNVALIDATED`。不自动把涨幅榜变成买卖建议。

北京时间 2026-10-27 17:54 的修正版实测取得 20 个候选，只有 2 个未触发质量提示。提示包括低于 1 美元、价差至少 1%、非正股快照、市值缺失、参考价不一致、报价过旧。1% 是报价诊断线，不是已验证交易门槛；未触发提示也不等于可执行。快照更新时间不等于盘前最后一笔成交时间。

本轮命令只取上下各 10 条，未做全量阈值扫描。正式发现器需要按市值组分别分页或遍历全部合格范围，保留采集前后时间与截断信息，避免微盘极端涨幅把大盘事件挤出榜单。分页有时间漂移，需测量变化并存原始页，不能宣称原子快照。

## 5. 历史数据的实际路线

| 路线 | 能解决什么 | 尚需验证什么 |
|---|---|---|
| 本地 OpenD 冻结数据 | 已能跑 EP0；还有小时线、更多固定股分钟研究数据 | 名单范围、已使用日期及价格时标；不能代表全市场异动 |
| OpenD 历史分钟 | 对已扣额度股票逐只取盘前和常规时段，再离线生成历史候选 | 全市场会受股票额度限制，且需要当时上市与退市名单；新标的额度先按项目规则办理 |
| Alpaca 历史行情 | [官方计划](https://docs.alpaca.markets/us/docs/about-market-data-api)列 2016 年以来历史，Basic 限制最近 15 分钟，免费实时仅 IEX | 不把实时 IEX 等同全市场；当前账户能否取延迟历史 SIP 须小请求验证。本机未配置相关 API key，本次未实际取数 |
| Massive 分钟 Flat Files | [官方文档](https://massive.com/docs/flat-files/stocks/overview?assetClass=stocks&license=personal&name=stocks_advanced)覆盖 SIP 盘前、盘中和盘后，可按日期重建当时异动范围 | 下载权限与价格未实测；原始文件不复权，需公司行动与历史证券身份；按日流式解压筛选，不能全市场多年一次入内存 |
| Databento 历史分钟及报价 | 有[官方盘前榜重建例子](https://databento.com/docs/examples/equities/equities-premarket-movers?lang=python)，可先用[免费元数据估价](https://databento.com/docs/api-historical)再定小试范围 | 示例用 `XNAS.ITCH`，不是全 SIP，收益参考是盘前首价也不同于昨收。须确定交易所覆盖、昨收基准和历史证券身份，不能照抄示例即当全市场验证 |

完整历史市值与流通盘需要独立来源。[Massive 官方 FAQ](https://massive.com/knowledge-base/categories/stocks)明确当前 free float 只有最新记录，不提供历史 float。公司公告和当时股本可补总市值，但股份与 ADS 比例、信息披露滞后及多类股必须核对。报价、退市和借券覆盖也要独立检查。

截至本次检查，未在当前环境配置 Alpaca、Massive、Polygon 或 Databento 的常用 API key 变量。没有注册账户、购买数据或调用计费下载。不能用产品宣传页推定当前账户已具备权限。

## 6. 下一阶段应落到的工程形态

先用同一事件记录连接三份独立证据：发现当时的原始行情、当时公开的催化与条款、历史同类分组及其统计版本。记录包含证券身份、事件 ID、首次可知时间、采集时点、当时市值与流通盘、股票供给或消息类别、输入版本及质量标记。缺统计时输出待验证，不补模型概率。

解禁先建设公告支持的事件表，优先比较临近事件的供给压力与事后修复。盘前先重建完整历史 09:20 名单，再研究预登记的四项顺逆向与时点政策。EP0 仅 09:00，不能冒充 09:20。把 09:35 确认或成本结构改变计作新政策，避免复用旧失败机制后只改名称。

按日期流式保留前一常规收盘、截至截止时点的价量摘要，以及入场、退出所需端点。全市场历史扫描一次先取代表性日期核对覆盖与估价，再扩大；输出统计按事件机制、当时市值、流动性和消息有无划少量组。严格分清选择与未使用验证段，保留失踪、停牌、退市和无法借券的记录。

本次交付的工程边界是可运行的一次性盘前发现原型与固定 EP0 复算器。尚未实现自动解禁日历、全市场历史重建、统计匹配规则或自动盘中异动流。候选不自动晋级为可交易策略。
