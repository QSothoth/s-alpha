# EXEC8 预登记：场景剧本第二版

登记时间：2026-10-26，跑数之前（EXEC1–EXEC7 结果都已看过）。实现 `exec_eval.py playbook2`，单测 `tests/test_exec_eval.py::Playbook2Tests`。测试集、成交模型、指标与 [EXEC_TESTSET_CN](EXEC_TESTSET_CN.md) / [EXEC7](EXEC7_PREREG.md) 相同。本轮只测试，不调参数、不在本轮内二次修改；看完结果的任何改动另开一轮。

## 依据（交易员方法论）

来源均为 `studies/trader_registry/dossiers/`：

- **卖进强势，不猜顶**：Martin Luk “涨超 3 倍 ADR 卖第一批”（swing/martin_luk.md、MARTIN_VERSION_CROSSWALK.md）；Goverdhan 牛旗“首段在推进中卖 1/4 至 1/2”（active/goverdhan_gajjala.md GG4）；Qullamaggie 抛物线“禁止仅凭涨太多提前猜顶，等首次转弱”（qullamaggie/dossier.zh.md）。合起来：有利推进时不在上涨途中卖，也不等跌下来确认，**在推进出现第一根不再走高的 K 线时卖**。
- **转弱直接走，不等反弹**：Qullamaggie 用“当时日低”止损、偏好市价止损而非止损限价（S03）；Goverdhan 止损预设、前棒低点作参考、离屏硬止损（GG3）；Clement Ang 等首个 15 分钟棒再走只用于“多股连同指数跳空到支撑”的例外，并明确建议新手直接接受首损（CA1）。所以本版在“转弱时直接卖 / 等第一根反弹卖”二选一中**选直接卖**，并加“跌破当日低点即卖”。
- **不追高、回调买**：Martin 买 9/21 EMA 回调；Goverdhan “EMA Kiss and Fly”、回调棒高触发；Qullamaggie 止损距离通常不超过 1 倍 ADR，接受首损。买单在急涨后等**回到 EMA9 附近再转强**，而不是等一根红 K 就买。

## 精确判定（跑数前写定）

记号同 EXEC7：c、hi、lo 为有向正股收盘 / 高 / 低（CALL 取正、PUT 取负），m 为刚完成的分钟。场景识别与优先级沿用 EXEC7（开盘混乱 → 急涨 → 急跌 → 冲高过度 → 深跌过度 → 顺势 → 逆势 → 收复 → 失守 → 盘整）。新增：

- **当日低点**：开盘到 m−1 的有向最低价 min lo(0..m−1)；c(m) 低于它为“跌破当日低点”。
- **推进**：c(m−1) ≥ c(m−10..m−2) 的最大值（上一根是近 10 根收盘新高）。

每根 K 线依次检查，成立则下一根有成交的期权 K 线成交（同 EXEC7）：

1. 保护：买单期权可买价 ≥ 到达价 × **1.10**、卖单可卖价 ≤ 到达价 × **0.90**，立即成交。
2. 流动性差且剩余 ≤ 15 分钟：立即成交。
3. 开盘混乱（m < 5）：不成交。
4. 卖单：跌破当日低点 → 立即卖（记 `stop_low`）。
5. 场景打法：

| 场景 | 买 | 卖 |
|---|---|---|
| 急涨 | c(m−1) ≤ EMA9(m−1) + 0.25 ATR 且 c(m) > c(m−1)（回调到 EMA9 附近再转强） | c(m) ≤ c(m−1)（冲高衰竭） |
| 冲高过度 | c − VWAP ≤ 0.5 OR | c(m) ≤ c(m−1) |
| 急跌 | c(m) > c(m−1) | **立即** |
| 深跌过度 | c(m) > c(m−1) | **立即** |
| 顺势 | c(m−1) ≤ EMA9(m−1) + 0.25 ATR 且 c(m) > c(m−1) | 推进且 c(m) ≤ c(m−1)（卖进强势） |
| 收复 | 立即 | 同顺势 |
| 逆势 | c(m) > c(m−1) 且 lo(m) ≥ lo(m−1)，或 c > VWAP | **立即** |
| 失守 | 同逆势 | **立即** |
| 盘整 | c ≤ 近 10 根区间中点 | c ≥ 近 10 根区间中点 |

6. 紧迫度（同 EXEC7）：r = 剩余分钟 / 时间段总分钟，0DTE 在 14:30 之后 r 取一半。r < 0.2：立即成交，但买单处于急涨时先等 1 根（卖单不再有“急跌先等”）；0.2 ≤ r < 0.5：进入该区间后最多再等 3 根。到点按测试集口径强制成交。

## 对照与指标

对照：立即成交、到点成交、EXEC6 的 HB2（买）/ HS2（卖）、EXEC7 剧本一版。指标：平均改善、最差 5%、坏成交率（前后 5 分钟区间的不利 20%）、好成交率（卖在高位 / 买在低位，有利 20%）、超时比例；按触发成交的场景报告次数、平均改善、卖在局部低点 / 高点比例（买单为买在局部高点 / 低点）。与立即成交、与 HB2 / HS2 逐用例配对，按交易日聚类 bootstrap 95% 区间（1000 次，种子 20261026）。

## 判定（四组分别：买 / 卖 × 到收盘 / 60 分钟）

**通过**（沿用 EXEC7 四条）：坏成交率低于立即成交且配对差 95% 区间不含 0；平均改善配对差 95% 下限 ≥ −0.5%；最差 5% ≥ −20%；超时比例不高于到点成交。

另报两项目标（不改变“通过”的判定）：

- 买单“不差于 HB2”：坏成交率不高于 HB2（点估计），且与 HB2 的平均改善配对差 95% 下限 ≥ −0.5%。
- 卖单“卖得精”：卖在局部低点的比例低于立即成交、卖在局部高点的比例高于立即成交；同时报告与 HS2 的配对差。

选择段、已用过的验证段、1–4 天诊断三段并列报告，均为已见过的数据；剧本无参数可选，最终检验留给 `exec_capture.py` 新采集的数据。
