# TK7 预登记：止盈优先、不设或放宽止损（用户前提）

登记时间：2026-10-26，跑数之前（TK1–TK6 与按准确率的重算已看过）。实现 `ticket_eval.py --round TK7`。

## 用户前提与假设

- 选股和方向由用户的前置环节决定；本工具只管择时与固定止盈止损，接受低胜率，靠盈亏比。
- 用户 2026-10-26：期权场景里止损的价值可能没那么大，止盈更重要；在盘中高点附近止盈一次，就能覆盖多次交易的成本。
- 选择段诊断支持这一点：v6.6 入场后 30% 期间涨到过 +100%，持有到收盘中位数却是 −37%，大量浮盈被吐回。0DTE 的最大亏损本来就是权利金。

## 候选（入场都用 v6.6 信号；5 个，常见值）

“跟踪止盈”：浮盈到过 A 之后，回落到最高浮盈的 K 倍就卖（`trail_after_pct` / `trail_keep`）。

| 候选 | 止损 | 止盈 | 跟踪止盈 |
|---|---|---|---|
| F1 | 无 | +100% | 无 |
| F2 | 无 | +200% | 无 |
| F3 | 无 | 无 | 到过 +100% 后回落到 0.7 倍 |
| F4 | 无 | 无 | 到过 +50% 后回落到 0.6 倍 |
| F5 | 无 | +200% | 到过 +50% 后回落到 0.6 倍 |

对照：K4（−50% / +100%）、A2（−50% / +300%）、A3（−50%，到过 +100% 后回落一半）、“无止损无止盈持有到收盘缓冲”（记作 H0）。

## 评分、选择与判定（按用户前提）

- 主指标：方向准确率 60% 时的每笔期望（镜像加权，同 TK1）；同时报 55% / 65%、方向对时的胜率与盈亏比、平均亏损、≥ +200% 占比。
- 选择：40 折留一天交叉验证，每折从 {F1–F5, K4, A2, A3, H0} 中选 60% 期望最高者，拼接留出日成交。
- 判定（全部满足为“止盈优先成立”）：交叉验证 60% 期望 > 0 且利润因子 ≥ 1.2；交叉验证选中最多的候选不设止损；该候选在选择段上 60% 期望高于 K4。
- 已用过的验证段照报，不参与选择或判定。
- 这是检验用户提出的新机制，不计入 TK4–TK6 的入场层轮次上限。
