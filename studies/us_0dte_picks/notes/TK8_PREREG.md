# TK8 预登记：随盈利上抬的止盈止损（保住并放大利润）

登记时间：2026-10-26，跑数之前（TK1–TK7、EXEC1–EXEC8 结果都已看过）。实现 `ticket_eval.py --round TK8`，执行时点单测 `tests/test_ticket_eval.py::RatchetTimingTests`。数据、成交模型、标签、镜像加权同 [TK7](TK7_PREREG.md)。

## 用户要求与假设

- 用户 2026-10-26：现有止盈止损太朴素（固定一条线，或者“到过 X 后回落到 K 倍”这种单档跟踪）。人工交易时，止损线会随盈利**不断上抬**：先保本，再锁住一部分利润，涨得越多锁得越多；同时尽量让赢家跑大。
- 与 EXEC 的区别：EXEC 里“从高点回落 10% 就卖”被否定，是在**卖出时间段内比成交价**（相对立即卖），那是一笔卖单的执行质量。本轮评的是**整笔交易**：入场之后怎么管仓位，主指标是整笔每笔期望。
- 依据（`studies/trader_registry/dossiers/`）：Qullamaggie 当时日低止损、之后把止损抬到保本、余仓用均线跟踪（qullamaggie/dossier.zh.md 第 63 行）；Martin Luk 把止损抬到前一根低点（SMCI 2024-01-09），首次涨超 3 倍 ADR 先卖一小部分、余仓用 9/23 EMA 跟踪（swing/martin_luk.md ML2/ML3）；EXEC7/EXEC8 中唯一稳定有效的卖法是“卖进强势”（急涨后第一根不再走高就卖）。
- TK7 已知：去掉止损很差，−50% 初始止损保留；紧的单档跟踪（F4：+50% 后回落到 0.6 倍）提胜率、降盈亏比。本轮的阶梯在低位放得宽（+50% 才保本、+100% 才锁 +50%），越往上越紧，目的是不把小波动当离场，又不把 +200% 的赢家吐回成亏损。

## 候选（5 个；入场都用 v6.6 信号；初始止损都是 −50%；都不设固定止盈；平台收盘前 15 分钟平仓不变）

记号：g = 当前可卖价相对成本的收益，P = 持仓以来 g 的最高值（每根期权 K 线收盘后更新）。“锁线”L(P)：g ≤ L 即卖，下一根成交（与 TK7 相同）。

| 候选 | 规则 |
|---|---|
| G1 阶梯锁利 | L = −50%；P ≥ +50% → L = 0（保本）；P ≥ +100% → L = +50%；P ≥ +200% → L = +100%；P ≥ +300% → L = +200%；之后 P 每再到一个整百（+400%、+500% …），L = 该整百 − 100% |
| G2 越涨越紧 | L = −50%；P ≥ +50% → L = 0；P ≥ +100% → L = 0.5·P；P ≥ +200% → L = 0.6·P；P ≥ +300% → L = 0.7·P |
| G3 G1 + 卖进强势 | G1，另加：P ≥ +100% 时，若上一根期权 K 线的可卖价比它之前第 3 根高 ≥ 15%（急涨，EXEC7 期权急涨阈值），且本根可卖价 ≤ 上一根（第一根不再走高），卖出（记 `ticket_climax`） |
| G4 G1 + 尾盘收紧 | G1，另加：0DTE 14:30（开盘后第 300 分钟）起，若 P ≥ +50%，L = max(G1 的 L, 0.8·P)（记 `ticket_late_trail`） |
| G5 均线跟踪（Martin 式） | L = −50%；P ≥ +50% → L = 0；P ≥ +100% 后，正股按开盘起每 5 分钟合成 K 线，有向（CALL 取正、PUT 取负）5 分钟收盘低于 5 分钟收盘的 EMA9（开盘第一根为种子）时卖出（在该 5 分钟 K 线收完的那一分钟判定，记 `ticket_ema_trail`） |

对照：A2（−50% / +300%，TK7 主选）、K4（−50% / +100%）、A3（−50%，到过 +100% 后回落一半）。

## 指标

- 主指标：方向准确率 60% 时的每笔期望（镜像加权，同 TK7）；同时报 50% / 55% / 65%、成交笔胜率、盈亏比、平均亏损、≥ +200% 占比、利润因子。
- 新增“利润保留”：入场后到平仓时点之间可卖价的最高收益记为当日峰值 D。对 D ≥ +100% 的成交笔，报笔数、平均离场收益、平均 D、保留率 = 平均离场收益 / 平均 D；对 D ≥ +50% 的成交笔同样报，另报其中以亏损离场的比例（“赚过 50% 又亏着走”）。
- 压力口径（成交偏移 50% 振幅）下的 60% 期望。

## 选择与判定（跑数前写定）

- 选择：40 折留一天交叉验证，每折从 {G1–G5, A2, K4, A3} 中选 60% 期望最高者（并列看盈亏比），拼接留出日成交。
- 判定（全部满足为“上抬锁利成立”）：
  1. 交叉验证 60% 期望 > 0 且 60% 利润因子 ≥ 1.2；
  2. 交叉验证选中最多的是 G1–G5 之一；
  3. 该候选在选择段上：60% 期望高于 A2、成交笔盈亏比 ≥ 2.0、≥ +200% 占比 ≥ 4%（盈亏比优先，不允许变成高胜率小赚）。
