# EXEC6 预登记：模仿人类交易员的执行规则（避开坏成交，卖出要精）

登记时间：2026-10-26，跑数之前（EXEC1–EXEC5 结果已看过）。实现 `exec_eval.py human`。

## 目标调整（用户 2026-10-26 同意）

分钟级数据比不上高频，执行层不再追求择时收益（期望按 0），而是像一位不做高频的交易员那样**不犯错**：不追急涨、不杀急跌、避开开盘最乱的几分钟、到点必成交。用户强调：**卖的时候一定要精**。本轮因此不以平均改善为目标，而以“坏成交”是否减少、平均是否不变差来判定。

## 指标

- 坏成交率：成交所在分钟前后各 5 分钟内（事后，只用于评测）可成交价的区间里，卖单成交价落在最低 20%（卖在局部低点）、买单落在最高 20%（买在局部高点）的比例。区间为零时不计。
- 平均改善（相对到达价）、最差 5%，同前；与对照方案逐用例配对，差值按交易日聚类 bootstrap 给 95% 区间。

## 规则（覆盖在基础方案之上）

基础方案先决定“本来要在哪一根成交”，人类规则再检查这一刻：

- **开盘缓冲**：开盘后前 5 分钟（09:35 前）不成交，推迟到第一根 ≥ 09:35 的 K 线。
- **不追急涨（买）/ 不杀急跌（卖）**：本来要成交的那一根之前，最近 3 根已完成 K 线的可成交价朝不利方向（买：上涨；卖：下跌）累计超过 X，就先不成交，等第一根朝有利方向的 K 线（买：比前一根便宜；卖：比前一根贵）出现后，在下一根成交；最多等 5 分钟。
- **保护**：等待期间，买单可买价 ≥ 到达价 × 1.20、卖单可卖价 ≤ 到达价 × 0.80 时立即成交；时间段结束按测试集口径强制成交。

| 方案 | 基础 | 规则 |
|---|---|---|
| 对照 B0 / S0 | 立即成交 | 无 |
| 对照 S1 | 从高点回落 10% 卖 | 无 |
| HB1 | 立即买 | 开盘缓冲 + 不追急涨 X = 10% |
| HB2 | 立即买 | 开盘缓冲 + 不追急涨 X = 20% |
| HS1 | 立即卖 | 开盘缓冲 + 不杀急跌 X = 10% |
| HS2 | 立即卖 | 开盘缓冲 + 不杀急跌 X = 20% |
| HS3 | S1 | 开盘缓冲 + 不杀急跌 X = 10% |

## 判定（选择段，四组分别：买 / 卖 × 到收盘 / 60 分钟）

规则“成立”需同时满足（对各自的基础方案）：坏成交率下降、且配对差的 95% 区间不含 0；平均改善不变差（配对差 95% 下限 ≥ −0.5%）；最差 5% 不变差。四组里买、卖各选坏成交率下降最多的成立方案作为执行层默认。已用过的验证段与 1–4 天诊断只报告。
