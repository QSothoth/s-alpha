# 持仓只卖执行：首轮规则预登记

2026-09-30 用户明确要求“只卖出”按策略自动择时。本轮先实现一个候选 `position_pnl_v1`，不搜索参数，不读取新验证集，不声称收益改善。

假设：已有仓位没有今天的真实入场事件，用真实平均买入成本与新鲜可卖 bid 计算毛收益，可以避免把 0DTE 模型收益误当实际收益；持久记录接管后的报价峰值可避免重启重置锁盈。这是执行语义假设，不是正收益假设。

固定规则：毛亏损达到 30% 退出；毛收益达到 100% 退出；接管后观察到毛收益至少 50% 后，回落至最高毛收益的 50% 退出；原尾盘截止继续生效。阈值取常见整数，止盈和锁盈比例沿用 v3 数值但收益定义不同，因此不能继承 v3 验证或 live 资格。峰值从接管开始，历史未观测峰值不补造。仅一个候选；本轮不根据结果调阈值。

入场成本：本库保留仓位采用原买单实际／模拟成交加权价；外部持仓使用券商 average_cost，缺失则拒绝接管。不使用可能包含历史摊薄损益的 cost_price 替代，不用当前价代替成本。报价必须满足执行层新鲜度与合约身份校验，不扣未知费用，因此始终标毛收益。

本轮工程验收：禁止买入、成本证据核对、止损/止盈/锁盈触发、过时报价不改变峰值、重复与倒序报价不推进、重启峰值保留、部分卖出后只卖剩余、尾盘无报价明确等待。合成路径仅用于单元测试。

后续效果验收必须另行冻结未使用的真实持仓/买卖报价路径与费用，先分选择段和验证段并固定对照与门槛，验证只看一次。当前没有这种独立收益评测，因此本候选仅 dryrun/paper，live 显式拒绝；不在旧 v3 报告上补写结果，也不更改注册状态。
