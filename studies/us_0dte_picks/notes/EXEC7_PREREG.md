# EXEC7 预登记：场景剧本的测试

登记时间：2026-10-26，跑数之前。剧本：[EXEC_PLAYBOOK_CN](EXEC_PLAYBOOK_CN.md)（用户确认、冻结）。实现 `exec_eval.py playbook`。本轮只测试，不选参数、不改剧本。

## 实现时的精确判定（剧本文字的落地，跑数前写定）

记号：c、hi、lo 为有向正股收盘 / 高 / 低（CALL 取正、PUT 取负），m 为刚完成的分钟；“期权近 3 根涨跌”= 最近一根已成交期权 K 线的可成交价相对 3 根之前的变化。

- 急涨：c(m) − c(m−3) ≥ 2 ATR，或期权近 3 根 ≥ +15%；急跌：≤ −2 ATR 或 ≤ −15%。流动性差时只看正股。
- 收复：最近 5 根内有一根收在 VWAP 不利一侧、当前收在有利一侧；失守相反。
- 盘整：其余情形；“近 10 根区间中点”= 近 10 根有向最高与最低的平均。
- 流动性差：期权最近 10 分钟有成交的分钟 < 5。

成交条件（在第 m 根判断，成立则下一根有成交的期权 K 线成交）：

| 场景 | 买 | 卖 |
|---|---|---|
| 开盘混乱（m < 5） | 不成交 | 不成交 |
| 急涨 | c(m) < c(m−1) | c(m) ≤ c(m−1) |
| 急跌 | c(m) > c(m−1) | c(m) > c(m−1) |
| 冲高过度 | c − VWAP ≤ 0.5 OR | c(m) < c(m−1) |
| 深跌过度 | c(m) > c(m−1) | c(m) > c(m−1) |
| 顺势 | c(m−1) ≤ EMA9(m−1) + 0.25 ATR 且 c(m) > c(m−1) | c(m) < EMA9(m) |
| 逆势 | c(m) > c(m−1) 且 lo(m) ≥ lo(m−1)，或 c > VWAP | c(m) > c(m−1) |
| 收复 | 立即 | 不成交（拿着） |
| 失守 | 同逆势 | 立即 |
| 盘整 | c ≤ 近 10 根区间中点 | c ≥ 近 10 根区间中点 |

- 时间段的第一个判断点就是开始时刻那根 K 线；条件成立即等同“立即成交”。
- 保护：买单期权可买价 ≥ 到达价 × 1.20、卖单可卖价 ≤ 到达价 × 0.80，立即成交。
- 紧迫度：r = 剩余分钟 / 时间段总分钟；0DTE 在 14:30（第 300 分钟）之后 r 取一半。r < 0.2：立即成交，但买单处于急涨、卖单处于急跌时先等 1 根；0.2 ≤ r < 0.5：进入该区间后最多再等 3 根；流动性差且剩余 ≤ 15 分钟：立即成交。到点按测试集口径强制成交。

## 对照与指标

对照：立即成交；EXEC6 的 HB2（买）/ HS2（卖）。指标：平均改善、最差 5%、坏成交率（前后 5 分钟区间的不利 20%）、卖单“卖在高位”比例（有利 20%）、超时比例；按触发成交时的场景报告次数、平均改善与坏成交率；与立即成交逐用例配对，日聚类 bootstrap 95% 区间。

## 判定（四组分别：买 / 卖 × 到收盘 / 60 分钟）

剧本“通过”：坏成交率低于立即成交且配对差 95% 区间不含 0；平均改善配对差 95% 下限 ≥ −0.5%；最差 5% ≥ −20%；超时比例不高于到点成交。选择段、已用过的验证段、1–4 天诊断三段并列报告；剧本无参数可选，三段地位相同，均属已见过的数据，最终检验留给新数据。看完结果的任何改动另开一轮，并在新数据上检验。
