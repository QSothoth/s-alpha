# R30：统一版本的双 mode，组合用于持有和退出

2026-10-14，在新候选运行前冻结。用户要求改完给出择时与真实期权完整交易结果。本轮不下单，不以开发集结果证明实盘盈利。

## 基线与归因

整体基线为日内期权择时 V6.6：selective 使用已冻结 zero_dte_timing_v6.6；required 使用已冻结 open_hold_v3。补充可运行的统一版本/mode 解析，但不改旧参数、注册状态或默认策略。两者分别按原入场，包括 required 第 60 分钟的兜底；本轮所有候选逐 case 入场必须与各自基线完全相同，隔离评价卖出端，不声称入场已优化。

## 组合及三个候选

使用两根完整相邻 3m 线的方向确认。这是延续 R28 的较大周期假设，改测持仓用途，不宣称其已经是最优信号。与港股 Watch 的 W29 原始标注计数不是同一种构造。

分钟为美股开盘后完成时间，1–3 为第一块，4–6 为第二块；不重叠，不用未完成块。每块收盘相对开盘同向，在完成时位于当日 VWAP 同向一侧，EMA9/21 严格同向；第二块收盘继续推进。当前分钟也须价格/VWAP、EMA 同向，避免未完成块已反转仍延续旧确认。缺分钟清空，实例之间不共享状态。period=3 是唯一新增数值参数，官方 G10 照常扰动。

| 候选 | 动作 | 假设 |
|---|---|---|
| H | 同向组合成立时，暂缓模型翻倍止盈与无进展退出；其他风险、锁盈、尾盘规则保留 | 继续持有可能多拿趋势收益，但可能增加回吐与时间损耗 |
| X | 反向组合成立且原规则尚未退出时，发出退出 | 较长尺度反转可能更早切断亏损，但可能过早卖出 |
| HX | 同时应用 H 与 X | 检验两种作用是否互补 |

CALL 同向为强 B、反向为强 S；PUT 镜像。H 不延迟止损、保本、跟踪、浮盈回落锁盈、晚盘虚值退出或尾盘强平。X 不覆盖原规则已经触发的退出原因。已进入退出状态不撤回，不加仓、不反手、不做第二笔。组合只作研究引擎的状态，不修改实时 Watch 标记。

## 数据、评价与门槛

只使用已有 custody-0dte-v6.1 开发集，146 case / 21 日、73 对真实 CALL/PUT；09-18、SV1 和港股 2024H1 留出均不打开。开发集已反复使用，不能称作新样本外。每个候选在两个 mode 各运行官方 `python3 -m custody evaluate` 全部检查（默认随机对照、参数邻域、压力成本），只在临时注册表注册研究引擎。原门槛、评级算法不改。

联合晋级规则额外固定如下，不能仅凭某个 mode 或一侧好转命名 V6.7：

1. 两个 mode 的 G2 前缀检查通过，逐 case 入场与各自基线一致；selective 完整数不低于基线，required 全部 146 个 case 完成卖出，到期结算不算卖出；
2. 两个 mode 主口径 50% 方向平衡净均值均>0、利润因子>1，50%/60% 综合分均不低于自身基线；
3. 每个 mode 的 CALL/PUT 各自平衡净均值均>0，且各自不低于基线；各侧情景覆盖完整；
4. 两个 mode 按交易日配对重抽样 1,000 次、seed=20261014，净均值差的 95% 区间下限均>0；
5. 两个 mode 的压力成本下相对基线差值均不为负，最差一笔不恶化；selective 还必须通过正式开发段 G3–G13。required 保留其原正式评级，不冒充相同评级标准。

全部通过者按两个 mode 中较小的净收益改善排序，同分按 H/X/HX。没有通过者不注册 V6.7。即使通过，本轮最多冻结开发候选，独立验证计划另行预登记，不自动打开其他数据或切到 live。

## 展示与诊断

- 时机层：入场一致性、卖出提前/推迟/相同的数量、持有时间、退出原因；真实分钟行情重放，报告组合出现及其作用，不用事后最高价决定成交。
- 完整交易层：146 个 case 全保留，真实期权下一根成交、原滑点和费用；分 mode、CALL/PUT，报告净均值、盈亏比、利润因子、完整买卖数、收益差及不确定性。
- 输出逐笔对照 CSV，标明原/新入场、原/新卖出、退出原因、持有时长与净收益差，便于复核。没有组合或没有交易的 case 也输出。
- 用基线决策价到候选决策价的正股变化作卖点诊断，同时列真实期权净收益差；正股改善但期权不改善照实保留，不能替代期权主指标或称作纯 theta。
- 补充固定合约名排序选每个交易日第一个标的的 CALL 及 PUT 两条独立诊断路径，避免按收益选日内计划；两条路径各自每天最多一买一卖，不能合并成同时做两笔的账户。该机械上游选择不是选股能力、不是可执行的整数张资金账户曲线。
