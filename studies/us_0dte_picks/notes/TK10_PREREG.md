# TK10 预登记：信号出现后怎么买更便宜

> 编号说明：2026-10-26 应用户要求，“借鉴加密货币机器人的离场”与“信号后怎么买更便宜”两轮对调编号（原 TK10 → TK9，原 TK9 → TK10）。两份预登记的规则、候选、判定都没有改动；对调前两轮都尚未汇报任何结果。

登记时间：2026-10-26，与 TK8 同时登记，跑数之前。实现 `ticket_eval.py --round TK10`，执行时点单测 `tests/test_ticket_eval.py::EntryWaitTimingTests`。数据、成交模型同 [TK8](TK8_PREREG.md)。

## 用户要求与假设

- 用户 2026-10-26：买的时候要想办法让成本更低。
- v6.6 的入场信号多出在突破、期权正在急涨时；立即买（下一根成交）常买在局部高点。人工交易员不追急涨、等回踩（Martin 买 9/21 EMA 回调、Goverdhan 回调棒高触发、Qullamaggie 不追高）。EXEC6 的 HB2（期权 3 根内涨 ≥ 20% 时最多等 5 分钟、等第一根回落）在单笔买单上坏成交少、尾部小。
- 代价：等的时候行情可能直接走掉，到截止时间只能更贵地买；所以评的是**买入成本**和**整笔结果**两样。

## 候选（3 个；离场 = TK8 判定成立时交叉验证选中最多的候选，否则 A2；跑 TK8 之前写定）

记号：信号分钟 m0（v6.6 发出入场的那根）；b(m) = 第 m 根期权 K 线的可买价（成交模型买价）。“动手”后下一根成交，与立即买相同。

| 候选 | 规则 |
|---|---|
| J0 立即（对照） | m0 动手 |
| J1 不追急涨（HB2） | 若 m0 及之前 3 根期权 K 线可买价涨幅 ≥ 20%：从 m0 起等第一根 b(m) < b(m−1) 时动手，期间 b(m) ≥ 1.2·b(m0) 立即动手；m0 + 5 仍未动手则动手。否则 m0 动手 |
| J2 等便宜 5% | 从 m0 起，第一根 b(m) ≤ 0.95·b(m0) 时动手；m0 + 10 仍未动手则动手 |
| J3 等第一根回落 | 从 m0 起，第一根 b(m) < b(m−1) 时动手；m0 + 5 仍未动手则动手 |

动手时间若晚于平台最后入场时点，按“不入场”记（与 v6.6 相同）。

## 指标

- 买入成本：与 J0 逐笔配对（同一信号），成本改善 = J0 成交价 / 候选成交价 − 1；报平均、中位数、最差 5%、改善为正的比例、按交易日聚类 bootstrap 95% 区间（1000 次，种子 20261026）。
- 整笔结果：60% 期望、利润因子、盈亏比、≥ +200% 占比（同 TK8）。

## 判定（跑数前写定）

某候选“买得更便宜”成立需同时满足（选择段）：
1. 平均成本改善 > 0，且 bootstrap 95% 区间下限 > 0；
2. 最差 5% 成本改善 ≥ −20%；
3. 整笔 60% 期望不低于 J0（差值的 bootstrap 区间上限 ≥ 0 即视为不低于）。

多于一个成立时，取平均成本改善最大者为默认买法。已用过的验证段照报，不参与判定。
