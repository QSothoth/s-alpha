# 失败经验（美股 0DTE 选标的 / 方向 / 择时）

「失败」指没过事先登记的门槛。2026-10-12 清理时，各轮的代码、预登记和报告从仓库里移出（TS16–TS67、FD、来源核验等约 640 个文件）；这里只留结论和教训。P1–P5、SV1/SV2 的预登记和报告仍在本目录。

## 总教训（先读这一节）

1. **开盘前的信息给不出日内方向。** 日 K、盘前、期权统计、资金流、财报、宏观日历、基本面、另类数据都试过，S 系列约 85 条规则加 TS 系列 67 轮，没有一条在新数据上稳定成立。能成立的只有**波动大小**（财报日、放量宽幅次日的大动名单，S22 / P2 K1、K4B），不带方向。
2. **共同的失败形态：胜率能提上去，盈亏比上不去。** TS 系列很多候选能把胜率从约 18% 提到 30–40%，入场能提前 40–70 分钟，持有更久、卖飞更少，但盈亏比停在 1.1–1.8，扣成本后净 R 为负。「更早入场」「持有更久」都不等于赚钱。
3. **模型化准入也没用。** ridge（TS8）、条件均值表（TS9）、HOLD/EXIT 回归（OS1）、六分类概率（TS58）、分年浅树（TS63）在日线层面的最高预测收益都 ≤ 0 或低于门槛，名单全空、零交易。可预测的部分比成本小。
4. **偶尔出现的正结果都是小样本。** TS59（42 笔，净 R +10~+20）、TS64（13 笔）、TS45（周一）的均值为正，但日期区间都跨 0。不能拿来救回。
5. **方法上的教训：同一份开发集不能反复用。** TS 系列几十轮都在同一个 19 股 × 376 日（7144 单位）的开发集上测，每轮单独看都预登记了，合起来就是大规模多重检验；再测下去即使出现「通过」也不可信。以后新机制要么用没碰过的数据，要么先定总轮数上限。
6. **审计开销不能超过研究本身。** 后期每轮都有大量 SHA 守恒、跨进程字节一致、源文件独立复核，文档变成流水账，人读不了，也没提高结论的可信度。一轮的记录写成一行结论就够了。
7. **外部来源成本很高。** SEC / BLS / 交易所原件经常 403、跨行、字段口径对不上（LR1、OF1、TS29、CS1、IF1、TSU1），好几轮还没到评分就耗在取源上。优先用 OpenD 能按需拉的数据。
8. **股票收益不等于期权收益。** FD1 发现股票评分和真实期权收益对不上；要用期权代理时，先在真实期权上校准（SV2 校准后 k = 0.46）。
