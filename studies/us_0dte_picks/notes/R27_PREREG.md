# R27：V6.6 连续确认与方向强度

2026-10-14，用户要求研究 V6.7；本文写于候选实现和收益计算之前。本轮只测下面四个候选，结果出来不增加候选、不改门槛。

## 假设与边界

连续完整分钟都满足入场条件，可能减少单根假突破；代价是入场更晚、权利金更贵和漏单。收盘靠近有利端且成交量不缩，可能表示推动更持续，也可能只是追涨。两种方向对称处理，LONG 买 CALL、SHORT 买 PUT。

V6.6 已使用多根历史，不是只看一分钟；本轮增加的是最终入场条件的连续性。区别于旧 persist_minutes（只要求站在 VWAP 一侧）：这里每分钟都须满足完整 V6.6 入场条件，包含前五根突破、EMA、VWAP 距离、压缩及模型权利金。任一分钟失败或时间不连续都清零，在第 N 根收盘发出 ENTER，沿用下一根可成交期权 K 线成交。

不移植 Watch 的日线／指数强度档，它不符合 custody 当天正股输入契约，而且不是胜率。仅借用连续确认和成交量／收盘位置的思路。旧的五分钟 VWAP 确认与放量过滤曾失败，本轮是用户明确要求的、数量封顶的一次组合检验，不能循环调参。

## 固定候选

全部以 zero_dte_timing_v6.6 为基线，退出、成交成本、预算、评测标准不变，无兜底入场。

| 代号 | 完整信号连续分钟数 | 额外强度，每一分钟都要满足 |
|---|---:|---|
| C2 | 2 | 无 |
| C3 | 3 | 无 |
| S2 | 2 | 当根量 ≥ 此前5根均量；收盘在当根有利侧四分之一区间 |
| S3 | 3 | 同 S2 |

强度口径：LONG 的 (close-low)/(high-low) ≥ 0.75；SHORT 的 (high-close)/(high-low) ≥ 0.75；零振幅拒绝。量基准不包含当根，使用已有 min_breakout_volume_ratio=1.0（不同于 Watch 的20根量基准）。新增 entry_confirm_minutes，默认为1；新增 min_close_location，默认关闭。G10 同样扰动新增参数，不能排除。

## 数据与选择

- 只使用已登记 custody-0dte-v6.1，146个真实0DTE case／21个交易日，CALL/PUT 全部保留。冻结 checksum 以评测报告记录为准。
- 这份数据已经被多轮使用，只能作开发筛选。旧09-18验证结果已知，不再拿它挑规则；SV1 数据为原流程检验保留，不读取其价格或收益。本轮没有可称为全新验证的20个交易日。
- developed_on.sessions_through 写研究日期 2026-10-14，不能把已经过去的日期自动计作新版本前向样本外。
- 每个候选通过隔离临时注册表调用原 `python3 -m custody evaluate`，完整 G2–G13，默认随机对照次数、滑点、手续费及压力测试，不缩减。原注册表与默认版本不改。
- 排序先看 G3–G13 未通过／不适用数量，再看50%命中率综合分，同分按 C2、C3、S2、S3。晋级要求 G2通过、G3–G13全通过、50%和60%命中率综合分都高于 V6.6，且按交易日配对重抽样1000次、固定seed=20261014的50%综合分差95%区间下限大于0。
- 留一天交叉选择稳定性诊断：每折只用其余20日计算候选／基线综合分，候选需两种命中率分数均高于基线、盈亏比≥2、利润因子>1；按50%综合分最高者选择，否则保留V6.6。记录21折选择和被留出日收益。这是预先定义的简化选择稳定性诊断，不冒充每折完整G2–G13嵌套评测，更不是新的独立验证集。最终晋级仍取决于上述完整门槛和配对区间。
- 无晋级者：记录失败，不登记V6.7，不打开留出段，不在同一批数据继续优化。若有晋级者：可冻结为V6.7 candidate研究版本；独立验证仍待新数据，不能 accepted／live，也不自动替换会话默认。
