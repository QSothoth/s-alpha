# EXEC3 预登记：原子单的成交时机（一次成交）

登记时间：2026-10-26，跑数之前（EXEC1–EXEC2 结果已看过）。实现 `exec_eval.py --round EXEC3`。

## 用户澄清

评测对象是“智能买 / 智能卖”原子单本身的能力：给定合约、张数、时间段，这张单在时间段内一次成交、到期必须成交。测试用例和指标不围绕分批设计。EXEC1–EXEC2 里的 TWAP 与“一半立即、一半等待”属于分批做法，不再作为候选；TWAP 只在报告里留作参考线（它的平均值等于“时间段内随机时刻一次成交”的期望，可用来区分时机选择的贡献与单纯的时间价值衰减）。

## 候选（每个都是一次成交，只决定何时成交）

| 买 | 规则 |
|---|---|
| BM | 时间段过半时买 |
| B2 | 可买价从开始以来的最低点反弹 20% 就买 |
| B3 | 反弹 30% 就买 |
| BG10 | 等到时间段结束再买；途中可买价 ≥ 到达价 × 1.10 就立即买（防跑飞） |
| BG20 | 同上，阈值 1.20 |

| 卖 | 规则 |
|---|---|
| SM | 时间段过半时卖 |
| S1 | 可卖价从开始以来的最高点回落 10% 就卖 |
| S2 | 回落 20% 就卖 |
| SG10 | 等到时间段结束再卖；途中可卖价 ≤ 到达价 × 0.90 就立即卖（止损式） |
| SG20 | 同上，阈值 0.80 |

基准：立即成交、到点成交（也是一次成交）；TWAP 只作参考。

## 选择与判定

- 四组（买 / 卖 × 到收盘 / 60 分钟）各自在选择段上，从 {立即, 到点, 本轮候选} 中选平均改善最高者，要求最差 5%（改善的 5% 分位）≥ −40%；没有满足的取“立即成交”。−40% 是研究者设定的风险上限，用户可调整，调整须记录。
- 选择段成立：选中者平均改善 > 0、日聚类 bootstrap 95% 下限 > 0、最差 5% ≥ −40%、超时比例不高于到点成交。
- 验证段（holdout-20261023 + 09-18）已在 EXEC1 用过，只报告；1–4 天到期诊断只报告。最终检验留给其他机器采集的新数据。
