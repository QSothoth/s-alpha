# EXEC1 预登记：智能买 / 智能卖第一轮

登记时间：2026-10-26，跑数之前。测试集与指标按 [EXEC_TESTSET_CN](EXEC_TESTSET_CN.md)（已冻结）。实现 `studies/us_0dte_picks/exec_eval.py`。

## 问题

用户给定合约、张数、方向（买或卖）和时间段，时间段结束时必须成交。在只用当时已完成的期权 1m 成交价的前提下，哪种执行方式的成交价最好。

## 依据

- 0DTE 期权有时间价值衰减：平均来看买得晚更便宜、卖得早更贵，但价格随时可能朝不利方向跑。
- 常见的执行做法是“等拐点”：卖时等价格从高点回落一定比例（移动止盈式），买时等价格从低点反弹一定比例（移动买入）；或者挂一个比当前更有利的限价，等不到再在结束时成交；或者先成交一半、另一半等拐点。
- 本轮没有看过任何执行方案的结果；用过的只有 TK1–TK7 的策略收益（不同问题）。

## 规则（全部在每根已完成的期权 1m K 线上判断，决定后下一根有成交的 K 线成交，成交价按测试集成交模型）

卖：“可卖价” = 该 K 线按成交模型的卖出价；买：“可买价” = 按成交模型的买入价。

| 卖方案 | 规则 |
|---|---|
| S1 | 移动止盈 10%：可卖价从开始以来的最高点回落 10% 就卖 |
| S2 | 移动止盈 20% |
| S3 | 移动止盈 30% |
| S4 | 一半立即卖，另一半按 S2 |
| S5 | 限价：可卖价达到到达价 × 1.05 就卖 |

| 买方案 | 规则 |
|---|---|
| B1 | 移动买入 10%：可买价从开始以来的最低点反弹 10% 就买 |
| B2 | 移动买入 20% |
| B3 | 移动买入 30% |
| B4 | 一半立即买，另一半按 B2 |
| B5 | 限价：可买价跌到到达价 × 0.95 就买 |

所有方案到时间段结束仍未成交的，按测试集口径强制成交。基准：立即成交（到达价）、TWAP、到点成交。

## 选择与判定

- 分四组各自选择：买 / 卖 × 时间段（到收盘 / 60 分钟）。
- 选择：在选择段（v6-work 0DTE）上，从 {立即成交, TWAP, 到点成交, 5 个候选} 中选“相对到达价的改善”均值最高者，但要求它的尾部损失（改善的 5% 分位）不比 TWAP 差；不满足的跳过，取下一个。
- 通过（验证段 holdout-20261023 + 09-18，每组只评选中者一次）：改善均值 > 0 且按交易日聚类 bootstrap 95% 下限 > 0；相对 TWAP 改善 ≥ 0；尾部损失不比 TWAP 差；超时比例不高于到点成交。
- 诊断：`custody-train-dte4`（有偏）与按到期档、权利金、流动性分层只报告。
- 看完结果才想到的改动另开一轮（EXEC2），仍在选择段上选，验证段不再作选择依据（只报告）。
