# A1 预登记：agent 审卡能否过滤掉 v6.6 的坏入场

状态：**定稿**（2026-10-02 用户确认输入与评分；运行前定稿，之后不改）。

**用户费用决定（运行前）：本轮只跑 C1（Codex，订阅额度），C2、C3 不运行**；它们的单卡实测费用保留在预算一节，供以后决定。

## 问题

择时线 `zero_dte_timing_v6.6` 出信号就买。用户实盘流程里，agent（Codex、Claude、Grok 等不同 harness 加不同模型）看卡片后决定接受或拒绝。这一环节此前没有任何评测。本轮回答：**同一张卡片，agent 只挑部分接受，能不能比"全部接受"赚得更多，并且好于随机挑同样数量？**

结构性理由：规则只看少数条件（VWAP、EMA、突破、压缩），看不到区间位置、大盘是否同向、离强平还剩多少时间等上下文；人工复核本来就是为补这些。反方理由：卡片上的信息规则已经用过一部分，模型也可能只是在讲故事。

## 输入

- 卡片由 `code/cards.py` 从冻结数据集生成：每个 v6.6 实际入场的决策分钟一张。只含该分钟之前（含）已完成的正股 1m K 线、同日 SPY / QQQ 的 5m K 线（数据集有时才给）、期权方向、规则入场原因、行权价、最近一笔期权成交价与累计成交量。
- 匿名化：不给标的代码和日期，价格按当天第一根 1m 开盘价 = 100 缩放，防止模型凭记忆认出行情。
- 训练集 `custody-0dte-v6.1`：96 张（v6.6 在这份数据上选出，规则层面属样本内；但 agent 从未见过这些卡片）。
- 验证集 `custody-eval-2026-09-18-v2`：12 张，只报告。
- 结果（不给 agent）：取该 case 在 custody 回放里 v6.6 自己的成交和离场，按每笔 100 美元权利金折算。全部接受的合计应与 v6.6 报告账户视角一致（v6.1：+612 美元）。

## 候选（3 个，固定，不调）

| 候选 | 调用 | 模型 |
|---|---|---|
| C1 | `codex exec --ephemeral -s read-only --json`，stdin 接 /dev/null | gpt-6.1-sol，推理强度用配置默认 medium |
| C2 | `claude -p --output-format json --tools ""`，单次上限 1 美元 | claude-opus-5-5，默认 effort |
| C3 | `grok -p --output-format json --max-turns 1 --tools ""` | grok-4.6-build，默认推理强度 |

三者共用 `code/prompt.txt`，同一提示、同一卡片，只换执行者。本轮不改提示词；看完结果才想到的改动，留到下一轮用没用过的数据验证。

## 运行

- 每张卡每个候选跑 3 次，以多数票作为该候选的决定；输出不是合法 JSON 记为 SKIP，并单独计数。
- 每次调用的原始输出、用量、耗时、harness 版本都落盘。

## 评分（不用打分模型，直接看回放盈亏）

对每个候选：

1. 接受率、接受部分的合计盈亏（美元）、每笔期望、盈亏比；
2. **相对全部接受**：合计盈亏之差；按交易日重抽样 2000 次，给出这个差值的 95% 区间；
3. **相对随机挑选**：从全部卡片里随机抽同样张数，抽 10000 次；p =（随机合计 ≥ 候选合计的次数 + 1）÷（10000 + 1）；
4. 稳定性：3 次判断完全一致的卡片占比；
5. 用量与费用：每张卡的平均 token、美元、耗时。

**通过线（训练集）**：合计盈亏 > 全部接受，且相对随机的 p ≤ 0.10。验证集 12 张只报告。即使通过，也只说明"值得在前向数据上验证"，不改变实盘流程。

## 已知限制

- v6.6 的 96 个入场点和它的盈亏来自同一份训练数据；验证集只有一天。真正的验证要靠前向数据，需要每个交易日收盘后执行 `custody freeze`。
- 卡片不含买卖报价（历史数据只有 1m 成交 K 线），与实盘卡片的信息不完全一致。
- 模型的知识截止与 2026-08/09 的数据先后未知，匿名化只能降低、不能排除凭记忆认出行情。

## 预算（运行前实测；本轮只用 C1）

实测单卡：Claude $0.05–0.14，Grok $0.02–0.03，Codex 不报美元（订阅额度），耗时 Codex 约 10 秒、Claude 约 13 秒、Grok 约 70 秒。108 张 × 3 次：Claude 约 $20–25，Grok 约 $7–9，Codex 324 次调用。总额度上限 40 美元，超出即停。
