# S27 预登记（2026-09-25，拉数据前）：放宽流动性，在从未用过的第 301–600 名期权活跃个股上一次性验证

## 来源（如实说明）

S26 的 W5 在验证段未成立。随后把 300 只个股的**全部** 791 天（2023-08 → 2026-09，含已用过一次的验证段）当作选择段做了明示探索：

- 十分位扫描（[reports/s27_explore_select_raw.txt](../reports/s27_explore_select_raw.txt)）：两段都为正的只有 **T−1 Put/Call z**
  （全段 +10.6bp，95% +3.8 ~ +17.9，t 2.9；2023–24 +13.4，2025–26 +8.3）；收盘位置、IV − HV 在 2025–26 反号。
- Put/Call z 的 Top N 篮子：全段 Top 3 +17.5bp、Top 5 +18.9bp；在当日隐含波动较高的一半里 Top 3 +26.6bp、Top 5 +23.6bp（2025–26 都只剩 +7 ~ +11bp）。
  沿所选方向的开→收幅度只有当日隐含波动的 0.02 倍左右。

用户要求「适当放低流动性要求」。结构性理由：Put/Call 反向是散户情绪效应，散户占比越高、做市越薄的票，情绪越容易过冲，效应应更强。
第 301–600 名（按 2026-09-24 期权成交量排名）的个股从未进入任何一轮，是干净的横截面样本。

## 数据

- 名单：OpenD `get_option_underlying_rank`（US_SECURITY，按成交量）在排名日取个股（不含 ETF）、价格 ≥ 3，第 301–600 名；与 300 只名单不重叠。
- 日 K：K_DAY 订阅后 `get_cur_kline` 1000 根（QFQ + 不复权），不扣历史 K 线额度；期权统计与 IV / HV 用历史统计接口（不扣额度）。
- 与 S24 相同地用 Yahoo 交叉核对日 K；OpenD 被所有可用来源否定的日子剔除。数据发 GitHub Release（`preopen-s27-holdout-v1`）。

## 规则（每天 T 在 09:30 决定，只用 T−1 及以前 + T 开盘）

活跃池：前收 ≥ 3、前 20 天均成交额 ≥ 500 万美元、**T−1 期权量 ≥ 1,000 张**（从 2,000 放宽到 1,000，按用户要求；拉数据前定）。高分做多、低分做空。

| id | 规则 | 理由 |
|---|---|---|
| Z1 `pcr_top3` | T−1 Put/Call z，Top 3 / Bottom 3 | 情绪反向，全段唯一稳定的特征 |
| Z2 `pcr_ivhalf_top3` | 同 Z1，只在当日池内隐含日波动（IV / √252）较高的一半里选 | 波动大、适合期权的一半；选择段效应更大 |
| Z3 `pcr_ivhalf_top5` | Z2，Top 5 / Bottom 5 | N 放大看是否更稳 |
| Z4 `composite_top3` | S26 合成分（z(Put/Call z) − z(IV − HV) + z(收盘位置)），Top 3 / Bottom 3 | 当前 `daily_top.py` 的排序，看它在低流动性票上是否成立（规则不变） |

## 指标与判定（只跑一次，4 个候选都报）

- 区间 2023-08-01 → 2026-09-24，只用第 301–600 名的票。剔除 US.BRK / US.SPCX / US.B 之类重复类别（若在名单中）。
- **篮子**（每天多头均值 − 空头均值，毛）：毛价差 − 20bp > 0、**95% 下限** − 20bp > 0（4 个候选，用 95% 而非 90%）、价差为正的天 ≥ 53%、
  两段（2023-08 → 2024-12 / 2025-01 → 2026-09）毛价差都 > 20bp。全部满足 = 成立。
- **每只**（扣 10bp）：期望 > 0 且 95% 下限 > 0、利润因子 ≥ 1.1。全部满足 = 成立。
- 期权视角（描述，不作门槛）：沿所选方向的开→收 / 当日隐含日波动。
- 任一候选成立 → `daily_top.py` 改用它（池子扩到 600 只、期权量门槛 1,000）；都不成立 → 如实记录，方向不再在 T−1 技术面上找。
