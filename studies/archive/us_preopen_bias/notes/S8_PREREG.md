# S8 预登记（2026-09-24，运行前）：资金流里的小单（一次性检验，没有选择段）

## 为什么可以这样做

OpenD 的日级资金流（超大 / 大 / 中 / 小单净流入）只有 2025-09-24 起的一年，全部落在 `preopen-us-valid-v1` 里。
这一段已经为 S1–S5 的三个入围者用过一次，但**资金流特征从未在任何数据上评测过**（S1 预登记就写明不用）。
所以这里不设选择段，按预登记的规则直接跑**一次**，门槛比常规验证更严（没有选择段、同时检验 3 个），跑完不改。

要承认的偏差：看过验证段的 Put/Call 结果，知道这一年恐慌做多失效；这不直接泄露资金流与涨跌的关系。

## 口径的限制

美股机构普遍用算法把大单拆成小单，「小单」在美股不像 A 股 / 港股那样等于散户；这是本轮最可能失败的原因，照记。

## 数据与区间

- 评测区间 2025-10-22 → 2026-09-23（资金流 2025-09-24 起，前 20 天做 z 分数热身），16 只。
- 特征用 T−1 行：小单占比 = 小单净流入 / T−1 成交额；主力占比 = 主力（超大 + 大单）净流入 / T−1 成交额；各自对前 20 日做 z 分数。

## 候选（3 个）

| id | 规则 | 结构性理由 |
|---|---|---|
| K1 `retail_flow_fade` | 小单占比 z ≥ +1.5 → SHORT；≤ −1.5 → LONG | 散户集中净买入之后日内回吐（反散户） |
| K2 `retail_vs_main` | 小单占比 z ≥ +1 且主力占比 z ≤ −1 → SHORT；反之 → LONG | 散户买、机构卖（或反过来）时跟机构 |
| K3 `main_flow_follow` | 主力占比 z ≥ +1.5 → LONG；≤ −1.5 → SHORT | 机构拆单执行跨日延续 |

## 判定（只跑一次）

每个候选四项都满足才算成立：信号 ≥ 100 个；胜率 ≥ 53%；按交易日重抽的 **95%** 区间下限 > 50%；超额 > 0。
