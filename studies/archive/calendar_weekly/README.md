# 历法／卦象预测指数（calendar_weekly，已归档）

2026-10-02 至 10-05 做的研究：用易学（历法、六爻、纳甲、河洛、月相）加统计底座，从固定起点一次推演三科技指数（恒生科技、纳指 100、科创 50）以及上证、恒生国企、标普 500 未来 156 周的周／月走势。约 60 轮（CW1、FA1、TP1/TP2、DE1、SM1、UM1、MR1、NA1–NA3、EE1、EH1、RESCUE5 等）。

2026-10-12 清理时，代码、预登记和报告全部移出仓库，这里只留结论。本机 `data/calendar-*` 共 81 个目录，没有发布 Release，也不再维护。

## 结论：没有找到易学增量

- **方向命中不超过「一直看涨」。** CW1 的五个确定性切片在三个市场的选择段都没过门槛。FA1 的 A 股混合方案周命中 60.78%，一直看涨是 54.25%，但概率质量没有改善，去掉历史均值后也不成立。QS1 在 29 个纳指起点上，五种方法的月命中都是 96/152，和一直看涨相同。UM1、MR1、EE1 的命中都低于或等于恒涨、历史均值（例如 EE1 是 170/288，基准 175/288）。
- **易学信号的信息量本身很小。** 固定在 09:00 起卦，4320 组输入只覆盖 8 个本卦、24 种本卦加动爻组合（SI1）。月相类的短周期特征到月度只剩约 5%，到 13 周只剩约 2.7%，被平均抵消了（LC1）。
- **公开的「易经交易」实现有前视偏差。** I Ching Trader 用全样本中位数编码，用到了后来的数据；论文的第三方实现有全量训练、向后标签和随机财务字段（IT1、RA1）。论文报告的行业 F1 不是指数周命中率（PA1）。
- **统计底座能改善区间，不能给方向。** 历史路径加波动缩放让月 80% 区间的覆盖率从 47.8% 升到 65.2%，但仍然欠覆盖，方向不变（CD1、VD1、WA1、DA1）。所有方法都偏多，是因为历史均值为正（LD1）。
- **评估方法上的发现。** 三个起点、27 次 bootstrap 的下界在零假设下有 1/8 的概率为正，不能当作单侧 95% 保证（EV1）。三期全胜的最小 p 也只有 0.125：起点太少，原理上就判断不了。

## 教训

1. 没有结构性理由的信号，换编码、换底座、换评价口径重复几十轮，只会消耗留出数据，不会出现增量。
2. 长周期、少起点的预测，样本数先天就不够做显著性判断；立项前先算功效。
3. 引用外部实现之前，先查有没有前视偏差。
