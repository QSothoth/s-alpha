## 方法经验

- 港股分钟研究按每根 K 线跨越价位数分层；混合样本中的反向优势不能外推到价位细的标的。
- 用下一根收盘及延后入场检验，避免把买卖价反弹当作收益。
- 失败结果照留；新假设另行预登记，不能重新挑选或重用已看过的验证数据。

数据发布与 SHA256 见 [DATA](../../../docs/DATA.md)。归档不会触发行情下载、回测或后台任务。
