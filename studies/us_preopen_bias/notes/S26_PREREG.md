## 候选（5 个；高分做多、低分做空；每日活跃池同 S24）

| id | 规则 | 理由 |
|---|---|---|
| W1 `pcr_top3` | T−1 Put/Call z，Top 3 / Bottom 3 | 期权情绪反向（恐慌买 put 后偏强、追 call 后偏弱） |
| W2 `pcr_liquid_top3` | 同 W1，但只在当日 T−1 期权量前 60 的票里选 | 期权量越大，Put/Call 越能代表情绪而非零星成交 |
| W3 `composite_top3` | 当日池内 z(Put/Call z) − z(IV − HV) + z(收盘位置) 等权，Top 3 / Bottom 3 | 期权情绪 + 波动溢价（Bali & Hovakimian 2009：IV 高于实际波动越多、后续越弱）+ 收盘强弱 |
| W4 `composite_liquid_top3` | W3，只在期权量前 60 里选 | 同 W2 |
| W5 `composite_top5` | W3，Top 5 / Bottom 5 | 看 N 放大后是否更稳 |

## 指标与判定

- 每只：胜率、盈亏比、扣 10bp 后期望、利润因子（同 S24）；**篮子**：每天多头均值 − 空头均值（毛），价差为正的天数比例（多空对冲后的胜率）、盈亏比。
- 选择段 2023-08-01 → 2024-12-31：S24 的每只门槛（期望 > 0 且 95% 下限 > 0、利润因子 ≥ 1.2、两半 > 0、胜率 ≥ 53% 或盈亏比 ≥ 1.3）**或**篮子门槛
  （毛价差 − 20bp 成本 > 0 且 95% 下限 > 0、价差为正的天 ≥ 53%、两半 > 0）任一全部满足即入围，最多 2 个。
- 验证段只跑一次：对应门槛的 90% 下限版本。
