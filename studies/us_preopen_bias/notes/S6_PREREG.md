# S6 预登记（2026-09-24，验证段失败之后、运行前）：纯价格信号 + 更早的留出段

纯价格信号（只用日 K）可以用更早、从未评测过标签的数据验证：日 K 从 2015-06 免费重拉（已扣费标的，额度不变），

## 切分

- **选择段 2023-08-01 → 2026-09-23**（训练 + 原验证 Release；原验证段已经用过一次，这里只作选择），两半以 2025-02-01 切开；
- **留出段 2016-01-04 → 2023-07-31**（`preopen-us-holdout-2016-v1` + 训练 Release 里 2022-06 → 2023-07 的日 K；S1–S5 从未评测过这段的标签），只评测一次；
- 留出段只有 14 只（SNDK、SKHY 当时未上市）。口径、选择段门槛同 [S1](S1_PREREG.md)。

## 候选（5 个，只用日 K 与 SPY 日 K）

| id | 规则 | 结构性理由 |
|---|---|---|
| H1 `spy_reversal` | SPY 昨日涨跌 / SPY ATR20 ≤ −1 → 全部 LONG；≥ +1 → 全部 SHORT（= D2） | 指数日间反转：杠杆 ETF 在收盘前按当日方向再平衡，把收盘价推过头，次日回吐 |
| H2 `own_reversal` | 该标的昨日涨跌 ≤ −1 个 ATR → LONG；≥ +1 → SHORT | 单只标的的短期反转（流动性提供者回补） |
| H3 `attention_gap_fade` | \|跳空\| ≥ 1 个 ATR 且昨日成交额 ≥ 20 日均值 1.5 倍 → 反跳空（= C3） | 关注度驱动的开盘集中买卖在日内回吐 |
| H4 `oversold_long` | 昨收低于 20 日均线 ≥ 2 个 ATR → LONG | 抛售型超跌的流动性溢价在日内修复；只做多（买方超买不对称） |
| H5 `gap_fade` | \|跳空\| ≥ 1 个 ATR → 反跳空（不要成交额条件） | 检验 H3 的关注度条件是否必要 |

## 入围与留出段判定

选择段通过者按胜率取前 2 个（H3 / H5 同一机制只取一个），留出段只跑一次：胜率 ≥ 53%、90% 区间下限 > 50%、超额 > 0 三项都满足才算成立。
