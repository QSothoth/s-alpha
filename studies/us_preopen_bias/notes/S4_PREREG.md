# S4 预登记（2026-09-24，S3 之后、运行前）：找做空侧

**如实说明**：S1–S3 通过的全是做多（恐慌之后做多）；做空侧 C1 只有 134 个信号，E5 放宽后没通过。
S4 把同一机制反过来——call 偏重（「贪婪」）之后做空——是看过 S1–S3 之后提出的，只能靠验证段证明。
选择段五档探索里做空侧本来就弱（Put/Call z 最低一档上涨比例 48.8%，对应做空胜率约 51%），所以阈值比做多侧更严。数据、口径、门槛同 [S1](S1_PREREG.md)。

## 候选（5 个）

| id | 规则 | 结构性理由 |
|---|---|---|
| F1 `greed_short` | Put/Call z ≤ −1.5 → SHORT | D1 的镜像：call 买盘异常集中后回吐 |
| F2 `greed_after_up` | Put/Call z ≤ −1 且 T−1 涨幅 ≥ 1 个 ATR → SHORT | 大涨后散户追 call，次日日内回吐 |
| F3 `daily_top_greed` | 每天只取 Put/Call z 最低的一只，且 z ≤ −1.5 → SHORT | E4 的镜像，每天一个对象 |
| F4 `greed_gap_up` | Put/Call z ≤ −1 且 T 日高开 → SHORT | E2 的镜像：追涨情绪延续到开盘，开盘价被推高 |
| F5 `greed_market_up` | Put/Call z ≤ −1 且 SPY 昨日涨幅 ≥ 1 个 SPY ATR → SHORT | 个股 call 偏重叠加大盘普涨，指数层面的日间反转同向 |

## 入围规则（S1–S4 合起来，最多 3 个）

1. 恐慌做多一族（C1 的做多侧、D1、D5、E1–E4）中胜率最高的一个；
2. 做空侧（S4 通过者中胜率最高的一个，没有就空缺）；
3. 其余不同机制的通过者（C1、D4）中胜率最高的一个。
