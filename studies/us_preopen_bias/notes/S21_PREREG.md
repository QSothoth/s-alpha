# S21 预登记（2026-09-25，运行前）：每日多空名单——波动大、适合做期权的日内选股

## 需求（用户 2026-09-25 明确）

每天开盘时，从期权流动性好的标的里挑出当天**可能大幅波动**的一批，给出**做多 N 只、做空 N 只**。日内怎么买卖由用户已有的策略负责，本研究只做选股。
只用日线级数据与开盘前可见的盘前 / 盘后数据，不用分钟线。

## 标的池与准入

- 34 只热门中小盘（`notes/universe_smallmid.json`：OpenD 2026-09-24 期权成交量排行，市值 5 亿–300 亿美元、股价 ≥ 5，按板块归 AI / 创新药 / 资源各前 12；
  KOD、AVTX 因 5 分钟数据与 Yahoo 不一致已剔除）。名单按「今天」的热度选，带幸存者偏差（多空两侧分开报告）。
- 每日准入（全部只用 T−1 及更早）：前一日名义收盘 ≥ 5 美元、名义 ATR14 ≥ 0.5 美元、前 20 日平均成交额 ≥ 1,000 万美元（OpenD 不复权日线），
  且 **T−1 期权成交量 ≥ 5,000 张**（期权流动性）。

## 决策时点与标签

- 决策时点 T 日 09:30：已知 T−1 及更早的全部日线数据、T−1 盘后与 T 日盘前 30 分钟 K、T 日开盘价。
- 标签（T 日）：方向 = 收盘 vs 开盘；**顺向幅度** = 方向 × (收盘 / 开盘 − 1) ÷ ATR20（占价格）；**顺向最大空间** = 做多 (最高 / 开盘 − 1)、做空 (1 − 最低 / 开盘)，再 ÷ ATR20。

## 候选（5 个；每个每天给出做多 N、做空 N，N = 3 为主口径，另报 N = 1、5）

| id | 规则 | 结构性理由 |
|---|---|---|
| P1 `gap_go` | 按 \|跳空\| / ATR 排序（≥ 0.5）：跳空向上最大的 N 只做多、向下最大的 N 只做空 | 带消息的大跳空是当天的「Stocks in Play」，消息驱动的行情倾向延续（Chan 2003） |
| P2 `gap_fade` | 同 P1 的排序，方向相反 | 注意力驱动的开盘价被推过头、日内回吐（Berkman 等 2012） |
| P3 `pm_volume_go` | 按盘前成交额 / 前 20 日盘前均值排序（≥ 2），跳空方向延续：向上的前 N 做多、向下的前 N 做空 | 盘前异常放量 = 当天的信息日 |
| P4 `inplay_pcr` | 先取 \|跳空\| 最大的 10 只作「在场」候选，其中 T−1 Put/Call z 最高的 N 只做多、最低的 N 只做空 | 在大波动的票里，用期权情绪（恐慌做多、贪婪做空）定方向 |
| P5 `attention_short_fear_long` | 做空：T−1 盘后涨跌 / ATR 绝对值最大的 N 只（≥ 1，Q2）；做多：T−1 Put/Call z 最高的 N 只（≥ 1，D1） | 前面各轮仅有的两个在部分数据上成立过的日线信号，放到新标的池上 |

## 切分与判定

- **选择段 2023-08-01 → 2024-12-31**（两半以 2024-05-01 切开）；**验证段 2025-01-02 → 2026-09-24**，这 34 只在这段的日线标签从未被评估过，只跑一次，最多 2 个入围。
- 以一只入选票为一笔。选择段门槛：入选 ≥ 150 笔且覆盖 ≥ 60 天；方向命中率按交易日重抽 95% 下限 > 50%；
  超额（命中率 − 同日同池无条件的同向概率）≥ 2 个百分点；两半命中率都 > 51%；**幅度倍数**（入选票的 \|收−开\| / ATR 均值 ÷ 同日准入池均值）≥ 1.2。
- 验证段：命中率 ≥ 53%、90% 下限 > 50%、超额 > 0、幅度倍数 ≥ 1.2 四项都满足才算成立。
- 同时报告：顺向幅度均值、顺向最大空间均值、顺向幅度 ≥ 0.5 个 ATR 的比例，均与「同日准入池随机」对照。
