# 盘中临时 K 线与收盘 K 线的信号差异：预登记（I1）

登记日期 2026-10-21，写于看到任何差异结果之前；跑完不改。实现 `studies/trader_screens/intraday_study.py`，分钟线取数 `minute.py`。

## 问题与结构性理由

登记的 7 个系统都在 T 日收盘确认、按收盘价成交、止损在 T 日低点；改成 T+1 开盘买，收益大幅退化（X1 轮，`studies/trader_replication/notes/EXEC_PREREG_X1.md`）。所以看板要在收盘前用盘中快照当今天的临时日 K 跑一遍，尾盘下单。临时日 K 与收盘日 K 的差别有三类：收盘价还会移动；最高、最低还会被刷新；成交量、成交额只是部分值。前两类是价格，不能凭推测补齐，按原值使用；第三类有稳定的日内分布（U 形），可以按时点补齐。系统里用到成交量的有：EP 的“几倍量”、Wedge Pop / 收紧突破的放量、按成交额定的股票池和排序（20 日均成交额含当天）。成交量只算了部分时，这些条件会系统性偏紧，所以可能需要放大。

要回答：一、各截点下，临时日 K 算出的买卖与收盘日 K 差多少；二、成交量要不要按时点放大、怎么放大。

- **本地子集分钟线**（补天数）：美股为 `data/` 下 k5 目录的并集（同一代码取较大文件，约 280 只在股票池内，前复权），港股为 `watch-hk1m-{holdout-2025h2,train,valid}-v1`（1 分钟，约 138 只，前复权）。A 股本地没有分钟线。子集日只替换有分钟线的股票的当天日 K，其余股票用真实收盘；只在分钟线股票上统计信号，账户层面的买卖照常全部统计（其余股票的差异只可能来自连带）。

**核对**（跑信号前先做）：近期全名单分钟线合成的全天日 K（首根开盘、最高、最低、末根收盘、量和额之和）与我们的不复权日 K 比较，报告收盘价、最高、最低、成交量的差异分布，查清美股收盘竞价、盘前盘后是否在分钟线里。

## 临时日 K 的构造

截点 C（K 线结束时刻 ≤ C 的分钟线）：

| 市场 | 截点 | 主截点（看板建议运行时点） |
|---|---|---|
| 美股 | 15:40 / 15:45 / 15:50 / 15:55 | 15:50 |
| 港股 | 15:40 / 15:45 / 15:50 / 15:55（16:00 起是收盘竞价） | 15:50 |
| A 股 | 14:40 / 14:45 / 14:50 / 14:55（14:57 起是收盘集合竞价） | 14:50 |

- 近期不复权数据：开盘 = 真实日 K 开盘（快照里的开盘价已定）；最高、最低 = 截点前分钟线的最高、最低（含开盘）；收盘 = 截点那根的收盘；量、额 = 截点前累计。乘以当天的复权系数（面板收盘 / 不复权收盘）进入面板。
- 本地前复权数据：价格先换算到不复权口径（系数 = 真实日 K 与分钟线全天的开、高、低之比的中位数），量 = 真实日量 × 截点累计量 / 全天累计量，额同理。
- 前一日为止全用真实日 K，截点之后的数据一律不进面板。

## 放大方案（最多 5 个，取常见值，不做网格搜索）

只放大量和额，价格类字段不动。f 为“截点累计量 / 全天量”。

| 代号 | 方案 |
|---|---|
| V0 | 不放大（快照原值） |
| V1 | 量和额 ÷ 市场统一 f_m(C)：该市场选择段所有股票日 f 的中位数 |
| V2 | 量和额 ÷ 个股 f_i(C)：该股此前最多 20 个有分钟线的交易日的 f 均值（不足 5 天用 f_m） |
| V3 | 只有量 ÷ f_m(C)，额不放大（区分“放量条件”与“成交额股票池 / 排序”两种作用） |

“只按时点折算成交量门槛”要改系统代码，不在本轮；对“当天量 ≥ k × 均量”这种条件，它与 V1 等价。

## 评测

每天 D、截点 C、方案 V：前一日为止真实日 K + 临时日 K 跑 7 个系统，得到 D 日的：

- **形态信号**：当天所有入场候选（已买 + 没做的买点），按（系统、代码、方向、形态）；
- **买入**：实际开仓与加码，按（系统、代码、方向、是否加码）；
- **卖出**：全部离场（含跟踪线、分批），按（系统、代码、方向）。

与收盘真实日 K 的同一系统结果比较，统计：一致数、多出的假信号（临时有、收盘没有）、漏掉的真信号（收盘有、临时没有）、一致率 = 一致 / (一致 + 假 + 漏)；分人、分形态；共同买入的成交价差（真实收盘 / 临时价 − 1）和止损宽度差。

**翻转原因**（主截点、V0）：分别把临时日 K 的收盘、最高最低、量和额换成真实值再跑，某个不一致在哪种替换下消失，就记为那一类原因；都不消失记为“多项共同”。

## 选择规则与门槛

- 选择段：每个市场按日期排序的前一半测试日（取整向下）；验证段：后一半。
- 三个市场选择段合计，主截点上**买入 + 卖出**的（假 + 漏）总数最少的方案入选；只有比 V0 少至少 10% 才换掉 V0，否则用 V0；持平取 V0。
- 选择段只用 V0 跑全部 4 个截点，V1–V3 只在主截点跑。
- 验证段只跑一次：V0 与入选方案（若为 V0 则只有 V0），4 个截点；报告是否仍比 V0 少 ≥ 10%。不在验证段调参或换方案。
- 运行时点建议：取一致率与“合计耗时 + 下单余量”能放进收盘前的最晚截点；耗时以三个市场各一次的实测为准。
