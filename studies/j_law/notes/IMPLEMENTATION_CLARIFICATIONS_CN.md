# 实现正确性修正与未消除限制

2026-10-17。以下是审计后正确性修正，不是看结果调参数。

1. 日线R1原实现以成交当日全天成交量限制开盘数量，属于不可用信息；已改成上一完整日成交量的事前数量上限，原摘要保留superseded_volume_sizing。上限不是开盘可成交量证明。所有候选及200次随机对照重跑，门槛不变。
2. 分钟共享引擎以同区间多证券批次冻结前一时点权益/现金/未平风险；盘中退出不回流到同批更早买入；已持仓标的不允许同bar先退出再用先前高点新入场。
3. 目标部分成交保存剩余目标数量，不重新取剩余仓位比例；目标后保本同bar冲突用悲观路径。请求数量只用事前资金/风险，实际数量另外受已完成bar量的事后上界约束。该容量模型不等于逐笔可执行，在bar结束前不能认为容量已知。
4. Clement本轮三根形态精确定义是已确认局部低点（b低于a,c），并未要求它高于更早摆动低点；是A机械化，报告不能泛称严格“更高低点”已复制。
5. evaldata-v2的QFQ是数据发布时统一复权尺度，并无逐日可得的历史复权版本。split尺度变化虽通常保持比例，现金调整/价格门/量能可能受影响；仅调整单位价格路径诊断，不能宣称真实raw股票账本或完全PIT价格特征。真正raw share与公司行为核验仍是资格阻塞。
6. 这次修复与新增Deepak预登记都保留来源和时间；新机制研究不覆盖既有失败或限制。
