# 人性化仓位（H 轮）：总预登记

2026-10-20 写，在跑任何 H0 / H 结果之前。目标由用户给出：在“像人能做的交易”约束下重新优化已登记的交易员系统，不加融资，但允许按把握分档定仓位，让账户靠少数重仓的好交易接近他们公开的收益。实现在 `studies/trader_replication/human.py`（配置里的 `human` 开关，默认没有，登记系统逐位不变），单测 `tests/test_human.py`。

## 硬约束（研究者取值，取整，不调）

| 项 | 取值 | 实现 |
|---|---|---|
| 不融资 | 多头市值 + 空头市值 ≤ 100% 净值；每笔入场、加仓的总敞口空间都扣掉买入成本，现金不为负，不产生融资利息 | `max_gross = min(原值, 1.0)`、`gross_cost` |
| 同时持仓 | ≤ 10 只（多空合计） | `max_open = min(原值, 10)` |
| 每天新开 | ≤ 3 笔（多空合计，所有形态，含 EP 单独名额） | `max_new_all = 3`（原有的 `max_new_long` 等更紧的仍生效） |
| 每年开仓 | ≤ 250 笔（自然年，多空合计；加仓不算新开） | `max_new_year = 250` |
| 单只上限 | 可分档，最高 50% 净值；加仓也不超过该笔的档位上限 | `max_position = min(原值, .5)`、`cap_adds_entry` |
| 仓位档 | 最多 3 档（含基础档） | `human.tiers` |
| 当天不买回 | 某只票当天有卖出或止损（含分批），当天不再开新仓 | `no_rebuy_day` |

每个候选都在全区间、选择段上实测：最大 / 平均同时持仓、收盘时最大总敞口、每天最多新开、每年开仓、融资利息、当天买回次数，任何一项超限就作废（`human.humanized` 的 `ok`）。

已知说明：收盘时的总敞口还会随空单上涨而被动抬高（空单涨、净值降、空单市值升）；实测超过 100% 的就算作废，不另设容差。

**修订（2026-10-20，看过 H0 首跑后）**：首跑里所有带空头的 H0 都因此超限（收盘总敞口最多只超出 1 以内的零头，融资利息 1e−7～6e−6），按上一段会连 H0 一起作废。用户的约束是“任何时刻 ≤ 100%”，所以改为在引擎里直接执行：每个收盘若总敞口超过 100%，先回补空单（大的先），不够再卖多头，压回 100%（`gross_close`，执行记为 `gross`，单测 `test_a_rising_short_is_covered_at_the_close_back_to_the_gross_limit`）。这是硬约束的实现，不是可调参数；H0 与所有 H 候选都带上，首跑结果作废、不用于任何选择。

## H0

每位交易员的登记版本原样加 `human: {}`：只套硬约束，其余不变。原有的每天截断（Martin R74 在 build 里先截到 4 笔）保留，再由引擎按 3 笔截。H0 只测量、不调参；登记版本 → H0 的损失写进 `reports/HUMAN_SIZING_CN.md`。

## 每轮（`studies/<id>/notes/rounds/H<n>.json` + `PREREG_H<n>.md`）

- 每轮 ≤ 5 个候选，建在当前带入的版本上（第一轮是 H0）；候选只来自他的原话或台账 note 列；参数取整数或常见值；跑完不改，失败进否定登记表。
- 选择段 2024-01-02 → 2025-12-31，美股；2026 段（V1 / V2 已用过）与港股、A 股只报告，不作判断。
- 安慰剂：同池随机换股，同一天、同样止损宽度，同样套硬约束和仓位档（随机股继承原入场的档位与上限），筛选 50 次，带入前 100 次，种子固定。

## 接受规则（`human.accept`，都和 H0 比）

1. 满足硬约束；门禁四项全过（数据摘要、成交价在当日区间、胜率 ≤ 35% 在全区间上查；不看未来只对要带入的候选查，用 2024-09-30 / 2025-09-30 两个截点）。
2. 选择段收益高于同池安慰剂中位数。
3. 有数据期内公开成绩的人（Flanders、Clement、Martin）：2024、2025 两年的 |log((1 + 我们) / (1 + 他))| 都比 H0 小；其余人：选择段收益高于 H0，最大回撤不超过 H0 + 2 个百分点。
4. 行为不比 H0 差：选择段内实际买到他的有日期多头不少于 H0；他公布过的胜率、平均赚、平均亏、赢家平均持有天数，与他的平均对数距离（胜率按对数优势比）不超过 H0 + 0.02；他没公布的项，胜率不低于 H0 − 2 个百分点，其余与 H0 的对数差 ≤ 0.10。持仓更集中是这次的目的，不算行为变差；前 10% 交易的利润占比照报。

通过的候选里，有公开成绩的人取两年对数差的平均最小的，其余人取选择段收益最高的；它还要好于这一轮的基础版本（绝不带入更差的），再用 100 次安慰剂和不看未来检查复核，复核不过就看下一个。

## 仓位档的条件

- 只按整份台账的机制定义（形态、EP 质量、突破前收紧、强度），不写具体股票；条件都用入场收盘时已知的数据（`human.condition`，或研究模块的 `tier_mask`）。
- 报告每档在全部交易里触发的笔数、赚钱笔数和盈亏。
- 报数前核对头部交易：日期、成交价、当时的档位、单笔仓位和总敞口（`top`）。

## 预算与停止

每人最多 10 轮；轮次没用完、差距没定位到层（仓位、形态、排序、执行、数据）之前不停。全部是样本内结论。
