# trader_replication：逼近一位交易员的通用代码

使用说明见 [skills/trader-replication](../../skills/trader-replication/SKILL.md)，第一个例子在 [martin_luk/](../martin_luk/README.md)。只读研究，不接 custody。

| 文件 | 内容 |
|---|---|
| `ledger.py` | 交易台账 CSV 的读取、校验（日期精度 exact / chart / window）、按日期切选择段 / 验证段 |
| `fidelity.py` | 某环节的输出（天 × 股票的布尔掩码）命中台账交易的比例、同宽随机命中率、提升倍数、名单宽度、累积漏斗 |
| `edge.py` | 同一天、同一波动分组里选中 vs 没选中的同类事件的结果差（按日重抽样区间）；次日开盘起的远期收益 |
| `system.py` | 多空日 K 组合：收盘确认入场、固定风险定仓、分批（按 R / 按信号）、EMA 跟踪（分批后或回撤 / 指定市场日换另一条）、保本、信号全卖、加码（一档或多档，止损提到成本价）、次日无延续离场、新仓反馈调风险、按日风险倍数、同时持仓上限、当天盘中止损；安慰剂（同一天同一名单随机换股、同样止损宽度）。新规则都在 `Rules` 里、默认关闭 |

R77 起 `simulate` 可接收真实分钟 OHLC：`px['session']` 是交易日编号，`px['daily_close']` 标记每日最后一根，止损和分批逐根运行，日线跟踪/加码/持有期限在日末执行，融资费用每日一次。省略这些字段仍按原日线模式，R74 数值已精确复现。`px['mark']` 只用于以前一已知收盘估值，不能用作可成交 OHLC。调用者必须提供因果入场和当时可知的指标，不会自动消除输入中的未来信息。

`audit=True` 返回逐笔入场、加码、退出的时间/价格/股数。`ret` 保留除以初始名义本金的历史口径；`ret_invested` 改除以初始及加码累计投入，仅为统计补充，不改变交易或账户收益。交易接口仍不属于本模块。

R80的可选`Rules.max_new_long`按交易日统计成功新开多头，不按输入信号数统计；已有持仓、非法止损或资金不足不占名额，入场当天止损仍占一次，空头不受此参数限制。默认0不设此限制；旧调用者的信号截断仍由调用者自己决定。

R81的`arm_trail_on_entry=True`允许用入场当根已知的均线和完成收盘激活均线跟踪，次日首次跌破即可退出；不改变初始止损，缺失均线不取未来值。默认False保留旧行为。
