# WF02 预登记：同日新点名优先

本预登记在候选运行前写定。选择段为 2024、2025，比较对象固定为 v1；2026 为已反复查看的历史留出，标“留出*”，只对最终接受版本测一次。冻结段表中峰前日跨过 2025 年末的未决段从选择段分母和峰前持有中剔除，另列三段。

## 假设与输入

新出现或刚升级为领涨的扫描票值得重点观察（原话③；TRANSLATION“盯的是刚变强的票”）。当同一时点的入场争用名额时，新点名优先可能改善点到、买到、峰前仍持有之间的衔接；不能把个别股票的结果当作依据。IE47 点名、C062 执行和分配、B4_PCT2 状态日历均读冻结输入。日 K、e8_scale、手续费与资金档按任务书；策略不读段表或台账。状态只用于拆账，不控制执行。

比较对象 v1：2024/2025 峰前持有 4/7，收益 61.3095246651%/57.3668776138%，峰前仓位中位 0.10168106447651955，行为项 1。W1E 是消融参照，不是验收比较对象：峰前持有 5/8、收益 113.8979584527%/64.3556514230%、峰前仓位中位 0.1691133784745543、行为项 1。v0 master 只作报告。

## 轮前机制检验与放行

v1 与 W1E 的选择段逐笔、权益等价性通过；v1 的 STATUS 漏斗为 L0–L6：1/4/1/5/10/2/5。机制检验先于段表诊断，只读 W1E 入场簿、准入、账本和行情。全部 1,124 条入场各自以初始权益 1 单票回放，风险 0.5%、e8_scale 和 C062 管理不变，取消名额与组合约束，年末持仓按 end 标记，且逐条核对实际开仓与 R。

同日静态重排有 87 天、112 笔换入及 112 笔换出；不模拟换入后对后续日的路径影响。换入新点名单票平均 1.9827556207R，≥5R 13/112（11.6071%）；换出旧点名单票平均 1.8461367749R，≥5R 11/112（9.8214%）。两项均严格更高，C4 放行。旧点名在 W1E 的实际成交平均 1.8641240175R，≥5R 11/112，只作参考。分年：2024 新/旧单票平均 3.3315/0.3301R、≥5R 9/52 对 4/52；2025 为 0.8138/3.1601R、4/60 对 7/60。合计放行不代表每年都改善。

观察第 1–3 天的 882 条单票入场平均 1.5123468166R、≥5R 75/882（8.5034%）；第 4–5 天 242 条平均 2.5087794873R、≥5R 24/242（9.9174%）。后者两项均更高，C5 不放行，删除 W2B 及任何含 C5 的候选。

C4 的静态增量上限为 4 段：2024/2025 各 2 段；up 3、weak 1。配置要求比 v1 多 3 段，W1E 已多 2 段，尚需 1 段，所以上限允许继续。静态上限不是净增保证：C4 对 v1 和 W1E 已峰前持有段的首笔分别有 2 段和 3 段被挤出的风险。C5 未放行，不计算其可达上限；其观察期截短分别会使 v1 的 3 段和 W1E 的 4 段首笔消失。详细逐段数据和分年分状态统计见 `work/d0_diagnosis.json`。

## 组件和候选

- C2：满仓且持有至少 3 个交易日、涨幅低于 2% 时按原引擎换出最弱仓位；`rotate_below=0.02`、`rotate_min_days=3`。
- C3：每笔风险 0.005，其他 C062 执行不变。
- C4：同日同一成交时点按 `(-born, rank, code)` 排序；不改入场集合、成交价或止损。引擎只有 `make_room_kind` 开启时按位置读取该优先级，本轮该项关闭。
- C5：E6a 的 3 晚观察期，已按全账本检验删除。

| 配置 | 组件 | 用途 |
|---|---|---|
| W2A | C2 + C3 + C4 | 唯一放行的选择候选 |
| W2B | C2 + C3 + C5 | 未放行，不运行 |
| W2C | C3 + C4 | 仅当选中 W2A 需要消融时运行，不参与选择 |
| W2D | C2 + C4 | 同上 |
| W2E | C4 | 仅当删去多个无贡献组件、需要整体验证该组合时运行，不参与选择 |
| W1E | C2 + C3 | 已做等价性重放；作为去 C4 的消融参照 |

## 判定、消融与报告

只对放行的 W2A 调用 `pipeline.accept('merge', 候选, v1, cfg)`；门槛仅从 config 读取：两年不亏、每年峰前持有不低于 v1、合计多至少 3 段、峰前仓位中位不降、行为项不减，且选股不采用 master 成交额排序。若多个主候选均放行，先取峰前持有最多，与其相差不足 3 段视为并列；并列按组件较少、较差一年收益较高、编号依次取。实际本轮 W2B 未放行。

没有合格候选则记 branch，不跑留出、不建缓存，STATUS 按任务书照抄。收益更好而峰前持有或行为未通过者只记探索分支。W2A 合格时逐一去掉 C2、C3、C4，用 W2C、W2D、W1E 报峰前持有（分年、分状态）、行为项、峰前仓位中位和各年收益；四项均不变差的组件不进入最终版本。去掉多个组件后的组合须整体跑过并重判；未通过或时间不够则回退被选中的整体候选。

仅当最终版本选择段接受，才连续回放至 2026-10-16 一次，同时报告 L1、L2、L2.8 及 L2.8 pro_rata；L2.8 是验收档，其余只作对照，不用留出结果择优。若 2026 收益低于 `hard_lines.annual_return_min`，标 `holdout_loss=true`。本轮不重算选股和状态，不运行其他旧版本、参数扫描或交易测试台缓存。

逐候选报告全部准入原因相对 v1 和 W1E 的变化；对 C4 换入和推后的入场报告全账本 R 分布、胜率、≥5R、分年分状态及后来是否成交；报告每笔换仓、证实状态、之后 20 个交易日变化（不足标截断）、卖出而新仓未开的次数、满仓天数和持仓构成。缩短观察期或改变优先级不会凭空增加入场触发，但会改变实际成交，胜率、盈亏比和笔数可能离开 ±20% 而使行为项减少。总重计算墙钟不超过 60 分钟，同一时间一个进程，CPU 60%、内存 900 MB、单线程数值库。
