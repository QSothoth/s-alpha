# IE41 预登记：降方差的拟合策略

本文件在任何拟合、聚类、标签结果计数之前写入，运行后不改。唯一任务书为 `PLAN_IE41_CN.md`；以下原样固定共同设置、候选与判定。

## 共同设置（所有候选）

- 指标：v1.1 全部 117 项；h4nan 过滤；主尺子 3 新 / 晚、持有 3 晚、冷却 10 晚、窗口 −4..+2；副尺子约 4 只只报告。
- **缺失不当特征**：缺失行在该项上得 0 分（不单列一档）。
- 2024–25 拟合；挑选只用 2024–25 内部留一半年 4 折 CV；2026 只测选中者一次。
- 平滑目标 Σu：u_i = 窗口（新挑 −6..+2）内 max σ((3.5 − 有效名次) / 2)，有效名次 = 剔除冷却占用后的当晚名次；搜索 / 拟合用 Σu，挑版本仍以 CV 命中数为主。

## 候选（先原样写成 `PREREG_IE41_CN.md`，再开跑，跑完不改）

- **G1 清洗基线**：沿用现行逐项搜索；改为当晚池内分位（平均秩 / 当晚有效个数，0/1 项保持原值）后固定 3 档；档分用经验贝叶斯收缩：score = log[(h_b + κ·p_b) / (H + κ) / p_b]，κ = H / Q；最多 5 项，权重 (0, 0.5, 1, 1.5, 2, 3)。
- **G2 因子归组 + 条件 logit**：在 2024–25 池行上算 117 项的 Spearman，平均链接聚成 **12 组**；组内按与组中心相关的符号对齐后，取当晚池内分位的均值作为因子（每组一个）。以夜晚为组的条件 logit：正样本为他的目标在学习夜晚的池行（每笔权重和 1），负样本为同晚其余池行；特征为 12 个因子及其 (x − 0.5)²（允许“中间段偏好”）；L2 系数按“有效自由度约 4”的规则在预登记时一次定下，写进 PREREG，不搜。每折聚类与拟合都只用该折训练行。
- **G3 两条腿**：G2 的打分 + 0.3 × 池级“会大涨”打分。池级标签：该行次日开盘起 60 个交易日内最高涨幅 ≥ 30%，只用 60 日窗口在 2025-12-31 前结束的行（每折再限制在训练半年内）；按（股票，60 日区块）聚类去重加权；同样的 12 因子条件 logit 与 L2。护栏：他 32 笔入场的 CV 覆盖不低于 G2 减 1。
- **G4 分行情连续倾斜**：在 G2 的 12 组上，事先按流派把每组标为 M（动量 / 突破：趋势均线、涨幅与相对强弱、价格结构里的新高突破、涨幅前 50 次数、收盘位置等）或 B（整理 / 回踩：波动收敛、VCP、底部、回踩 EMA21、锚定 VWAP 底部等），其余为共同组。打分 = 共同部分 + (1 − a_t)·M + a_t·B，a_t = clip(a0 + a1·R_t, 0, 1)，R_t = 当晚 QQQ 收盘相对 EMA50 的距离（以 QQQ 自身 ADR20 为单位）。共同、M、B 内部权重沿用 G2；只在训练段估 a0、a1。行情标签置换（保持各状态夜数，夜晚间随机重排 R_t）200 次只重估 a0、a1：a1 的置换 p ≥ 0.1 时 a1 固定为 0，并写明“分行情在 2024–25 没站住”。弱势期无样本，只按这条线外推，不另编画像。
- **G5 按他的买点分名额**：3 个名额分给 breakout / pullback / ep 三个打分器，各自用 G2 的方法但最多 4 个因子、只用该 setup 的目标学习；每晚各出排名最高、尚未被选的 1 只；某打分器当晚无可选票时名额给 G2 打分。按（股票、半年）聚类自助法 30 次重估，取当晚分位均值。

## 挑选与判定

- 选中者 = CV 命中最高者；同分看 Σu，再同分按 G1→G5。
- 前进：G1 需 CV ≥ 18/28（B0 + 3）；G2–G5 需 CV ≥ 19/28（B0 + 4，差 ≤ 3 属于 28 笔四折的噪声带）；且四折里不能有 ≥ 2 折低于 B0 同折。
- 选中者另做：同预算随机 30 次（同样走四折口径）；打乱标签 5 次（新种子）完整流程；按因子组消融（2026 只报告）；按（股票）聚类自助法给 CV 的 95% 区间。

## 实现细则（先固定，不按结果挑）

- 学习夜晚保持 0、1、2；每笔可用学习行的权重和为 1。G2 主腿只学 primary；G3 第一腿原样使用 G2，不追加 secondary；32 笔只作 G3 护栏。
- 固定当晚有效值的 1 起平均秩 / 有效数；0/1 项按冻结 SPEC 的 binary 元数据保持原值。缺失不参与排名、相关性或档占比，档贡献为 0。因子为 0.5 + 各成员带符号的 (分位−0.5) 之和 / 固定组大小；缺失成员贡献 0。两种基函数均在全组缺失时贡献 0，不增加缺失指示。
- Spearman 按训练池两项共同有效行精确计算平均秩；距离 1−|ρ|，平均链接，按库顺序稳定打破同距离，直到 12 组。组中心是组内平均绝对相关最大的 medoid，符号取与该中心的相关符号（0 取正）。每折重新聚类，不用验证折或 2026。只生成 117×117 小矩阵。
- 条件 logit 使用同晚 softmax 似然，正行加上每笔归一权重、同晚其余行作为对照；不跨夜比较。两个基函数为 x−0.5 与 (x−0.5)²，不另加截距。损失为负加权条件对数似然 + λ‖β‖²/2。
- L2 一次固定规则：以该次训练样本在 β=0 的条件 Fisher 信息矩阵 I0 的非负特征值 d，解 Σ d/(d+λ)=min(4,rank(I0))。由二分解 λ（仅解方程，绝不按覆盖率、结果标签的涨跌或留出成绩挑 λ）；所有 logit 重估沿用此规则。不做 L2 网格。记录 λ 与实际零点有效自由度。
- logit 系数按规定的条件似然拟合；涉及离散搜索的 G1、G4 与 G5 因子挑选一律最大化训练 Σu，同分看命中，然后按库顺序。Σu 是带冷却的有效名次；被冷却挡住的票当晚效用为 0。G1 保留逐项加入、三轮调权/替换及删项，最多 5 项，只在 Σu 不降时删项。
- G3 标签使用次日开盘至第 60 个后续交易日的最高 high / 次日 open−1；要求 60 日均有有效 high。整个未来窗口不得越过训练半年（也不得越过 2025-12-31）。以 (股票, 日历交易轴整除60的区块) 为簇，每簇所有可用行权重和 1，正行用该权重进入同晚条件 logit。0.3 固定，护栏失败仍报告但不参与择优。
- G4 在聚类前给每个指标固定流派标签，再对组投票：trend、momentum、relative_strength 为 M；波动收敛、VCP、底部、回踩、低点/底部 AVWAP 为 B；新高、跳空、上破、收盘位置、涨幅前50次数为 M；其余共同。每组按成员票数最多者定类，同票共同优先、再 M、B。成员表写入代码和结果，不看目标标签。
- G4 R 使用缓存 QQQ 的当晚 close/EMA50−1 除以过去20晚 mean(high/low−1)。EMA 从缓存原始起点递推。QQQ 三态：close≤EMA50 为弱势；close>EMA21 且 EMA21>EMA50 为上升；其余为回调。R 只用当晚及过去数据，不做三张独立表。
- G4 从 (a0,a1)=(0.5,0) 出发，用固定步长坐标爬升（a0 初始步长0.5，a1初始步长1，逐次对半缩至1/64；a0∈[0,1]、a1∈[−2,2]），最大化训练Σu。200次在训练夜晚间置换整个 R，保持夜数和连续值多重集；只重估 a0/a1。检验统计为相对固定a1=0的最优Σu增量；p=(1+不小于观测增量次数)/201。p≥0.1时重新采用最优常数a0、a1=0。每折独立执行，种子由固定主种子加折序号得出。
- G5 每个 setup 先在训练段用贪心加入选择至多4组（每次条件logit重估后按Σu择优），再按 (股票,半年) 对该setup的目标有放回抽样30次，仅重估所选因子的系数。聚类和因子选择仅用该次折的原训练行；bootstrap不读测试行。每次预测取当晚平均秩/池数，30次取均值。顺序 breakout→pullback→ep，每腿1个尚未冷却且未被其他腿选中的名额；无票的槽位给G2。副尺子用 breakout/pullback 两槽各1个、持2晚。
- 训练优化只在训练半年重放冷却；内部CV与随机对照都用该折冻结模型、沿整条历史因果重放冷却，再只计留出半年目标。记录这一因果耦合，不把四折当作独立试验。2026行不会参与训练优化。
- 选定者的五次打乱标签（20261105411..415）重做该候选四折和全段完整流程，包括聚类、因子选择、收缩、行情置换/装袋；不重新在五候选间择优，不读取2026。置换在同半年目标可见的最近池夜晚一一置换股票，保留日期、tier、setup和缺池状态。
- 随机主种子20261105416，30次，每次对四折分别生成逐夜随机排名，并走同一冷却/窗口；另存全段随机，报告年表和副尺子。G4种子20261105417，G5种子20261105418；按股票聚类 bootstrap 2000次估CV命中95%区间（固定已冻结折外预测，不重拟合），种子20261105419。
- 2026仅对选中者正式评测一次；其余候选表填“未测”，服从任务书“2026只测选中者一次”的限制。正式预测、消融、漏票与随机均在选定和冻结之后同一报告阶段产生；消融仅报告不调参。
- 画像每项必须写偏好区间、原话、经济解释三列。因禁止读原话源资料，允许资料未含可核实直接引文时如实写“原话没有”，不拿统计偏好冒充引文。
