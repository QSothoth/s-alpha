# R27 预登记：空头

2026-10-17 写于看任何 R20–R27 结果之前，跑完不改。股票池同 R20 的选择。

## 来由（他的原话，见 RULES_CN ⑧）

最好的空头是第一次跌破 50 EMA 后第一次反抽到 50 EMA，9/21 也靠近并开始下拐；反抽到下行且收敛的均线、在当日高点设止损；空单两三天内分批了结；周线还好的不做空；12 月的教训是 QQQ 在 50 日线上方、IWM 走强时少做空。R5、R7 的空头建立在事后挑出的热门股名单上（对空头不利），在随机抽样股票上没有单独测过他的这套空头。

## 信号（第 t 天收盘确认，EMA 用 t−1）

- 共同条件：在股票池内；周线 EMA9 < 周线 EMA21（周线不好）。
- **Z1 第一次反抽 50 日线**：t−1 收盘 < EMA50，过去 30 天内至少有一天收盘 > EMA50，EMA9 < EMA21；当天最高价 ≥ EMA50 × 0.99 且收盘 < EMA50。
- **Z2 反抽到下行均线**：EMA9 < EMA21 < EMA50；当天最高价 ≥ EMA21 且收盘 < EMA9。
- **Z3 = Z1 + 市况**：股票池等权指数前一日收盘 < 其 EMA50。
- **Z4 = Z2 + 市况**：同上。
- **Z5 收紧后跌破前低 + 市况**：EMA9 < EMA21 < EMA50，前一日内包或窄幅，当天收盘 < 前一日最低价；市况同上。
- 入场 = 当天收盘卖空，止损 = 当天最高价，宽于 min(5%, 0.5 × ADR20) 不做；+3R 回补 15%；收盘站下 EMA9 后第一次收盘站回 EMA9 回补；最多持 3 个交易日；单边成本 0.05%，借券费不计（只报告其影响量级）。

## 判定

- 空头单独成组合（仓位同 R26 的选择），安慰剂 = 同一天股票池里随机换股做空、同样止损宽度，100 次。
- 选择段 2024 按“真实收益 − 安慰剂中位数”选一个；验证段 2025-01 → 2026-10：真实收益 > 安慰剂 90 分位且 R 下限 > 0 算通过；通过才并入完整系统。
- 命中率：他的 `exact` / `chart` 空头交易当天是否出现所选信号（只报告，空头笔数少）。
