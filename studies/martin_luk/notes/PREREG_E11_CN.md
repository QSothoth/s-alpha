# E11 预登记：再上车接进端到端执行

2026-11-06。接 [E10](../reports/E10_CN.md) 第 5 节：单层里最强的是“被洗后收回买价再买一次”（RE，两年 +70.9%），但它不在 E10 的端到端候选里；E10 选中的 K2（AS + X1）两年 +59.6%、2026 −10.1%。本轮只改执行层的组合方式，不加新的价格规则；唯一的新东西是 L5 允许再上车两次（原话“多次试单”，他 2025 年 940 笔）。本登记先于 E11 代码与评测；先写单测。只用日 K，不取新数据，不冻结、不提交。选股（IE47，每晚 3 只、观察 5 天）和 E8c 的其余规则（3R/5R 各卖 15%、试单半份加仓、市况减半、0.5% 满仓风险）不动。

## 候选（≤5，各层定义同 E10 预登记）

| 候选 | 组合 | 为什么测 |
|---|---|---|
| L1 | AS + X1 + RE | K2 加再上车 |
| L2 | AF + X1 + RE | 加仓保护换成单层更好的 AF |
| L3 | AF + RE（离场仍为收盘破 9EMA） | 两个最强单层，X1 单独是变差的 |
| L4 | AF + X1 | AF 替 AS 的 K2，看 AS/AF 与 X1 的配对 |
| L5 | AS + X1 + RE2 | RE2：再上车的单子若也被干净止损，10 天内再收回它的买价时再买一次；每个原始信号最多再买两次，判定与止损同 RE |

参照（不参与选择，同一次运行重算）：ref（E8c）、K2、RE。

## 选择规则（只用 2024-01-02～2025-12-31，看结果前定）

1. 资格：平仓笔数 ≥ ref 的 70%；按实际投入涨 ≥ 20% 的赢家笔数 ≥ ref 的 90%（与 E10 相同，ref = E8c）。
2. 有资格者按两年账户收益排序；与最高者差 < 2 个百分点的按 `study.gap`（行为差距，小者优先）；再按 L1→L5。
3. 无人有资格：不选，执行仍为 K2，2026 不测。
4. 选中者 2026（至 2026-10-16）只测一次，报全段；K2 2026 −10.1% 作参照。

## 照记

- 2026 已被 IE47 和 E3–E10 反复使用，作验证集的独立性很弱；2024 年之前没有共同面板数据，按规定不取新数据。2026 结果只作“没有明显变坏”的检查，不当新证据。
- RE / RE2 的判定只用原始单子的止损和价格路径（与账户是否实际成交无关），再上车当天收盘买，止损按 E6c 规则；被止损当天不再买（`no_rebuy_day`）。
- 尺子与 E10 相同（账户分年、回撤、笔数、胜率、平均赚亏、赢家 ≥20%、大涨票赚钱出来的比例、按入场种类的平均 R、他确切日期 17 笔），另报再上车单子分第一次、第二次的笔数与平均 R。

## 预期

L1 / L2 应高于 K2 和 RE 单独；若 L3 最好，说明 X1 在有再上车时多余（被洗后反正能回来）。L5 若笔数大增而平均 R 降到 0 附近，说明第二次再上车多是在走弱的票上反复挨打，照记。
