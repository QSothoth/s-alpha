## 候选（先原样写成 `PREREG_IE41_CN.md`，再开跑，跑完不改）

- **G1 清洗基线**：沿用现行逐项搜索；改为当晚池内分位（平均秩 / 当晚有效个数，0/1 项保持原值）后固定 3 档；档分用经验贝叶斯收缩：score = log[(h_b + κ·p_b) / (H + κ) / p_b]，κ = H / Q；最多 5 项，权重 (0, 0.5, 1, 1.5, 2, 3)。
- **G2 因子归组 + 条件 logit**：在 2024–25 池行上算 117 项的 Spearman，平均链接聚成 **12 组**；组内按与组中心相关的符号对齐后，取当晚池内分位的均值作为因子（每组一个）。以夜晚为组的条件 logit：正样本为他的目标在学习夜晚的池行（每笔权重和 1），负样本为同晚其余池行；特征为 12 个因子及其 (x − 0.5)²（允许“中间段偏好”）；L2 系数按“有效自由度约 4”的规则在预登记时一次定下，写进 PREREG，不搜。每折聚类与拟合都只用该折训练行。
- **G3 两条腿**：G2 的打分 + 0.3 × 池级“会大涨”打分。池级标签：该行次日开盘起 60 个交易日内最高涨幅 ≥ 30%，只用 60 日窗口在 2025-12-31 前结束的行（每折再限制在训练半年内）；按（股票，60 日区块）聚类去重加权；同样的 12 因子条件 logit 与 L2。护栏：他 32 笔入场的 CV 覆盖不低于 G2 减 1。
- **G4 分行情连续倾斜**：在 G2 的 12 组上，事先按流派把每组标为 M（动量 / 突破：趋势均线、涨幅与相对强弱、价格结构里的新高突破、涨幅前 50 次数、收盘位置等）或 B（整理 / 回踩：波动收敛、VCP、底部、回踩 EMA21、锚定 VWAP 底部等），其余为共同组。打分 = 共同部分 + (1 − a_t)·M + a_t·B，a_t = clip(a0 + a1·R_t, 0, 1)，R_t = 当晚 QQQ 收盘相对 EMA50 的距离（以 QQQ 自身 ADR20 为单位）。共同、M、B 内部权重沿用 G2；只在训练段估 a0、a1。行情标签置换（保持各状态夜数，夜晚间随机重排 R_t）200 次只重估 a0、a1：a1 的置换 p ≥ 0.1 时 a1 固定为 0，并写明“分行情在 2024–25 没站住”。弱势期无样本，只按这条线外推，不另编画像。
- **G5 按他的买点分名额**：3 个名额分给 breakout / pullback / ep 三个打分器，各自用 G2 的方法但最多 4 个因子、只用该 setup 的目标学习；每晚各出排名最高、尚未被选的 1 只；某打分器当晚无可选票时名额给 G2 打分。按（股票、半年）聚类自助法 30 次重估，取当晚分位均值。
