# R26 预登记：仓位与市况

2026-10-17 写于看任何 R20–R26 结果之前，跑完不改。信号、入场、离场 = R23–R25 的选择（未通过的环节用参照）。

## 来由（他的原话，见 RULES_CN ⑦）

每笔风险约 0.5%，单只 25%–30%，最大约 280% 多头；新仓顺利才继续加、连续亏损时降风险；最看重自己新仓的反馈，其次看指数是否在均线上方；领涨名单只数越来越少就是市况变差。R1 的 C4/C5（股票池等权指数在 EMA21 上方、回撤 10% 风险减半）在 R1 的日 K 版本上没有通过；本轮在新信号上比较。

## 候选

- **S0（参照）**：0.5% 风险、单只 ≤ 30%、总 ≤ 200%。
- **S1 比赛上限**：同 S0，总仓位上限 280%（超出权益的部分按年 7% 计息）。
- **S2 按反馈调风险**：最近 10 笔已平仓交易的 R 之和 < 0 时每笔风险降到 0.25%，否则 0.5%。
- **S3 指数过滤**：股票池等权指数前一日收盘在其 EMA21 上方才开新多仓。
- **S4 名单宽度过滤**：前一日“W* ∧ 日线领涨”只数不低于其过去 50 天中位数才开新多仓。

## 判定

与 R25 相同（全市场美股日 K，安慰剂 100 次，选择段 2024 按真实 − 安慰剂中位数，验证段真实 > 安慰剂 90 分位且 R 下限 > 0）。另报最大回撤与收益 / 回撤比。
