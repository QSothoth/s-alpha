# IE24 预登记：组合模型与公式演化，固定池内前五覆盖

本登记先于 IE24 的搜索及覆盖计算。唯一任务书为 `PLAN_IE24_CN.md`，运行中不修改任务书和本登记。IE23 全部文件只读，优先读取 `ie24_work/ie23_ranks.npy` 与 `ie23_prepared.json`。不读取规则、访谈、字幕、台账 setup 或备注；既有评价缓存仅提供记录标识、股票、入场日、主次目标和四个评价夜晚。解释在结果后写，不参与选择。

## 固定输入、评分和隔离

- 复用 IE9 四条过滤、全部 51 笔主目标和四晚任一命中。报前 1/3/5/10、主目标和全部 81 笔入场。IE9、IE23 的冻结 JSON 作为对照，不重新选择。
- 模型输入为 IE23 的 5543 列池内百分位，缺失补 0.5。因子矩阵列连续，以只读 memmap 按 64 列读取；不复制整矩阵。
- 训练接口只接收训练半年主目标的行号、半年和有效夜晚，不接收留出标签。半年取任务书固定的六段。训练仅使用所属半年内的信号夜晚；另将每个未参与训练半年第一个市场交易日前四个交易日晚从训练中剔除。这个隔离由市场日历和半年边界决定，不查看留出目标在哪些夜晚出现。
- 每笔先对剩下的有效夜晚等权，再按笔、按半年等权。softmax 只在有有效目标的训练半年上，对各半年有效笔等权；没有有效夜晚的笔无可优化项，覆盖分母仍保留。公式适应度对无有效夜晚的笔记中性 0.5，再按全部笔、半年等权。
- 同分名次沿用原池行顺序。股票身份只用于对齐缓存和评分，公式和模型不接收代码、记录标识或日期作为数值输入。

## A：模型搜索

复用 `ie_factor_models.py` 的组内 softmax 梯度、深度二树拟合和预测；在 IE24 内提供权重和训练接口，不修改原模块。

1. 每个训练集合从全部 5543 列重新预筛。零分数 softmax 下，分别按绝对梯度、四分位三处分裂的最大二阶增益排序，各取前 64 列，合并最多 128 列；平手按原列号。预筛只用训练目标及其同晚池内股票。公式列不参加此预筛，B 独立搜索。
2. 条件 logit 用前向选择：从零分数开始，按当前绝对 softmax 梯度加入一个尚未选中的列，重新拟合已选列，最多 10 列。每次重拟合用 50 次 Newton 步、固定 L2 0.01 稳定项，Hessian 为各晚加权 softmax 协方差；步长回溯至损失不升。这仍是最多十列的前向条件 logit，不是全部列的稠密模型。复杂度档为 1、3、5、10 列，按一次路径取快照。
3. 提升树固定深度 2、四分位分箱、每叶至少 20 个池内行、学习率 0.1、叶正则 0.01；轮数为 20、40、60，按一次路径取快照。损失为相同加权组内 softmax。
4. 在外层五个训练半年内部再留一半年，每个内部训练集合重做预筛和拟合。选择先比较五个内部验证半年前五覆盖的最小比例，再比各半年比例均值，平手依次取实际使用列少、树少、logit 优先、登记档次先出现者。A 的模型家族也在此内部选择，不看外层标签。分别保存 logit、树及 A 所选版本的结果。

## B：只用 numpy 的遗传公式搜索

- 终端：缓存 `o,h,l,c,v,t`（成交额）、QQQ 收盘、IV、HV、期权总量/认购量/认沽量、期权总未平仓/认购未平仓/认沽未平仓。不使用原有人为 H4、同伙、财报或股票身份列。只加载当前固定池涉及的 300 只股票、951 个缓存交易日，按股读取，内存规模有界；缓存缺失保持 NaN。
- 二元运算：加、减、乘、保护除（也就是比值）；一元运算：取负、差分、滞后、滚动均值/最高/最低/标准差、EMA、ADR 归一化、自身过去 250 日平均秩、当晚固定池平均秩。带窗口运算的窗口只取 1、2、3、5、10、20、50、100、250。差分为 `x-lag(x,w)`；ADR 归一化为 `x / mean(h/l-1,20)`；不是依照解释手写候选公式。
- 每个终端和运算均计一个零件，最多 7 个、运算深度至多 3（终端深度 0）。保护除在分母绝对值不超过 1e-12 时记缺失；中间有限值截在 ±1e12 防溢出。滚动包含当晚，至少一个有限值；EMA 从首个有限值起，缺失日不更新。history250 包含当晚，有限值平均秩，单值 0.5。当晚池内排位仅对实际在固定池内的股票计算，池外为 NaN；后续时间算子仍只读当前和过去。最终输出统一再转当晚池内百分位，缺失中性 0.5。
- 种群 50，20 代，每代最多 50 个有效且不同的候选；初始含所有终端，其余随机长树。锦标赛 3，保留最好 5 个；交叉 0.6、子树变异 0.3、复制 0.1，超出尺寸/深度的后代丢弃重抽。每代最多尝试 1000 个后代，不足时保留实际多样种群，不放松阈值。
- 适应度为训练各半年目标的笔均有效夜晚池内百分位的最小值，减 `0.002 × 零件数`。平手按零件少、公式字符串排序。负方向必须由公式的取负或减法表达，同样计复杂度。
- 每代按适应度从高到低，利用训练半年全部池内行的最终百分位做 Spearman 相关去重，严格大于 0.7 的后选公式丢弃；不取绝对相关，常数只保留一个。用逐个代表比较，不构造大相关矩阵。最后保留最多 5 个不同公式。
- B 档次为前 1、3、5 个公式等权平均，不足档次的候选不可用。每个内部四半年训练集合都从初始种群重跑搜索，再评内部留出半年，按最差覆盖、平均覆盖、公式少依次选档。外层五半年重新完整搜索，并采用内部选定档次；不足时用不超过所选档次的全部可用公式。
- 搜索 RNG 为固定基础种子 2026112400 加训练半年集合的确定性位掩码；各打乱标签版本采用相同随机起点，之后演化完全由各自训练适应度驱动。可以跨折复用不含标签的原始行情和因果公式值，不能复用另一训练集合搜出的公式、适应度、种群或模型。相同训练集合及相同标签版本在不同内部位置出现时，只复用该完整搜索的存盘结果；这是相同算法的共同子问题，不使用更多标签。

## 嵌套流程、组合和对照

- 六个半年依次外层留出。每折只把另外五个半年的标签传给完整 A、B 选择流程；内部每个半年只用其余四半年从头搜索。固定外层 A、B 后，AB 为二者当晚池内百分位等权平均，不再调权重。A、B、AB 各只评本折外层半年一次，保存完整模型、训练和内部记录、冻结摘要、全部夜晚排名和逐笔名次。
- 打乱种子 2026112401…2026112405，按每晚池内共享置换目标，保持过滤外损失及重复标签映射；每个种子从预筛、公式演化、内部选择到六个外层评测完整重跑。真实各方法须严格超过五次打乱中 A/B/AB 的最大合计，避免在三个方法之间择优造成较宽松的比较；同时列逐方法对照。
- 同池随机种子 2026112430…2026112459，30 次独立每晚随机排列，报各半年前五覆盖的真实排位、并列数、均值及范围。
- 通过线不变：主目标前五至少 26/51，且每半年至少 25%，并过完整打乱对照；账户最后只作否决。通过者中取留出合计最高，再取使用列/公式较少，再按 A、B、AB。没有通过者就如实报告，不用收益或全段拟合回选。
- 每半年 80% 的逐笔缺口为 `max(0,ceil(0.8*n)-hit)`；同时列固定池可达上限。2025H2 池最多保留 10/13，达 80% 需 11 笔，保留这个结构性缺口，不改池或分母。

## 最终版本、删除诊断和解释

- 用全部六半年走相同内部选择流程，得到 A/B/AB 单一最终版本。正式成绩始终使用外层各折冻结预测；全段模型是拟合版，不能替代正式留出。
- 对每个最终版本逐项删已选列/公式。固定最终选择的超参和列/公式身份，按六个半年分别重拟合其他五半年（B 的固定公式无参数），汇总留出前五；删后合计不降即删，按当前列/公式顺序，接受后从头开始，直到没有可删项。logit 删除后在剩余列上重拟合；树删除后只用剩余列重建相同轮数。AB 同样逐项试删两侧，任一侧空时仅剩另一侧，双方空时全零同分。保存所有前后半年表。
- 此删除诊断的身份先用全段标签选出，带选择偏差，明确标成最终精简诊断。它不改外层正式模型、真实或打乱成绩。
- 对每个最终留下的项列出完整表达式、事后市场含义、删项改善的半年、至少 3 个命中和 3 个仍漏例（不足就全部列出）。报告可展示票名/入场日，代码不写字面名单或日期。列全部外层各折所选特征/公式和重合度；不同折不同就报未找到稳定特征。
