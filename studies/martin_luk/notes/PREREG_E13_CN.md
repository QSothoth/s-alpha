# E13 预登记：风险按行情被证实的程度分配

2026-11-06，任何 E13 结果和冒烟测试之前定稿。第 2–4 节逐字沿用唯一任务书。

## 2. 方案：一个统一机制

**风险按这段行情被证实的程度分配**：未证实时小仓试错、止损放在证伪点；证实后用浮盈往上加，整只票的总风险始终不超过最初一份。选股（IE47）和入场信号（E6c 收盘越过前高，观察 5 天）不动；其余同 K2（E8c 市况减半、3R/5R 各卖 15%、X1：9EMA 下方 1% 盘中跟踪止损，成交日后第一个收在 9EMA 上方时武装）。

记号：w = K2 的止损宽度（`capped_stop` 给出的 收盘 − 止损，≤ min(5%, ADR/2)）；一份风险 U = 0.5% 权益 × E8c 市况系数（同 K2）。

### S 试单（小仓 + 收盘止损）

- 入场同 K2（收盘价）。证伪价 L0 = K2 的止损价（突破日低点，受上限）。
- 成交后、被证实之前：**只有收盘价 < L0 才在该收盘离场**；盘中与开盘只认硬止损 H = 成交价 − 2w（开盘 ≤ H 按开盘价，盘中最低 ≤ H 按 H）。入场当天不判任何止损。
- 股数按硬止损算：试单在 H 处的亏损 = 0.5U（即 K2 试单在其止损处的同一亏损）。
- 现有引擎字段 `close_stop_days` / `hard_stop_mult` 是“前 N 天”的语义；本轮要的是“证实之前”。如需新字段，加在 `Rules` 里、默认关闭、写单测，不改动任何现有字段的默认行为（其他交易员的结果必须逐位不变，跑 `studies/trader_replication/tests` 全量验证）。

### P 证实与加仓（保证主升浪期间的仓位）

- **证实**：第一次收盘 > 成交价（不含成交当天）。此时加仓，使持仓达到 K2 满仓股数（K2：试单 + 同股数加仓 = 2 × K2 试单股数），止损改为常规：盘中止损 = max(L0, 使整只票在止损处总亏损 ≤ 1U 的价格)；之后 S 的收盘止损规则不再适用。若该价格 ≥ 当日收盘（总风险压不进 1U），本次不加仓，保持试单与 S 规则。
- **再加仓**（最多 2 次，已证实后、不在成交当天和证实当天）：收盘 ≥ 此前 20 个交易日最高收盘价（不含当天），或当天最低 ≤ 9EMA 且收盘 > 9EMA 且收盘 > 前一日最高；每次加 K2 试单股数，止损上移到使整只票在止损处总亏损 ≤ 1U 的价格（只上移不下移）；压不进 1U 就不加。单只上限 30% 权益，总敞口上限同 K2。
- 离场同 K2 的 X1 跟踪与 3R/5R 减仓（R 以初始 w 计）。

### T 同一段行情内再试（最多 3 次）

- 一次试单在证实之前被 S 规则止损出局后，若之后 20 个交易日内（从第一次试单成交日算）某天收盘 > 前一日最高价，且当天收盘 > 21EMA、21EMA > 50EMA、21EMA 高于 5 天前，则在该收盘再开一笔试单（S 规则、新的 L0 与 w 按当天重新计算）。每个原始观察最多 3 笔试单（含第一笔）。
- 再试由价格路径决定（按 S 规则的收盘止损与硬止损判定出局），与账户是否实际成交无关（同 E10 的 RE）；出局当天不再买（`no_rebuy_day`）。

## 3. 候选（≤5，只用 2024-01-02～2025-12-31 选择）

**选择规则**（看结果前定，写进预登记后不改）：
1. 资格：2024 与 2025 账户收益**都**不低于 K2 的同年值（+39.0%、+14.8%）。
2. 有资格者取 min(2024, 2025) 最高者；差 < 2 个百分点取第 4 节尺子①（他 36 段在行情中点时持仓的段数）多者；再按 F1→F5。
3. 无人有资格：不选，2026 不测，照记差在哪。
4. 选中者 2026（至 2026-10-16）只测一次，同时报 K2 2026（−10.1%）。

## 4. 尺子（每个配置都报，分年）

主升浪只用于**评估**，可以用未来价格划定，但任何规则不得读取它：
- 他的段：同 leg_position.py（他 2024–25 年多头，峰值 = 他日期后 60 个交易日内最高价，起点 = 峰值前 60 个交易日内最低价，涨幅 ≥ 50%，同一只同一峰值合并）。
- 池内段（防止只拟合他的 36 段）：IE47 每晚选中的票，峰值 = 选中后 60 个交易日内最高价，起点 = 峰值前 60 个交易日内最低价，涨幅 ≥ 50%，同一只同一峰值合并。

报：
1. **两类段各自：行情到达中点（起点 + 一半涨幅，第一次收盘达到）那天，我们持有该票的段数、持仓占权益的中位与均值**；到达 1/3 处同样报。
2. 每段的试单次数、试单累计亏损（以 U 计），首笔与最后一次进场的位置。
3. 账户：分年收益、回撤、笔数、胜率、平均赚/亏（按实际投入）、赢家 ≥20% 笔数、R 分布（未证实 / 已证实分开）、平均敞口、融资利息。
4. 他确切日期 17 笔买到几笔（同 E10 `his_exact`），只报告。


## 实现口径（看结果前固定）

- 仅执行任务书 E13，不增加候选、门槛或调参轮次。参照 K2 完全复用 E10 的 `rule_layers`；2024–2025 连续账户按年切收益，交易统计按入场年份分组，未平仓的 `end` 行只估值、不算已平仓。中点与 1/3 当日按收盘管理和成交后的持仓量 / 当日权益计；零仓位计入全部段的均值、中位数，同时列持有段内的条件均值、中位数。段按锚定日（他的日期 / 选中夜）年份分组；同票同峰值跨年合并时归最早锚定年。
- 硬止损只改变证实前的盘中止损与初始股数，初始 w、3R/5R 的 R 仍取 K2 的 w。3R/5R 各减初始试单股数的 15%，继承 K2 引擎口径。S 期间的收盘证伪价固定为 L0，硬止损固定为成交价减硬止损倍数乘 w；X1 可武装，但其止损在证实后才生效。证实后不再适用 S。
- K2 试单目标股数按首次成交权益、该日 E8c 系数、0.5U/w 计算，受当时 K2 单只 25% 和总敞口空间约束并固定；P 首次目标为其两倍，后续每次增加该 K2 试单股数。候选受单只 30%、总敞口 280% 及其余 K2 账户限制，空间不足时只加可容纳部分；没有最小成交空间则本次不加、保持原状态。证实加仓失败可在后续收盘仍高于原成交价时再尝试。再加仓仅成功成交计次，最多两次。
- 1U 固定为该笔试单初始成交权益 × 0.5% × 初始 E8c 系数，不随之后权益、系数改变。风险止损计入该票累计现金流、已实现减仓盈亏和买卖费用：新增后现金流 C、剩余股数 Q 时，所需止损为 (-U-C)/(Q×(1-卖出费率))；实际止损取该价、L0、此前止损的最大值。止损价不低于收盘就不加；跳空成交可使实际亏损超过计划风险，要如实报告。
- F4 保留 S 的小股数，第一次合格的后续盈利收盘按 K2 的“加与初始试单相同股数”加一次、止损取此前止损与加仓日低点较大者；不使用 P 的放大目标、风险止损和再加仓。成功加仓后进入已证实状态。
- T 对每个原始观察独立重放价格路径，不读取账户成交/拒绝。每次试单入场当天不判止损；后续先判开盘硬止损、盘中硬止损、收盘证伪，再判盈利收盘证实；已证实的路径终止再试。F2 路径按 K2 的常规止损和 X1 武装/上移判定。第一次试单成交日 b 后的 b+1..b+20（含第 20 个后续交易日）内最多三次；出局当日不再买。再试条件及止损重新按当天、ADR 前一天计算。重复被选中的新观察保留独立身份；账户不重复持有同票。
- 两类段均用任务书的未来峰值、低点，仅在评估阶段构造，不进入入场簿、再试簿、信号数组或引擎。每段逐笔列试单次数、所有亏损试单的累计亏损/U、首笔与最后入场位置，同时保留“未证实试单亏损/U”单列。2024–2025 的段允许使用既有 2026 价格确定未来峰值，但绝不查看任何候选的 2026 账户结果；若无人合格，2026 不测。
- 合成数据只用于单测。冒烟只能 2024-01～02。正式 train 和 validate 各用排他创建的开始标记阻止重复；崩溃只允许核查后续接尚未完成的工件，不重选、不覆盖既有结果。
