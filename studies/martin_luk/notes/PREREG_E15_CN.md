# E15 预登记：有效方向全组合与证实后仓位

2026-11-06，单测、实现、冒烟及任何 E15 结果之前定稿。

## 2. 全组合（7 个因子，各 2 档，共 128 个配置）

其余同 E14 的 W（IE47 选股、E6c 入场、E8c 市况、3R/5R 各卖 15%、1U 只作上限、单只 30% 上限、总敞口同 K2）。各档定义沿用 E14 预登记的同名做法，不改阈值。

| 因子 | 档 0 | 档 1 |
|---|---|---|
| S 试单 | W：0.5U 按 2w 硬止损定股数，证实前只看收盘跌破 L0 | SK：K2 试单（K2 股数与止损） |
| T 同段再试 | 有（W：20 天内最多 3 笔） | 无（T0） |
| C 证实后止损 | 证实当天最低价（W） | 原成交价（CF） |
| A 再加仓 | 回踩 9EMA 收回（AE，最多 2 次） | 不再加（A0） |
| H 离场 | 证实后即改收盘跌破 21EMA（H21A） | 至少再加仓 1 次或浮盈 ≥5R 后才改 21EMA，之前用 X1（H21） |
| Z 证实后仓位 | K2 满仓（2 × K2 试单股数） | **加大：4 × K2 试单股数，单只上限放到 50% 权益**（仍受 1U 上限约束） |
| M 回撤刹车 | 无 | 权益距高点 ≥20% 时新开仓风险减半（MD） |

另跑参照 K2（应逐位等于 E10/E11/E13/E14 的 K2）。128 个配置顺序跑，每个跑完立即写部分结果，可断点续跑。

## 3. 尺子（每个配置都报）

1. 账户：2024、2025、两年收益，回撤，笔数，胜率，平均赚 / 亏（按实际投入），赢家 ≥20% 笔数，平均敞口，融资利息。
2. **周 / 月尺度**（用户要求）：月收益的中位、正收益月份占比、最差月、最好月；周收益的正收益周占比、最差周；与 K2 同口径对比。
3. 利润来源：未证实试单合计 U、已证实合计 U；已证实阶段占总盈利的比例。
4. 主升浪：他的段和池内段在中点、1/3 处的持仓段数与仓位（同 E13/E14）。
5. 他确切日期 17 笔买到几笔（只报告）。

## 4. 选择（看结果前定）

1. 资格：2024 与 2025 收益**都**不低于 K2 同年（+39.0%、+14.8%），且两年最大回撤 ≤ 50%。
2. 有资格者取 min(2024, 2025) 最高；差 < 2 个百分点取“他的段在中点持仓的段数”多者；再取配置编号小者（按上表因子档位二进制编号）。
3. 稳健性只报告、不进选择：选中配置的 7 个“只翻一个因子”的邻居，它们 min(2024, 2025) 的中位和最小值。
4. 无人有资格：不选、2026 不测；报告列出 min-year 前 10 名、每个因子的主效应（该因子档 1 减档 0，在其余 64 组上的 min-year 差的中位）和两两交互最强的 5 对。
5. 选中者 2026（至 2026-10-16）只测一次，同时报 K2 2026（−10.1%）、全段、2026 的月尺度表现。

无论是否有人合格，都报每个因子的主效应和最强交互（这是本轮最重要的信息：哪些方向值得保留）。

## 执行口径（任何 E15 结果之前固定）

- **用户批准的例外：128 个组合全部参加选择**。该批准来自唯一任务书第 1 节；本轮不增加候选、不改档位、不调门槛。其余纪律照旧。
- 因子顺序固定 S,T,C,A,H,Z,M，S 为最高位、M 为最低位；配置编号 C000–C127 等于七位二进制的十进制值。全档 0 为 C000，全档 1 为 C127。H 的 0 档为 H21A，1 档为 H21；A 的 0 档为 AE，1 档为 A0。K2 只作参照，不参加组合选择。
- 沿用 E14 修正后的 float64 股数计算、费用、融资利息、连续账户、按入场年归类已平仓交易、固定 U、真实买卖现金流和主升浪定义。结构止损只上移；1U 为上限，先按结构止损反解可加股数，再同时受总敞口和单只上限约束。Z1 的试单仍沿用 Z0 的试单，只有证实与后续加仓单只上限变为 50%；证实目标为 4 份 K2 试单股数，每次后续加仓仍为 1 份。Z0 单只上限 30%。
- S、T、C、A、H、M 各档严格映射 E14 同名做法。证实指首次实际加仓成功；无空间或已超风险上限则保持试单。H21/H21A 从切换后下一交易日起生效；收盘离场优先，不能同日加仓再离场。MD 只用前一日收盘权益和截至该日高点，回撤恰好 20% 也减半，只影响新开仓风险。
- 年度门槛用本次重算、未四舍五入的 K2 同年值；两年最大回撤限制为含初始权益 1 的 2024–25 连续账户回撤。合格者先找最高 min-year，再在距此最高值严格小于 0.02 的集合内按他的段中点持有段数、配置编号选择。无人合格不选、不测 2026；用于审计和详细展示的第一名按 min-year 降序、编号升序确定，诊断展示不等于采用。
- 因子主效应是固定其余六档的 64 个 min-year 配对差（档 1−档 0）的中位；两因子交互是固定其余五档的 32 个差中差 y11−y10−y01+y00 的中位，按中位的绝对值降序取前 5 对，并列按因子表顺序。另存完整配对分布摘要；不据此重选或生成新候选。稳健性只报告选中者七个一位邻居的 min-year 中位与最小值。
- 周收益按 ISO 年周、月收益按自然年月，用各期最后收盘权益 / 上期最后收盘权益−1；第一期以初始权益 1 作分母。区间首末不完整期保留并标明；年度周/月分布使用同一连续账户中归属于该年的交易日计算，年初基准为上一年最后权益。2026 单段重置为 1，另跑 2024 至 2026-10-16 连续全段；不把 2026 称为独立样本外。
- 利润来源先保留 E14 的已平仓交易分组：从未实际证实、曾实际证实的完整现金流分别除该笔固定 U。另按真实阶段拆分：首次成功证实加仓前，以该笔当时持股按证实收盘价标记的累计现金流为试单阶段损益；之后的剩余完整现金流为证实阶段损益（证实加仓费用归后段）。从未证实者全额归试单阶段。阶段损益之和逐笔等于已平仓交易净损益，已证实阶段占总盈利比例 = 后段净损益 / 全部已平仓交易净损益；分母为零记空，净亏损时不称盈利比例，比例可因前段亏损超过 100%。融资利息单列、不混入交易现金流；期末未平仓仅估值，不算已实现。
