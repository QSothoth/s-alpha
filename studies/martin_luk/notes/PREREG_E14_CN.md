# E14 预登记：执行层多方向诊断、自动组合与一次验证

2026-11-06，单测、实现、冒烟和任何 E14 结果之前定稿。

## 2. 基底 W（修正后的完整版）

选股 IE47、入场 E6c 收盘越过前高、E8c 市况系数、X1 跟踪（9EMA 下方 1% 盘中止损，成交日后第一个收在 9EMA 上方时武装）、3R/5R 各卖 15% 不变。记号同 E13：w = K2 止损宽度，L0 = K2 止损价，U = 一份风险。

| 环节 | W 的做法 |
|---|---|
| S 试单 | 0.5U 按硬止损 H = 成交价 − 2w 定股数；证实前只在收盘 < L0 离场，盘中 / 开盘只认 H；入场当天不判止损 |
| C 证实后止损 | 证实（第一次收盘 > 成交价，不含成交当天）时加仓；之后整只票止损 = max(L0, 证实当天最低价)。**1U 只作上限**：若该止损处总亏损 > 1U，就减少加仓股数到总亏损 = 1U；减到 0 仍超就不加仓、保持试单状态 |
| Z 证实目标 | 加到 K2 满仓股数（2 × K2 试单股数），受上面 1U 上限约束 |
| A 再加仓 | 证实后最多 2 次：收盘 ≥ 此前 20 日最高收盘（不含当天）；每次加 1 份 K2 试单股数；止损上移到加仓当天最低价（只上移）；受 1U 上限与单只 30% 上限约束，装不下就减股数 |
| T 再试 | 证实前被 S 规则止损后，20 个交易日内（从首笔成交日算）出现收盘 > 前一日最高、收盘 > 21EMA > 50EMA、21EMA 高于 5 天前，就再开一笔试单；每个观察最多 3 笔 |
| H 拿住 | X1 + 3R/5R 各卖 15%（同 K2） |
| M 仓位与市况 | E8c 市况系数（同 K2） |

## 3. 第一步：单环节替换（全部在 2024-01-02～2025-12-31 跑，只诊断）

每行只把 W 的一个环节换成该做法，其余保持 W。阈值都是常见整数，不调。

| 环节 | 替换做法（代号） |
|---|---|
| S | S15：硬止损 1.5w；S30：硬止损 3w；SK：K2 试单（K2 股数、K2 止损，无收盘证伪）；SC2：收盘证伪只在前 2 个交易日，之后恢复 L0 盘中止损（股数仍按 2w 硬止损） |
| C | CF：证实后止损 = 原成交价；CU：E13 原做法（止损放在总亏 1U 价位，诊断用） |
| Z | Z15：证实目标 1.5 × K2 满仓；Z075：0.75 × K2 满仓 |
| A | A0：不再加仓；AE：再加仓条件改为“当天最低 ≤ 9EMA 且收盘 > 9EMA 且收盘 > 前一日最高”；AR：在 +2R、+4R（R 以初始 w 计）各加一次（引擎 `add_levels` 语义）；A4：20 日最高收盘条件，最多 4 次 |
| T | T0：不再试；T2：最多 2 笔、10 个交易日内；T5：最多 5 笔、30 个交易日内 |
| H | H21：已证实且加过至少 1 次再加仓后（或浮盈 ≥ 5R 后），跟踪改为收盘跌破 21EMA 离场；H21A：证实后即改为收盘跌破 21EMA；HN：不做 3R/5R 减仓 |
| M | M0：去掉 E8c 市况系数；MD：权益距高点回撤 ≥ 20% 时新开仓风险减半（引擎 `dd_risk`） |

共 20 个替换 + W + 参照 K2。每个都报 E13 的全部尺子（分年账户、回撤、笔数、胜率、平均赚亏、赢家 ≥20%、他的段和池内段在中点 / 1/3 处的持仓、每段试单、未证实 / 已证实 R 分布与按 U 计的合计、他确切日期 17 笔）。

## 4. 第二步：自动组合（规则看结果前定）

1. 对每个环节，在“W 的做法 + 该环节的全部替换”里取 min(2024 收益, 2025 收益) 最高者；与 W 的做法相差 < 2 个百分点时保留 W 的做法。
2. 把各环节选出的做法组合成 **W\***。
3. 记录每个环节的第二名（min-year 次高）及它与第一名的差距。

## 5. 第三步：端到端候选（≤5）与选择

| 候选 | 定义 |
|---|---|
| G1 | W\* |
| G2 | W（基底，检验组合是否真的更好） |
| G3–G5 | W\* 中，把“第一名与第二名差距最小”的三个环节分别换成各自的第二名（检验环节间牵连） |

若 W\* 与 W 相同，G1 = W，G2 改为“各环节第二名中差距最小者”的替换，依次顺延，保证 5 个候选互不相同。

**选择**：
1. 资格：2024 与 2025 收益**都**不低于 K2 同年（+39.0%、+14.8%）。
2. 有资格者取 min(2024, 2025) 最高；差 < 2 个百分点取“他的段在中点持仓的段数”多者；再按 G1→G5。
3. 无人有资格：不选、2026 不测；报告写清最好的是哪个、差在哪年哪层。
4. 选中者 2026（至 2026-10-16）只测一次，同时报 K2 2026（−10.1%）与全段。

## 执行口径（任何 E14 结果之前固定）

- 以上第 2–5 节逐字复制唯一任务书。20 个替换只诊断，不按单项资格直接选用；最终候选最多五个，按任务书自动生成，不手选、不增加搜索轮次。单环节比较使用重算 K2 未四舍五入的同年值作年度门槛。
- 继续 E13 的连续账户、费用、融资利息、段定义、删失、按入场年归类交易、固定 U 与完整买卖现金流口径。3R/5R 各减最初实际试单股数的 15%。T5 的第 4、5 次试单也完整记入分布。
- C 的结构止损与已生效的 X1 保护止损取较高者，已有保护止损不下移；新增股数由该止损处整笔现金流亏损 ≤ 1U 反解，计入全部买卖费用与已经减仓的现金流。股数、单只 30% 与总敞口空间同时取较小者；无可成交空间或剩余试单本身已超 1U，保持原状态。证实成功的定义继续是实际加仓成功；失败可在以后盈利收盘重试。CF 只换证实的结构止损为原成交价；CU 只换证实为 E13 的预算价，后续 A 仍按 W 的当天低点。
- Z 改第一次证实的总股数目标（2×K2试单股数为满仓），不改后续每次增加一份 K2 试单股数。AR 在证实后使用 add_levels=(2,4)，每天最多消费一个级别；即便无空间成交也消费该级别，继承引擎 add_levels 语义；单次股数和当天低点止损仍同 W。A0 不影响首次证实，A4 仅增加成功再加仓次数上限。
- SC2 前两个后续交易日用 S，第三日起恢复常规盘中止损（不低于 L0；X1 武装后仍只上移）；初始股数依然按 2w。SK 不使用 S 的宽硬止损和收盘证伪。T 的价格路径按对应 S/SC2/SK 重放，不读账户接受或拒绝；T2/T5 的期限均从首次成交算，含最后一天。
- H21/H21A 切换从触发日的下一交易日起生效：之后不再随 9EMA 抬高止损，保留已经生效的保护止损，已武装的 21EMA 严格收盘跌破离场。H21 在证实后成功再加仓至少一次，或收盘浮盈 ≥5 个初始 w 时切换；H21A 实际证实当日触发。HN 仅移除 3R/5R 减仓。MD 含恰好回撤 20%，仅用前一日收盘权益和截至该日的高水位，新开仓 U 与试单风险一并减半，已经固定的 U 不变。
- 环节顺序固定 S,C,Z,A,T,H,M，环节内并列按任务书列序，W 列第一。先按 min-year 原始收益排序，再应用“最佳替换较 W 改善 <2 个百分点则保留 W”；第二名指该环节在保留项以外分数最高的做法。报告同时保存原始排名、应用 W 回退后的第一/第二名和有符号分差（若 W 因回退保留而次名略优，分差为负）。候选互换按差距从小到大、环节固定顺序打破并列；跳过已出现的完整配置，顺延其余环节，直至恰好五个唯一候选。G1=W*、G2=W；两者相同时 G2 起顺延最小差距的第二名替换。
