# R19 预登记：用他的真实交易给现有流程打分（基线，只测量不选择）

2026-10-17 写于看任何 R19 结果之前，跑完不改。

## 来由

R1–R18 只看收益，没有检查我们的流程是否在做他做的事。用户要求收集他公开过的真实交易，检验流程能否选中他买的股票、在他买的那几天发出信号。台账 [trades.csv](trades.csv)，规则原话 [RULES_CN](RULES_CN.md)。

## 台账与分段（固定）

- 来源：两场 TraderLion 访谈的逐笔复盘（2024、2025 年）、他 2025-11-25 直播里的 10 月交易回顾、他本人 YouTube 频道 2025-11 → 2026-10 的每日直播（字幕下载后逐场整理，整理完冻结台账再跑 R20 起的检验）。
- 日期精度：`exact`（他自己说的日期、只在某一天出现的成交价、选举 / 公告这类事件日、直播当天）、`chart`（按他对图形的描述在日 K 上对出的日子，窗口前后各留 1–3 天）、`window`（只知道一段时间）。
- **选择段 = 窗口起点早于 2026-04-01 的交易，验证段 = 2026-04-01 及以后的交易。** 各轮只用选择段的交易挑方案；验证段交易只在每轮选定方案后评一次。
- 本轮只用选择段。

## 流程各环节（与 R11/R17 现有最好版本一致）

| 环节 | 定义（第 t 天，除形态外只用 t−1 收盘及以前的数据） |
|---|---|
| P0 有数据 | 当天有日 K |
| P1 可交易池 | 收盘 ≥ 5 美元、20 日均成交额 ≥ 2000 万美元、ADR20 ≥ 4% |
| P2 强度名单 W2 | 过去 20 天内某一天在 21/63/126 日涨幅中至少两张榜进前 2%（排名池：收盘 ≥ 1 美元、成交额 ≥ 200 万美元） |
| P3 趋势 | EMA9 > EMA21 > EMA50 |
| P4 形态（收盘确认，R17 的 G1） | 当天下探前一日 EMA9 / EMA21 后收回，或前一日内包 / 窄幅、当天收盘越过前一日高点 |
| P4′ 形态（盘中触发，只报告） | 前一日内包 / 窄幅且当天最高价越过前一日高点；或当天最低价触及前一日 EMA9 / EMA21 且收盘在其上方；或当天跳空 ≥ 10% |

## 指标（之后各轮沿用）

- **命中率**：台账交易在其窗口内被该环节（累积到该环节）选中的比例；P0–P3 用全部选择段交易，P4/P4′ 只用 `exact` + `chart`。
- **同宽随机命中率**：每天从可交易池随机抽同样多只，窗口内至少抽中一次的概率的平均；**提升倍数** = 命中率 ÷ 同宽随机命中率。
- 每天入选只数（中位数、平均）。
- 每笔被丢在哪一环、当时的特征（价格、成交额、ADR、1/3/6 月涨幅在全市场的百分位、相对 EMA 的位置、当天跳空与涨幅）。

## 判定

本轮不选方案，只给出漏斗和每笔被丢的原因，作为 R20 起逐环节优化的起点。
