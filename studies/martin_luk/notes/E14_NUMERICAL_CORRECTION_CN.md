# E14 数值更正记录

本记录不增加研究方案，唯一任务书仍为 PLAN_E14_CN.md，PREREG_E14_CN.md 原文及指纹不改。

首轮完成 22 个单环节诊断和 5 个完整候选，五个均未满足两个年度门槛，未测试 2026。随后独立重算真实成交现金流，发现计划止损风险最多超过 1U 约 0.00000485U；严格检查失败，因此不能把首轮工件视为完成的合格实现。

根因是 NumPy 2 的标量提升规则：float32 行情与 Python 浮点数混合运算仍可降为 float32。原合成单测使用 float64，没有覆盖这一条路径。补充 float32 组合现金流测试，在修复前重现失败；修复只在 E14 的 `proof_stop` 模式中将估值、成交现金流、股数上限的标量转为双精度，其他模式继续原行为。没有改动任何信号、止损定义、候选、门槛、选择或验证规则。

首轮完整结果、选择记录、失败检查、日志及与原指纹逐一核对的全部源码保存在 `reports/e14_float32_attempt/`，不覆盖、不改写首轮结论。数值修正后使用相同预登记重新跑工程复核和正式测量；这是一次实现更正，不冒充只有一次训练执行，也不当作新的调参轮次。继续不测试 2026，除非原门槛自动产生合格者。

更正后的必查项目：float32 合成回归、2024-01～02 冒烟真实现金流、修改前引擎默认关闭兼容、三套全量测试、W/W* 的真实截断与 gate、所有真实加仓的独立现金流上限、原预登记与登记版/看板保护。gate 只比较输入，不调用组合引擎；数值更正仅改 simulate 的算术，旧 gate 的输入证据仍有效，真实成交截断必须用修正后的引擎重做。
