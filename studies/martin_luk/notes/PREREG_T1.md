# T1 预登记：买到他的票优先（2026-10-31）

目标按用户 10-31 的要求改为：先买到他同期有日期的多头，并在这些票上赚到相近收益；账户收益是约束，不是目标。

依据：R74 + S7 在 2024–25 的 32 笔里，14 笔卡每日名额、2 笔已持有，第二层 R 合计最大。增长拆解：他 2025 年 940 笔、反推仓位约 17%，我们 220 笔、平均仓位 30%。他是更多笔、更小仓。此前解开名额失败时都带着 30% 单只仓位和杠杆，没有成对改过。

## 候选（≤ 5，跑完不改）

基础 = 登记版本 R74 + S7，只改下表。

| 候选 | 改动 |
|---|---|
| REG | 参照 |
| T1A | 每天 8 笔，单只上限 17% |
| T1B | 不限每日笔数，单只上限 17% |
| T1C | T1A + 题材排序（theme_priority） |
| T1D | T1A + 总敞口上限 170%（他的 17% × 约 10 只） |

17%、170% 来自增长拆解和 Flanders G3 的同一估算方式，8 是常见整数，不调。

## 门槛与选择

- 窗口 2024-01-02 → 2026-10-16，选择看 2024–25；2026 已用过，只报告。
- 全部满足才带入：买到他的 ≥ REG + 3；胜率 ≤ 35%；每年笔数 ≥ REG；2024–25 两年都盈利；跑赢同池随机中位数（只对过前四条的候选跑 100 次）。
- 选择：买到最多，相同时取这些票上第二层平均收益更高者。都不过就保留 REG，并定位差在哪层。
- 不看未来：用引擎原有入场与 t−1 排序，不新增字段。研究版，替换登记版本要用户同意。
