## 本轮各层的备选（全部只用日 K，路径无歧义）

基底 ref = E8c 原样。每个备选只改一层：

| 代号 | 层 | 定义 | 原话 |
|---|---|---|---|
| P1 | 入场价 | ref 收盘突破当天（b 日）不买，改挂限价 L = 被突破的前一日最高价 h[b−1]，b+1～b+3 有效。某天开盘 ≤ 止损：撤单；开盘 ≤ L：按开盘成交；否则最低价 ≤ L：按 L 成交。止损 = min(b 日最低价, 0.99·L)，宽于 min(5%, ADR[b−1]/2) 压到该宽度（同 ref；上限 <1% 不挂）。挂单在 b 日收盘后下，只用 b 日及以前的价格。b+3 可能越过观察期末，报成交日距突破日的天数分布。成交当天最低价 ≤ 止损记当天止损。限价在止损上方，碰止损必先成交，无先后歧义 | ⑤ 先回到支撑再买、离低点 >3% 不追；⑥ |
| P0 | 入场价 | b+1 开盘高于 h[b−1]、且不高于 1.03·h[b−1]（⑤ 不追）时按开盘价买；止损 = min(b 日最低价, 0.99·开盘价)，宽于 min(5%, ADR[b−1]/2) 时压到开盘价 ×(1−上限)；当天最低价 ≤ 止损记当天止损 | ④ wick play / 跳空延续 |
| AS | 加仓保护 | 加仓后整个止损抬到加仓日最低价（`add_signal_stop='low'`） | ⑦ 新仓顺利才加 |
| AF | 加仓保护 | 加仓后止损抬到原买价（`'fill'`） | 同上 |
| X1 | 离场 | 不看收盘跌破 9EMA；成交日之后第一个收盘高于 9EMA 时武装，止损跟随 9EMA 下方 1%，次日起盘中触发（`stop_ema_buffer=.01`、`stop_ema_only`，关 `exit_signal`）。引擎原来禁止盘中入场配此模式，放宽为只禁止“入场当天就武装”（会读成交日收盘的 EMA） | ⑥ 后来不看收盘、止损放 9EMA 下方一点 |
| IN | 形态 | 只认前一根 K 为内包日或窄幅日（振幅 < 0.6 × 前一日 ADR）之后的收盘突破；不合格的突破不消耗观察期 | ④ 内包日 / 窄幅日后突破 |
| RE | 再入场 | ref 的每个入场信号，若之后先碰到止损（早于收盘跌破 9EMA、也早于最高价到 3R），则在止损后 10 天内第一次收盘高于原买价时再买一次，止损按 ref 规则；当天被止损的票当天不再买；再入场单独报笔数与平均 R | 多次试单（笔数 940/年） |
| CS | 止损执行（越界诊断） | 成交日当天不变（收盘入场无盘中；盘中入场的当天止损照旧）；成交后第 1、2 个交易日盘中和开盘只用 2 倍初始宽度的硬止损，收盘低于初始止损按收盘价走（单列 `close_stop`）；之后恢复。引擎新开关 `close_stop_days`，默认关 | 无，诊断“盘中扫”占多少 |
| SL | 敏感性 | 盘中止损成交价差 0.1R（不超出当天价格区间；跳空止损本来按开盘价，不再加）。按宽度计，不偏罚窄止损。引擎新开关 `stop_slip_r`，默认 0 | 无 |

## 一轮内跑的三组（同一次运行）

**组 0 漏斗与上限（诊断）**：ref 的触发事件中 P1 在 3 天内成交的比例、P0 条件成立的比例（价格上限，未计名额与仓位拒绝）；成交 / 未成交两组买后 60 天最高涨幅分布（60 天涨幅只作尺子，不进任何规则）。

**组 1 单层归因（诊断，不选）**：ref 与 ref+P1、+P0、+AS、+AF、+X1、+IN、+RE、+CS、+SL，共 10 个。

**组 2 端到端候选（≤5，选择）**：W = P1 + AS + X1（每层取最贴原话的一项，其余同 E8c：3R/5R 卖 15%、试单加仓、市况减半、0.5% 满仓风险）。

| 候选 | 定义 |
|---|---|
| K1 | W |
| K2 | W 但入场换回 ref（收盘买） |
| K3 | W 但加仓保护换回 ref（止损不动） |
| K4 | W 但离场换回 ref（收盘破 9EMA） |
| K5 | W + IN |

另报 W + CS、W + RE、W + SL 三个诊断（不参与选择）。组 1 与组 2 的差异合起来给出各层在 ref 上和在 W 上的作用，看是否互相牵连。

## 选择规则（只用 2024-01-02～2025-12-31，看结果前定）

1. 资格：平仓笔数 ≥ ref 的 70%；按实际投入涨 ≥ 20% 的赢家笔数 ≥ ref 的 90%。
2. 有资格者按两年账户收益排序；差距 < 2 个百分点按 `study.gap`（小者优先）；再按 K1→K5 顺序。
4. 回退：K1–K5 无人有资格时，按同一资格与排序从组 1 的单层改动里选（不增加候选种类）；仍无人有资格才不选。
5. `study.gap` 用 E8 同一口径（`e8_research.invested`，按实际投入）。
6. 选中者 2026 只测一次；ref 2026 已知（−22.7%）作参照。
