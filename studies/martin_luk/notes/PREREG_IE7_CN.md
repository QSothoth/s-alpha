# IE7 计算前登记

唯一任务书为 `PLAN_IE7_CN.md`，本文件只追加各轮登记，不改既有轮次。只读 IE5/IE6 缓存；不取数、不改登记系统，不提交、不推送。2026 已看过两次，只在最终方案和对照冻结后报告一次。

## 固定口径（描述和新排名计算前）

- 比较范围沿用缓存的完整 leader_weekend，百分位在门禁前的当晚完整范围内计算；有限值用平均并列名次，缺值保持缺值。
- 描述覆盖 IE4 全部 64 个原始数值，以及 IE6 220 条候选使用的全部数值版本（原值或同晚百分位）；同一来源的不同阈值不重复计算。全部 220 条条件逐条映射到描述表。百分位版本的统计与对应原值共用同晚百分位，不把百分位再排名而制造差异。
- 每笔先对入场前四晚的有限百分位取中位数，再在每个半年对这些逐笔中位数取中位数；同时附四晚直接合并的中位数、有效笔数、证券夜数和缺失数。范围外和缺值不填成中性数据。主目标与全部已定位入场各有完整表。
- 稳定特征：四个半年都有有效值，且四个半年中位数全部 ≥0.65，或全部 ≤0.35。只在一两个半年达到偏离0.5至少0.15者标为不稳定，不得用于排名或门禁。其余标明混合或弱特征。
- observed_sessions 与 raw_price 只描述，沿用 IE6 禁止入选。选股不读本人代码、名单、日期；评价标签只用于描述和评分。
- 排名使用最多五个稳定原始数值的同晚百分位，低方向取 1−百分位，等权平均；缺值贡献0.5，排序同分按缓存代码顺序。门禁最多三条，只用稳定特征，有限值必须通过，缺值不通过。相同原始数值及其百分位不重复作两个排名因子。
- 每轮最多五个方案，最多三轮。方向、常见阈值在计算覆盖前写定，不做权重拟合。因此两折直接报 2024、2025，主分数=min(2024主目标前五率,2025主目标前五率)。这两年参与了稳定特征筛选，不把此数称为独立样本外成绩。
- 每个方案在全部交易夜晚排名。账户只有现金六仓 H4 不分批和 IE5 杠杆版，复用 IE6 的次开撮合、费用、2.5%保护和开盘加仓越界修正；选择阶段严格截到2025末，不读2026的平仓结果。账户只否决每年开仓<52或已结束胜率>35%的方案，收益不作门槛。每种选股只跑这两种账户，不做 K 比较和随机账户。
- 在合格方案内按主分数降序、排名因子数升序、四半年最差前五率降序选择；仍平手按登记顺序。每轮后按范围外、门禁误伤、排名落后分解未命中笔数，只针对损失最多层登记下一轮。范围为任务书冻结范围，不擅改范围。
- 最终胜出方案逐个删除因子、门禁；两年 min 不降就删，依次试排名因子再门禁，接受一次删除即重新开始，直到全部删除均会降低 min。删除不引入新条件或调阈值；账户仍检查并如实报告，若简化结果不合格不冒称通过。
- 对照仅一次，种子20261107：在每晚门禁前范围内固定置换代码与行号的对应关系，同一晚重复披露共用映射，原范围外仍范围外；重跑同一稳定筛选、三轮内已登记方案结构、相同 min 选择及消融。每个方案的因子按其在真标签稳定表中的“最差半年偏离强度降序、名字升序”的位置映射到打乱稳定表的同位置；稳定特征不足则该方案不可用；若没有任何可用方案，报告无合格稳定模型，并附零因子、零门禁同分基线覆盖，不伪造稳定因子。
- 每轮登记含准确因子、方向、阈值、白话解释、对照的位置结构。对照按已登记结构重放一次，不再为对照增加轮次或条件。
- 最后冻结简化方案，才计算2026。2024–25与2026报告前1/3/5/10、范围→门禁→前五漏斗、两种账户的笔数胜率收益回撤和实际买到本人入场数量，旁列 IE6 冻结结果。2026 不回流选择。

## 第一步

先只运行描述。各轮方案在描述完成后、各轮覆盖和账户计算之前追加。

## 第一轮（已看描述，未算任何 IE7 覆盖/账户）

稳定表共有21个允许特征，顺序为 adr20、iv、pot_count20、hv、h4_history、option_volume、put_volume、call_volume、fresh_pot、low20、option_open_interest、low60、high20、offlow252、high60、h4_peers、h4_momentum、g21、rs21、high252、near_ema9。除 high20/high60/high252 取低方向，其余取高方向。

以下 pct 均为门禁前同晚百分位；全部缺值不通过门禁。因子等权，不拟合权重。

| 方案 | 排名因子 | 门禁 | 一句话含义 |
|---|---|---|---|
| R1A | adr20↑、iv↑、pot_count20↑ | 无 | 日线和期权波动大，近期反复变强。 |
| R1B | R1A + h4_history↑ | 无 | 再偏向过去反复成为强势股的票。 |
| R1C | R1A + high20↓、near_ema9↑ | 无 | 已有波动和关注，又有回调且靠近短期均线。 |
| R1D | 同R1A | high20 pct≤0.50；near_ema9 pct≥0.50 | 先排除回调不足、远离短期均线的票，再排波动与强势扫描。 |
| R1E | 同R1A | adr20 pct≥0.75；iv pct≥0.75；high20 pct≤0.50 | 只在高波动、已有回调的票中排关注度。 |

排名因子含义：adr20为近20日平均日内振幅；iv为期权隐含波动率；pot_count20为20日强势扫描次数；h4_history为既有H4历史强势组；high20为收盘相对20日最高价的折价，越低回调越深；near_ema9为负的距EMA9距离/ADR，越高越靠近均线。没有暗含证券、名单或日期条件。

打乱结构按上列21项的零起始位置转移；门禁也是百分位，所以若替代因子稳定方向相反，则把上下界按 p→1−p 同时翻转，保持“顺稳定方向筛”的结构。第一轮不依赖任何覆盖漏斗；后续轮次只针对第一轮胜出方案损失最多的层。

## 第二轮（第一轮完成后登记，第二轮尚未计算）

第一轮胜出 R1D：2024为4/11、2025为3/17，min=17.65%；28笔中范围外2、门禁损失3、排名损失16。因此只改排名，门禁完整固定为 R1D 的 high20 pct≤0.50、near_ema9 pct≥0.50，不加门禁、不调阈值。

对漏在排名层的目标与同晚前五作描述比较：目标的历史强势组、靠近EMA9、期权量和未平仓量中位百分位更高；ADR/IV/强势扫描次数虽稳定，却低于排在前面的极端股票。第二轮据此降低重复的波动/扫描因子占比。此诊断没有试任何未登记的排名覆盖。

| 方案 | 等权排名因子（均↑） | 理由 |
|---|---|---|
| R2A | adr20、iv、pot_count20、h4_history | 固定门禁后补历史强势。 |
| R2B | adr20、iv、pot_count20、h4_history、near_ema9 | 再补靠近短期均线。 |
| R2C | adr20、iv、h4_history、option_volume | 用期权关注替换重复扫描次数。 |
| R2D | iv、h4_history、near_ema9、option_volume | 减少对极端日内波动的偏好。 |
| R2E | h4_history、near_ema9、option_volume、option_open_interest | 以历史强势、回调位置和期权参与共同排名。 |

option_volume是一晚期权总成交合约数；option_open_interest是期权未平仓总合约数，均只用当晚缓存。其余方向、账户否决和对照位置映射完全沿用上文。

## 第三轮（第二轮完成后登记，第三轮尚未计算）

第二轮胜出 R2D：2024为4/11、2025为6/17，min=35.29%；范围外2、门禁损失3、排名损失13。R2B主分数相同但因子多，故不选。第三轮仍只改排名，完整保留两条门禁及0.50阈值。

第二轮漏在排名层的目标，相对同晚前五最突出的差异是21日涨幅/相对涨幅、H4动量组和距20日低点涨幅更高；靠近EMA9和历史强势组的中位数反而低于对手。以下只测试加入近期价格动量或脱离低点，并用替换法避免超过五个因子。g21与rs21在同晚排名完全相同，不重复放入。

| 方案 | 等权排名因子（均↑） | 理由 |
|---|---|---|
| R3A | iv、h4_history、near_ema9、option_volume、g21 | 在R2D上补一个月动量。 |
| R3B | iv、h4_history、near_ema9、option_volume、low20 | 在R2D上补脱离近期低点。 |
| R3C | iv、h4_history、option_volume、g21 | 用近期动量替换靠近均线的排名偏好，门禁仍保留均线底线。 |
| R3D | iv、near_ema9、option_volume、g21 | 用近期动量替换历史强势，避免只认旧强票。 |
| R3E | adr20、iv、h4_history、option_volume、g21 | 以日内波动替换均线排名，保留近期动量和参与度。 |

g21是近21个交易日价格涨幅，low20是收盘相对20日最低收盘的涨幅。三轮预算至此用完；不因未达到80%追加方案。随后按既定规则消融、一次标签对照、冻结，再报告2026。
