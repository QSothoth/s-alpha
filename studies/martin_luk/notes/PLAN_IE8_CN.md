| | 门禁后每晚剩余（中位） | 他的主目标留在门禁后 | 前五 | 掉在哪 |

IE7 的年份互考让 2026 从 2/23 升到 7/23，方向对；但它要在 500 只里把他的票排进前 5（约前 1%），四个等权百分位做不到。IE6 把池子收到 90 只，却在门禁这一步丢了一半他的票。两段各自只解决了一层。

## 做法：两层，各自有明确指标

### 1. 第一层：收窄门禁（目标“留住他的票 + 池子够窄”）

- 只用 IE7 第 1 步判定的四半年稳定特征（数值稳定的 21 个允许特征及其 IE6 版本），方向沿用 IE7 描述。
- 每个门禁的阈值取同晚百分位的常见值（0.5 / 0.6 / 0.7 / 0.8 / 0.9 或其反向），不做连续搜索。
- 先描述（不选择）：对每个稳定特征和每个常见阈值，报 2024、2025 分年的“他的主目标留住几笔”和“每晚剩余中位只数”，画成留住率–宽度表，用来定可达上限。
- 第一层指标：两年中较低一年的主目标留住率 ≥ 90%，在此前提下每晚剩余中位只数尽量小；门禁 ≤ 4 条。按轮预登记，每轮 ≤ 5 个门禁组合、最多 3 轮，跑完不改。
- 报告第一层最终组合在 2024、2025 的留住率和宽度。若留住率 ≥ 90% 时宽度仍 > 100，如实写出，并说明第二层要面对的难度（前 5 / 宽度）。

### 2. 第二层：小池内排名

- 在第一层冻结后才开始。排名 = 少量稳定因子的同晚百分位等权平均（百分位在第一层门禁后的小池内重新计算，也报告在门禁前全池计算的对照），每个方案 ≤ 5 个因子，方向不拟合。
- 可以用第一层没用作门禁的稳定特征，也可以用作门禁的特征（门禁只框范围，小池内再比强弱）。
- 按轮预登记，每轮 ≤ 5 个方案、最多 3 轮。每轮后按漏斗诊断，下一轮只针对掉票最多的环节改，写明理由。

### 3. 打分与选择（选择前固定）

- 方向、阈值事先按整数/常见值固定，两折直接分年：主分数为 2024、2025 前五覆盖率的较小值（min）。
- 同时报前 1/3/10、四个半年、他全部入场的前五覆盖、漏斗（比较范围 → 第一层后 → 前五）。
- 账户只作否决：现金六仓 H4 不分批和第五段杠杆版，2024、2025 每年开仓 ≥ 52 笔、已结束胜率 ≤ 35%。收益只报告，不作选择。
- 平手取因子少者，再平手取四半年最低覆盖较高者，再按登记顺序。

### 4. 消融、对照、冻结

- 对最终两层方案逐项删门禁和排名因子，两折 min 不降即删，重复到不能删。
- 打乱标签一次（固定种子，换一个与 IE7 不同的种子），同结构走一遍。
- 冻结后在 2024–25 和 2026（已看过三次，不是干净考试）各报一次覆盖、漏斗、两种账户，与 IE6、IE7 冻结版并列。
