# R23 预登记：等形态（他买入当天的日线形态）

2026-10-17 写于看任何 R20–R23 结果之前，跑完不改。名单 W* = R20–R22 的选择（股票池 ∧ K* ∧ V*）。

## 来由（他的原话，见 RULES_CN ④）

三类买点：内包 / 窄幅后越过前一日高点（"每一段行情都从越过前高开始"）；EP（盘前跳空放量，越过开盘区间高点）；回调到上行的 9/21 EMA 后 V 形收回（2025 年主力）。R15 在 W2 名单上比较过缩量、波动收缩、浅回调、均线收敛、高位旗形，作为“基础形态之上的附加条件”，没有通过；本轮比较的是形态本身，用他买入当天的日线判断。

## 候选（第 t 天的日线，盘中可知；EMA、ADR 用 t−1）

- **E1 越过前高**：当天最高价 > 前一日最高价。
- **E2 收紧后越过前高**：前一日内包或振幅 ≤ 0.5 × ADR20，且当天最高价 > 前一日最高价。
- **E3 跳空（EP）**：开盘 ≥ 前收 × (1 + max(5%, ADR20))。
- **E4 回踩 9 EMA**：EMA9 > EMA21，当天最低价 ≤ EMA9 ≤ 最高价。
- **E5 = E2 ∪ E3 ∪ E4**（他的三类买点）。

## 指标

- 命中率：选择段 `exact` + `chart` 多头交易在窗口内的某天、该股在 W* 且出现该形态的比例；宽度为每天信号只数（中位数，2024-01 → 2026-03）。
- 超额：W* 名单内，当天有该形态的 vs 没有的，同日、同 ADR 十分位比较“当天收盘买入、10 天后收盘”的收益（入场价放到 R24 比较）。

## 选择与验证

- 选择：宽度中位数 ≤ 15 的候选里命中率最高的；2024 年超额点估计须 ≥ 0，否则顺延；并列取更窄。
- 验证：验证段 `exact` + `chart` 多头命中率高于“W* 内每天随机取同样只数”的随机命中率（提升倍数 > 1）且不低于 E2 算“更像他”；2025-01 → 2026-10 超额 95% 下限 > 0 另记“有超额”。
