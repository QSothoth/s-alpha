# TF1 train 段结果：三个市场都没有胜出者

预登记 [notes/TF1_PREREG.md](../notes/TF1_PREREG.md)；train 段 2024-10-01 → 2025-09-30；test 段**未打开**。数字全部在 [tf1_train.json](tf1_train.json)，逐笔交易在本机 `data/trend-breakout-v1-results/tf1_train.json`（不进 git）。复现：`PYTHONUTF8=1 /opt/futu-opend/venv/bin/python -m studies.trend_breakout.run_tf1 train`（约 6 分钟）。

## 结论

- **T1–T5 在美股、港股、A 股都没有通过全部门槛，按预登记 TF1 失败，test 段不打开。** 不放宽门槛，也不加候选来补救。
- **突破入场没有比随机入场选出更好的股票。** 15 个「候选 × 市场」里，只有美股 T2 的平均 R 高于随机入场（R0）的第 95 百分位；美股 T5 高于 R0 均值但不到第 95 百分位；其余 13 个连 R0 的均值都不到。
- **利润来自离场规则和行情，不是入场。** 随机入场配同样的跟踪离场，R 都是正的；港股、A 股的 R0 还明显更高。原因是 train 这一年港股、A 股都是大牛市，只要拿得住就赚钱。
- **收益集中在后两个季度。** 三个市场都是 2024-Q4 到 2025-Q1 亏、2025-Q2 到 Q3 赚。15 个候选全部没过季度集中度门槛（单季不超过总 R 的 50%），美股还全部没过「去掉最好的 5% 交易后仍为正」。
- **美股的正 R 全部来自期末未平仓的交易。** 已经平仓的交易，5 个候选的平均 R 全为负（−0.07 到 −0.25）；正的部分全靠 2025-09-30 按收盘价结算的浮盈。
- 形态上符合目标：胜率 36–48%（港股 T4 是 52%），盈亏比 1.7–3.4。但赚钱的根源是持有和行情，不是信号。

## 口径问题（照记，不改本轮结论）

R 的分母是「入场价 − 初始止损」和 1 ATR 中较大的一个。突破时股价贴着 22 日高点，Chandelier 初始风险约 2.6–2.8 ATR；随机入场的股票离 22 日高点更远，初始风险只有约 1.5–1.8 ATR。所以**同样的百分比收益，随机组的 R 更大**，这个对照对候选不利。

换成和口径无关的「每笔超额收益」（相对同期等权股票池）再比较：

| 市场 | 候选每笔超额（T1 / T2 / T3 / T4 / T5） | 同日随机入场（10 次平均） |
|---|---|---|
| 美股 | −0.09% / +0.76% / +0.16% / −0.03% / +0.18% | −0.02% / +0.01% / −0.01% / +0.50% / +0.09% |
| 港股 | −0.13% / +1.23% / +0.30% / +1.32% / +0.58% | +0.30% / +1.37% / +0.23% / +1.33% / +0.01% |
| A 股 | −0.04% / −0.20% / −0.25% / +0.47% / +0.03% | +0.19% / +0.26% / +0.11% / +0.71% / +0.14% |

（随机组分别配各自候选的离场规则。）按这个口径，美股的 T2、T3、T5 和港股的 T3、T5 略好于随机，其余和随机相当或更差，A 股全部不如随机。也就是说，换掉偏向随机组的 R 口径，结论仍然是「突破入场没有可靠的选股能力」。这个口径问题在 TF2 预登记里修正（统一初始风险），不回头改 TF1 的门槛。

## 其他记录

- **执行**：A 股因涨停开盘放弃了 26–217 次信号（T3 最多）；因跳空低于初始止损放弃的 0–40 次；因停牌放弃的是个位数。
- **期末未平仓**：按 2025-09-30 收盘价结算的交易占 7–30%（A 股 T2 最多，811 笔）。只看已平仓的交易，平均 R 为：美股 −0.12 / −0.17 / −0.07 / −0.25 / −0.09；港股 +0.09 / +0.06 / +0.32 / +0.43 / +0.24；A 股 +0.02 / −0.19 / +0.13 / −0.01 / +0.17（依次 T1–T5）。
- **股票池偏差**：取数池口径（今天还活跃的股票）和逐日口径相比，美股、港股的 R 略高，A 股反而略低。由于幸存者偏差，所有数字只可能偏乐观。
- **过程中修正过一个 bug**：第一次跑时，ST 排除误用了「名字含 ST」，并且套到了全部市场，美股 85 只名字含 FIRST、TRUST 之类的股票被错删。已改成只对 A 股生效、只匹配 `ST` / `*ST` 开头，并加了测试，然后三个市场整体重跑；本页是重跑后的结果，结论与第一次相同。
- **幸存者偏差**：只有 2026-10-12 仍上市的股票。
