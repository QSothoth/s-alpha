# 机会兑现时间 ↔ 期权/涡轮期限

把「价格大概何时动」映射到合约到期，使人与代理在确认句里带上明确的 DTE/到期。多空都覆盖；用户明确要做期权或涡轮时才进入本 skill。不做收益认证、不回测最优、不下单。

工程沿用根及 `studies/AGENTS.md`。相对链接按本 skill 真实路径解析。

## 何时用

- 上游已给出：代码、方向（多/空）、时间尺度线索（短线技术位 / 事件叙事 / 不明）、触发价与失效价（可来自 daily-technical）、兑现节点日期（若有）、市场（US 期权 / HK 涡轮或期权）。
- **不要**在尚未判断方向与「何时可能动」时先挑合约。
- **防错配**：方向对、到期太近 → 先付 theta。反例：海力士解禁前一周用近月空——叙事是数周事件，合约却是近到期。

## 输入

| 字段 | 说明 |
|---|---|
| 代码 | 如 `US.NVDA`、`HK.09988` |
| 方向 | 多 → CALL / 认购涡轮；空 → PUT / 认沽涡轮 |
| 时间尺度标签 | `短线技术位` / `中线` / `长线或事件` / `不明`（可来自 Discord 或 opportunity-research） |
| 触发价 / 失效价 | 未触发则**不付权利金**，只观察 |
| 兑现节点日期 | 解禁、财报、指引、产能节点等（若有） |
| 市场 | `US期权` 或 `HK涡轮或期权` |

时间尺度不明时：先追问或回 opportunity-research 补「多久兑现」；仍不明则按 **中线** 保守处理（DTE≥21），并标明「尺度未确认」。

## 短 / 中 / 长 → DTE（写死可执行档）

以下为**协作约定**，不是回测最优。代理与人按此对齐，避免临场随意缩期。

| 标签 | 典型持有/兑现 | 建议 DTE / 到期窗口 | 硬禁止 |
|---|---|---|---|
| **短线技术位** | 数日～约 2 周 | 约 **7–21** 个日历日（选落在此窗的到期） | 结构**未触发**则不买期权/涡轮，只观察；禁止用 0DTE「赌当天」顶替未确认结构 |
| **中线** | 约 2～6 周 | **DTE≥21**，且覆盖兑现日 + 缓冲（建议至少兑现日后 5–10 个交易日） | 禁止为省权利金改近月到「刚好卡在兑现周」 |
| **长线 / 事件** | 数周～数月（解禁、产能、指引） | **DTE≥21～45+**，覆盖节点 + 缓冲 | **禁止** 0DTE；**禁止**「等事件」却买最近到期；**禁止**催化前过早入场（节点前过早付 theta，节点后再评估） |

补充：

- 美股期权按实际到期周五选档；港股涡轮按**最后交易日**计可用寿命，到期日须与发行商条款核对。
- 多空同一套 DTE 规则；工具符号随方向换 CALL↔PUT / 认购↔认沽。
- 账户买不起合适合约时：**不能**用更虚值 + 更短到期凑杠杆；保留观察或缩小名义，不改期限映射。

## 输出给人

每条机会输出固定块（可直接贴群聊，再由人确认）：

1. **时间尺度判定**：短 / 中 / 长（或不明→按中线），一句依据（技术位天数 / 事件日期）。
2. **建议工具**：CALL 或 PUT；港股则认购/认沽涡轮（或期权若用户指定）。
3. **DTE 或到期窗口**：如「DTE 14–21」或「覆盖至 YYYY-MM-DD 后至少 N 日」。
4. **不该买什么**：列出禁止档（0DTE、最近到期、催化前过早、未触发就付权利金等）。
5. **与买点关系**：触发价未到 → **不买、不挂**；写「触发后再确认」。已触发才给可复制确认句。
6. **港股涡轮额外**（须核实后才可写「确认挂」）：有效杠杆、换股比率、街货量、街货比、打和点、到期日/最后交易日。任一查不到就标缺口，不编造；缺口未补则只给观察结论。

## 衔接

- **上游**：[opportunity-research](../../../us_0dte_picks/skills/opportunity-research/SKILL.md)（方向、兑现与失效）+ [daily-technical-review](../../../daily_technical/skills/daily-technical-review/SKILL.md)（触发/失效价与结构）。
- **下游**：执行确认句**必须**带 DTE 或到期日（及涡轮代码若适用）。[near-expiry-session](../../../us_0dte_picks/skills/near-expiry-session/SKILL.md) **仅**固定池最近到期会话；中长线或非池内标的**不塞进去**，保留研究/人工确认。
- 本 skill 不替代日 K 买点，也不授权实盘。

## 确认句模板（示例）

未触发：

```text
明日触发后再确认｜HK.09988 多｜尺度：短线技术｜工具：认购涡轮待核｜建议 DTE 7–21｜未触发不付权利金
```

已触发且涡轮要素已核：

```text
确认挂｜HK.09988 多｜涡轮 XXXXX｜到期 YYYY-MM-DD（最后交易 DD）｜DTE≈N｜行使价…｜换股比…｜有效杠杆…｜街货比…｜打和点…｜触发…｜失效…
```

人确认后交既有执行流程（如末日王者会话）；本 skill 本身不下单。
