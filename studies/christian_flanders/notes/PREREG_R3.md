# R3 预登记：入场与止损

2026-10-18 写于任何 R3 结果之前，跑完不改。基础 = R2 带入的配置。

## 来由

- R1、R2 的系统亏单平均 −8%～−9%（他公布 −3.35% / −4.55%，亏单 −0.89R / −1.02R），赢单像他、亏单比他大一倍：EP 和突破当天按当日低点止损，日 K 上止损太宽，且“越过触发价买、当日低点止损”在日 K 上是乐观近似（不知道低点在买入前还是后）。
- 他的原话：开盘区间高点买、止损放当日低点；EP 也可以“开盘就买，放 5% 或 6% 的止损”（Lot25@01:20:54）；亏单平均不到 2 天。

## 候选

- **E1** 悲观边界：越过触发价买、收盘低于买价的当天算在当日低点止损（level_pess）。
- **E2** 止损最宽 6%（更宽的上移到 6%）。
- **E3** EP 改为开盘买、固定 6% 止损（日 K 上精确）；突破不变。
- **E4** 收盘确认：收盘高于触发价才在收盘买，止损当日低点（日 K 上精确）。
- **E5** E1 + E2。
- 参照 = R2 带入。

## 选择规则

门槛：跑赢同池随机入场中位数、买到他的票（选择 + 验证）不少于参照、每天信号中位数 ≤ 30。目标：行为差距（笔数、胜率、平均赚 / 亏、赢单 / 亏单持有天数对他公布值的平均对数差）最小。都不过就沿用参照。
