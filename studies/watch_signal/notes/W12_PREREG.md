## 问题与边界

代码审查发现量比把当根纳入分母、港股价位表未跟随 2025-08-04 / 2026-08-03 的已生效调整，并且价位区间上界被排除。大写 B/S 当前只表示 `tpb >= 2` 且 `D+`，不表示量能可靠。

本轮分为确定性纠错与两个研究候选。纠错是否通过由官方定义、因果性及实现复刻决定，不由收益决定；历史收益仅作纠错审计。研究候选仅筛查，不得凭重复使用的选择段上线。

官方口径：[HKEX 实施时间与价位调整](https://www.hkex.com.hk/Services/Trading/Securities/Overview/Trading-Mechanism/Reduction-of-Minimum-Spreads?sc_lang=en)、[第二阶段价位表 FAQ](https://www.hkex.com.hk/-/media/HKEX-Market/Services/Trading/Securities/Overview/Trading-Mechanism/Reduction-of-Minimum-Spreads/Reduction-of-Minimum-Spreads-FAQP2_E.pdf)。

## 确定性修复及验收

1. 量比 = 当根量 / 严格此前 20 根均量；不足 20 根时只用已有此前各根，无此前根或均量为零时为未知，不误称无量。第一根不参与自身基准。
2. 港股普通股票价位按每根 bar 的日期选表：2025-08-04 起，`10 < p <= 20` 为 0.01、`20 < p <= 50` 为 0.02；2026-08-03 起，`0.5 < p <= 10` 为 0.005。旧日期保留旧表；所有价位表区间上界包含。实时默认日期为香港当日。
3. 保留原 VWAP、EMA9/21、RSI14、ATR（高低差均值）、预热 25 根、FVG、SWEEP、D+ 及按方向和档位去重 15 根。不把 ATR 改为另一种定义。
4. 对量比分母、零基准、各日期分界与价格边界做确定性测试；输入前缀的指标和标注须与整日相同前缀一致，不引入未来数据。
5. `code/w12_audit.py` 使用单日 `feat.build()` 指标，独立重算量比、价位、BOS/FVG/SWEEP、档位、去重、D+；与当前 `watch.marks()` 的逐条字段核对。真实选择段中按文件顺序最早 40 个合格标的日作为固定复刻样本，所有字段及前缀核对必须零差异。不足 40 日则失败。

## 研究候选（仅两个，不扩展参数）

| 名称 | 定义 | 结构性理由 |
|---|---|---|
| B0 | 上述确定性修复后的原规则 | 修正实现错误后的对照 |
| C1 | B0 中 BOS 仅在刚穿越当前已确认摆动点的本根成立：买入 `prev_close <= swing_high < close`，卖出 `prev_close >= swing_low > close`；FVG/SWEEP 不变 | 超过同一已破位水平不等于发生新突破，重复通知可能发生在价格已经跑远之后 |
| C2 | C1 基础上，同方向统一去重 15 根，不再按 plain/vol 分开 | 避免成交量切档对同一方向重复通知；它是通知简化假设，不预设量大更准 |

若出现多个触发，按原 BOS、FVG、SWEEP 顺序保留，候选不得删改其他触发。固定阈值均沿用，不搜索参数。

## 收益与统计口径

主收益 `d1f30`：本根标注后，下一根收盘入场，再过 30 根收盘退出，即 `side * (close[i+31] / close[i+1] - 1)`；不足 31 根的标注只计通知数、不计收益。报告毛收益 bp，不扣成本，不宣称可盈利。

按 `tpb < 2`、`2 <= tpb < 5`、`tpb >= 5` 及 D+ / D- 分层，D 未知单列。每层报告通知数、可评测数、交易日数、BUY/SELL 各自均值、两侧等权均值及按交易日聚类 t。共同主评估对象为全部 `tpb >= 2` 的标注；同时报告全标注，避免只挑有利小组。

两侧等权均值为 `(mean_buy + mean_sell) / 2`。按每方向样本数归一化后，将各日收益和组合成日贡献，再按交易日聚类计算标准误；候选相对 B0 的改善使用共同交易日集合的配对贡献差。各侧样本数不同不会把行情净方向当作优劣。

收益计算前的公式澄清：日聚类分数 `u_g = 0.5 * (sum_buy_g - n_buy_g * mean_buy) / N_buy + 0.5 * (sum_sell_g - n_sell_g * mean_sell) / N_sell`；`SE = sqrt(G / (G - 1) * sum(u_g²))`，`t = mean / SE`。候选差按两组交易日并集对齐、缺日补零，使用 `u_candidate - u_B0` 计算 SE；不采用日收益简单等权，不把每日样本数差异当成独立收益。

## 固定筛查门槛与后续

候选在主评估对象中须同时满足：

1. BUY、SELL 各至少 200 个可评测标注且各覆盖至少 60 个交易日；
2. 两侧等权毛收益 > 0，按日期聚类 `t >= 2`；
3. 相对 B0 的两侧等权改善 > 0，配对按日期聚类 `t >= 2`；
4. BUY 和 SELL 各自均值均不低于 B0（不设置事后非劣余量）；
5. 同时报告通知减少比例和所有预定分层，不以单只股票或有利层替代整体门槛。

两候选都通过时，只把改善 t 较高者列为待验证者，若相等优先 C1。任何候选即使通过，也因本次没有未使用的独立验证段而不得上线；失败照记。没有通过者不继续追加候选或调阈值。
