# W24 预登记：用当天 1m 线预测「余下还能走多远」，以及收盘前回吐

登记日期：2026-10-13。选择段探索（`code/w24_explore.py`、`code/w24_analyze.py`）已完成，下面的定义在查看验证段任何结果前固定。

## 选择段探索结论（2025-12-01 → 2026-08-14，88,673 个 `tpb >= 2` 检查点观测）

- **方向几乎不可预测**：缺口、开盘以来、最近 30 分钟、VWAP 偏离、日内区间位置、当日累计 B/S、最后一条 B/S、恒指开盘以来 / 最近 30 分钟 / 相对昨收，
  对其后 30 分钟、60 分钟、到收盘的方向，全部在 ±7bp 内，|t| ≤ 2.2；同时段日内周期性（Heston–Korajczyk–Sadka）与恒指日内动量（Gao 等，661 日）均为 0。
- **波动高度可预测**：当日至今每分钟已实现波动预测余下每分钟波动，各检查点 R² 0.53–0.71，同一标的内相关 0.53–0.64，明显优于昨日振幅（R² 0.24–0.47）；最高 / 最低五分之一的余下波动相差 2.1–2.7 倍。
- 收盘前回吐：`−sign(开盘以来) × 到收盘` 约 +3～+6bp（t≈2），低于 0.10% 成本。

结构性理由：波动聚集是日内最稳健的统计事实；方向信息在流动性好的价位细标的上已被定价。交易员能从 1m 线可靠拿到的，是**还能走多远**（决定目标是否现实、止损多宽、仓位多大、成本占比），不是**往哪走**。

## 候选 V1：余下预计振幅

- 检查点 10:00 / 10:30 / 11:00 / 11:30 / 13:30 / 14:00 / 14:30 / 15:00；只纳入 `tpb >= 2`、昨日振幅 > 0、至今已实现波动 > 0 的观测。
- 目标：检查点下一根起到当日最后一根连续分钟的（最高 − 最低）/ 入场价，取对数。
- 模型：每个检查点各自 OLS，`log 余下振幅 = a + b·log(至今每分钟已实现波动) + c·log(昨日振幅)`，系数只在选择段拟合；80% 区间取选择段残差的 10% / 90% 分位。
- 验证门槛（全部满足）：
  1. 合计样本外 R² ≥ 0.40，且每个检查点 ≥ 0.30；
  2. 优于只用昨日振幅的同法模型（合计 R² 高出 ≥ 0.10）；
  3. 80% 区间覆盖率合计在 75%–85%；
  4. 预测最高 / 最低五分之一的实际余下振幅之比 ≥ 2。
- 通过则上看板：每个标的显示 `余下 ±x%`（预测余下振幅的一半，近似中枢两侧）及 80% 区间，作为目标是否现实、止损宽度、仓位的依据。

## 候选 R1：收盘前回吐

- 同上检查点与纳入规则；方向 = `−sign(检查点收盘 / 当日开盘 − 1)`；下一根收盘入场、最后一根连续分钟出。
- 验证门槛：毛均值 > 0 且按交易日聚类 t ≥ 2；做多、做空两侧毛均值都 > 0；净（0.10%）均值单独报告——净值 ≤ 0 时结论为「有统计倾向、不可交易」，不上看板为买卖信号。
