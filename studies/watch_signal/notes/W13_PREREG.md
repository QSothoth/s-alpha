# W13 预登记：可校准的信号强度分数

登记日期：2026-09-29。在读取逐事件结果、计算候选分数前登记；跑完不改候选、阈值或门槛。

## 目标与边界

用户需要比 `B/S`、`D+/-` 更直观的数值。这里把强度严格定义为：

> `score = 100 × P(下一根收盘入场后，30 根收盘退出的方向收益 > 0)`

因此 50 表示与抛硬币相当；分数不是主观加权、不是预期收益、不是下单建议，也不把成交量倍数直接当成强度。零收益不参与胜负概率拟合，但保留在收益斜率评估中。主收益仍是毛收益，不扣交易成本。

本轮只做开发段的因果走步筛查。2025H2、2026-08-17 至 09-23 都已被历轮研究看过，不冒充全新验证段；任何候选即使通过，也只冻结为待验证方案，不接入 `watch/`。

## 数据与因果切分

- 只读 W12 已登记的真实分钟与日线数据：2025-12-01 至 2026-08-14；沿用 W12 修正后的量比、按日期价位表、当前 `marks()`、日线背景和 `d1f30` 口径。
- 先用 2025-12 至 2026-02 训练；从 2026-03 起逐月预测。预测某月时只能使用严格早于该月的数据，月末才把该月结果加入下一月训练。
- 分钟数据逐标的日流式读取；只保存“日期 × 方向 × 固定分组”的计数、胜数和收益和，不保存全量事件，不构造 N×N 矩阵。

## 固定候选（共两个）

概率均用 Jeffreys 二项先验的后验均值 `(wins + 0.5) / (n + 1)`，避免零胜/全胜单元输出 0 或 100。

| 候选 | 固定分组 | 结构性理由 |
|---|---|---|
| P1 | `tpb<2`、`2<=tpb<5`、`tpb>=5` × `D+`、`D-`、`D?` | 只使用当前已有且最有证据的价位质量和日线背景 |
| P2 | P1 分组 × 完整触发组合（如 `BOS`、`FVG`、`BOS+FVG`） | 检验结构触发本身是否在相同背景下仍有增量区分力 |

P1 单元训练胜负样本少于 200 时退回当时全局概率；P2 单元少于 200 时退回同期 P1 概率。门槛固定，不搜索平滑强度或分箱。基准 P0 为当时全部历史标注的 Jeffreys 概率。

## 预定评估

主评估为 2026-03 至 08 的全部可评测标注，预测值均为月初冻结值：

1. 概率质量：Brier loss；候选相对 P0 的逐日平均 loss 差，按日做配对 t。
2. 校准：整体实际胜率减平均预测概率，绝对值以百分点报告。
3. 排序：用线性概率回归 `win ~ score`，标准误按交易日聚类；斜率表示分数每升 1 点，实际胜率改变多少百分点。
4. 经济方向：回归 `d1f30_bp ~ score`，同样按日聚类；另报 BUY、SELL 各自的胜率斜率。
5. 报告预测分数的最小值、最大值和标准差，避免一个几乎恒定的“假精确”分数。

候选必须同时满足：

- 至少 60 个预测交易日，BUY/SELL 各至少 10,000 个非零胜负样本；
- Brier loss 低于 P0，逐日配对改善 `t >= 2`；
- 胜率斜率 > 0 且按日聚类 `t >= 2`；
- 方向收益斜率 > 0 且按日聚类 `t >= 2`；
- BUY、SELL 的胜率斜率都 > 0；
- 整体校准误差绝对值不超过 1 个百分点，预测分数标准差至少 0.5 分。

通过者中取 Brier loss 最低者为唯一待验证方案，相同时优先 P1。若都失败，不追加候选、不调门槛，结论是现有字段不足以支持合理的数值强度。
