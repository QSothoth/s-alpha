# W23 预登记：当天累计 B/S 判断余下走势

登记日期：2026-10-13。在计算任何 W23 结果前登记；跑完不修改定义、候选、顺序或门槛。

## 为什么

W22 把每条 B/S 当独立 2R/1R 交易，毛期望 ≈ 0。用户的实际用法不同：看当天信号**累计**的方向（一直是 B / 一直是 S）判断当天行情。
结构性理由：单条 1m 突破噪声大，但同方向反复出现说明趋势结构在持续，可能对当天余下时间的方向有信息；持有到收盘，成本占比也远小于 1m 的 R。

关键对照：「一直是 B」时价格通常已经涨了。若累计信号不比「今天到现在涨没涨」更有用，它只是在复述价格，看板表头的涨跌已经给出。所以**必须优于同一观测上的日内动量**。

## 定义（固定，不做网格）

- 信号：现行 `marks()`（`w12_audit.replica(..., 'B0')`）中 `tpb >= 2` 的标注；只用检查点及之前的标注（标注本身因果）。
- 检查点：10:30、11:30、13:30、14:30（取该分钟 K 线）；该检查点当日 `tpb >= 2` 才纳入。
- `N` = 检查点前 B 的条数 − S 的条数。
- 结果：检查点下一根收盘入场，当日最后一根连续分钟（15:59）收盘出，按方向取正负；成本 0.10% 往返。t 按交易日聚类。
- 动量基准 `M`：同一观测上 `sign(检查点收盘 / 当日开盘 − 1)`；两者同向时差为 0，差值只来自分歧观测。

## 三个候选（固定顺序）

1. `K1`：`|N| >= 2`，方向 = `sign(N)`；
2. `K2`：最近 3 条标注同向（当日至少 3 条），方向 = 该方向；
3. `K3`：当日至少 2 条且**全部**同向（「一直是 B / S」），方向 = 该方向。

## 数据

- 选择段：2025-12-01 → 2026-08-14（`data/watch-hk1m-train-v1`）。
- 验证段：2024-12-02 → 2025-05-30（W18 数据）；W22 未评测该段，此前从未计算过信号之后的价格结果；只评测一次。
- 2024H1 继续保留。

## 门槛（选择段与验证段相同，验证段笔数门槛减半）

1. 观测数 ≥ 1,000（验证 ≥ 500），有观测的交易日 ≥ 40（验证不设）；
2. 可交易：净收益（0.10%）均值 > 0，聚类 t ≥ 2；
3. 两侧：做多、做空两侧净均值都 > 0；
4. 增量：同一观测上 `候选方向收益 − 动量方向收益` 均值 > 0，聚类 t ≥ 2。

四条全过才进验证段；验证段四条全过才上看板（以「今日累计」形式显示方向与验证数字）。只过 1–3、未过 4 的，结论写成「与日内动量等价」，不上看板。

## 报告

每个候选、每个检查点：观测数、方向占比、毛 / 净均值 bp、聚类 t、两侧、动量基准同观测均值、增量差与 t、与动量同向比例。
