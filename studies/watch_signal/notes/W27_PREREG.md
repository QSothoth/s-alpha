# W27 预登记：不依赖历史分钟数据的 B/S 强度档（港股 / A 股 / 美股通用）

登记日期：2026-10-13。在计算任何 W27 结果前登记；跑完不修改定义或门槛。

## 为什么

W25 的强度档要用几个月的历史分钟线拟合分位表；A 股没有历史分钟数据，美股要扣额度，用户要求不依赖历史分钟数据。
这里改成**固定换算**：三项都用日 K 归一化成与市场、价位无关的量，再用固定的常见阈值打分。等级的含义由定义给出，不靠拟合，所以可直接用于任何有日 K 和当天分钟线的市场。

## 定义（固定，不拟合）

`side = +1 / −1`；`ATR20%` = 最近 20 个已完成交易日真实波幅 / 前收 的均值（日 K）。

1. 量 `v = clip(log2(当根量 / 此前 20 根均量), −1, 2)`，得分 `(v + 1) / 3`（0.5 倍及以下 0，1 倍 1/3，2 倍 2/3，4 倍及以上 1）；
2. 大盘 `m = clip(side × (指数信号分钟 / 指数昨收 − 1) / 指数 ATR20%, −1, 1)`，得分 `(m + 1) / 2`；
3. 个股 `p = clip(side × (信号收盘 / 昨收 − 1) / 个股 ATR20%, −1, 1)`，得分 `(p + 1) / 2`。

综合 = 三项得分均值；档位 = `min(5, 1 + floor(综合 × 5))`。指数：港股恒指，A 股沪深 300，美股 SPY。任一项缺失则无档位。

## 检查（只用本地已有的港股数据，不拉新数据）

段：2024-12-02 → 2025-05-30（W18 数据）与 2025-12-01 → 2026-08-14（训练数据），各报一次。日 K 取 `data/day_2024-06_2026-09.csv.gz`（含恒指）。

门槛（两段都须满足）：
1. 每档占比 5%–40%（固定刻度，不强求均匀）；
2. 三项得分均值随档位单调上升；
3. 价位三层（`tpb < 2`、`2–5`、`>= 5`）每层每档 ≥ 3%；
4. ≥ 80% 的标的（标注 ≥ 50 条）出现过 5 档；
5. 上午、下午 5 档占比都在 3%–40%。

A 股、美股：本轮没有历史分钟数据可查，上线后从看板日志（`MARK` 事件）积累，满 20 个交易日按同样门槛检查一次并写报告；在此之前 README 注明「港股已核对分布，A 股 / 美股尚未」。

## 必须报告（不作门槛）
