# W22 预登记：按交易计划评估 B/S，给出「做 / 观望」

登记日期：2026-10-13。在计算任何 W22 结果前登记；跑完不修改定义、候选、顺序或门槛。

## 为什么

用户（交易员）看到一条 B/S 时要回答的是：做不做、错了在哪认、对了在哪走、历史上这样做每笔赚几个 R。
W13–W16、W19–W21 的强度要么不预测、要么跨时期失败；加粗只有一档，粒度太粗。W2 证明按摆动点 `inv` 出场亏钱，
而且它会落在信号价另一侧，不能当止损。本轮把每条信号变成一笔**固定规则的交易**，直接评估净期望（单位 R）。

结构性理由：一根 1m K 线的波动尺度由 ATR 决定，止损和目标按 ATR 设才在不同价位、不同标的之间可比；
目标 2R / 止损 1R 对应用户「盈亏比优先」，盈亏比由构造固定为约 2，问题只剩「先到目标的比例够不够」。

## 交易规则（全部固定，取常见值，不做网格）

- 信号：现行 `marks()`（`w12_audit.replica(..., 'B0')`），与看板逐条一致；只评估 `tpb >= 2`（`tpb < 2` 已证实偏反向，W2）。
- 入场：信号后下一根收盘价 `E`（与 W2–W21 一致）。
- `R = 2 × ATR14`，ATR14 为信号根及之前 14 根高低差均值。
- 止损 `E − R`（BUY）/ `E + R`（SELL）；目标 `E + 2R` / `E − 2R`。
- 从入场后一根开始逐根检查：同一根同时触及止损和目标按**止损**；开盘已越过止损按开盘价出；触及目标按目标价出。
- 超时：入场后 60 根，或当日最后一根连续交易分钟（15:59），按收盘价出。
- 成本：每笔往返 **0.10%** × `E`（与 README 已有口径一致），折成 R 扣除；另报 0.25% 敏感性，不作门槛。
- 每条信号独立一笔（看板每条都显示），重叠不合并；t 按交易日聚类。

## 五个候选（固定顺序，全部在 `tpb >= 2` 内）

股、指方向：`s = side × (信号收盘 / 个股昨收 − 1)`，`m = side × (恒指信号分钟收盘 / 恒指昨收 − 1)`。

1. `C1`：全部；
2. `C2`：`D+`（现行加粗）；
3. `C3`：顺势，`s > 0` 且 `m > 0`；
4. `C4`：逆势，`s < 0` 且 `m < 0`；
5. `C5`：`D+` 且逆势。

`D+` 沿用 W6 定义，日线取 `data/day_2024-06_2026-09.csv.gz`；缺日线的信号不进 C2/C5。

## 数据切分

- 选择段：2025-12-01 → 2026-08-14（`data/watch-hk1m-train-v1`，恒指 `data/watch-hk-index1m-v1`）。
- 验证段：2024-12-02 → 2025-05-30（`studies/watch_signal/data/w18_2024-12_2025-05_1m.csv.gz`，含恒指）。此段在 W18 只做过描述性市场支持检验，从未计算过信号之后的价格结果；只评测一次。
- 2024H1（W19 数据）原样保留，不在本轮使用。
- 沿用 W16 质量规则：有无效 OHLCV 的股票整只排除。

## 门槛

选择段，每个候选：
1. 笔数 ≥ 300，有交易的日数 ≥ 40；
2. 净期望（0.10% 成本）> 0，按交易日聚类 t ≥ 2；
3. BUY、SELL 两侧净期望都 > 0。

通过者进入验证段（全部通过者一起，各评一次）：
1. 笔数 ≥ 150；
2. 净期望 > 0，聚类 t ≥ 2；
3. BUY、SELL 两侧净期望都 > 0。

## 看板规则（结果出来前固定）

- 验证通过的候选：信号显示 `做`，附计划价（止损 / 目标，以信号收盘近似入场价）和**验证段**的胜率、净期望 R、笔数。多个通过时按特异性取一个：C5 → C2 → C3 → C4 → C1。
- 其余信号显示 `观望`，附其所在 `tpb` 档在验证段的净期望 R（描述性）。
- 一个都不通过：全部 `观望`，如实写进 README；不降门槛、不换目标重跑。
