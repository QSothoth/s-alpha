# W32 预登记：强度档能否指导交易（幅度、方向、收益）

登记日期：2026-10-15。在计算任何 W32 结果前登记；跑完不修改定义、候选或门槛。

## 为什么

用户要求强度档「真的可以指导交易」。W22–W27、W31 已显示 1m 线上方向不可预测、档位不预测到收盘收益；
但档位里权重最大的是量，放量通常意味着之后波动更大。结构性理由：量与已实现波动的聚集是日内最稳健的事实之一，
若档位对**之后能走多远**有超出 W24 `left` 的信息，它就能指导目标远近、仓位与是否值得做（方向仍由交易员给）。
同时把方向与收益两个候选放进来，如实检验，不预设结论。

## 定义（全部沿用现行实现）

- 信号：现行 `marks()`，只用 `tpb >= 2`；档位：W27 三项得分 + W31 界线 0.40 / 0.57 / 0.73 / 0.86。
- 入场：信号下一根收盘 `E`；`ATR14` 为信号根 1m ATR14。
- 余下振幅 `rest` = 入场后到当日最后一根连续分钟的（最高 − 最低）/ `E`。
- `left` 预测：信号时刻最近一个已过检查点的 W24 公式（冻结系数）给出的余下振幅；信号早于 10:00 的不纳入 M1。
- 有利 / 不利波动：入场后至收盘，信号方向上的最大有利、最大不利价格偏移，单位 ATR14。

## 三个候选

1. **M1 幅度**：`log(rest / left预测)` 的档位均值随 1 → 5 严格上升；5 档减 1 档的差按交易日聚类 t ≥ 3；且 5 档的 `rest / left` 几何均值 ≥ 1 档的 1.3 倍。
2. **M2 方向**：（有利 − 不利）/ ATR14 的 5 档均值 > 0 且 t ≥ 2，并且 5 档减 1 档 > 0、t ≥ 2。
3. **M3 收益**：5 档到收盘方向收益扣 0.10% 成本后均值 > 0、t ≥ 2。

## 数据

- 选择段：港股 2025-12-01 → 2026-08-14（日 K 用 `data/day_2024-06_2026-09.csv.gz`）。
- 验证段：港股 2024-01-02 → 2024-05-31（`data/w19_2024h1_1m.csv.gz`，此前只用于 W19 的描述性检验，从未计算过信号之后的任何价格结果）。该段没有现成日 K：个股与恒指的日 OHLC 由同文件 1m 连续时段合成（开 = 首根开、高低 = 全天极值、收 = 末根收），每段前 20 个交易日无 ATR20、不纳入。
- 只在选择段通过的候选进入验证段，验证段只评测一次。不拉任何新数据。

## 上线规则

验证通过的候选才上看板：M1 通过则每条信号附「预计还能走多远」（`left` × 该档在验证段的 `rest/left` 倍数）；M2 / M3 通过才允许在 README 写方向含义。全部失败则如实记录，档位维持「描述力度」。
