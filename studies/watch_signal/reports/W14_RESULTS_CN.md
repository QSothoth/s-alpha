# W14：极端涨跌日压力测试未通过，当前强度设计不够稳健

日期：2026-09-29。预登记：[W14_PREREG.md](../notes/W14_PREREG.md)。脚本：[w14_extreme.py](../code/w14_extreme.py)。

## 结论

W13 冻结的 P2 概率分数在恒指极端上涨、下跌日总体仍有一点正向排序，但**没有通过全部预登记门槛**：极端下跌日 BUY 侧胜率斜率为负；20 个极端日合计的 30 分钟毛收益斜率不显著。当前 `tpb × 日线背景 × 触发类型` 的设计不足以稳健描述极端市场里的信号强度，继续保持不上线。

这不是说分数完全无信息：UP、DOWN 的总体胜率斜率、总体收益斜率点估计都为正，Brier 也都略优于滚动基准；但“点估计略正”达不到一个可交付强度分数应有的稳定性。

## 门槛判定

| 门槛 | 结果 |
|---|---|
| 两类样本量 | 通过 |
| UP、DOWN 总体胜率斜率均正 | 通过 |
| UP、DOWN 总体收益斜率均正 | 通过 |
| 两类 BUY、SELL 分侧胜率斜率均正 | **失败：DOWN BUY 为负** |
| 两类 Brier 均不差于基准 | 通过，但改善极小 |
| 合计胜率与收益斜率均 `t>=2` | **失败：收益 t=1.05** |
| 合计校准误差不超过 2 点 | 通过 |

总判定：**FAIL**。

## 含义与后续

1. 大跌日中，模型给 SELL 的排序仍为正，但 BUY 的排序反向；不能只看当天顺市场方向的一侧，否则会夸大合理性。
2. 大涨日实际胜率比预测低 2.14 点，大跌日则高 3.25 点，说明同一个无市场状态的概率基线在两类行情中存在明显漂移；两边合并后误差互相抵消，不能只看合计校准。
3. 下一候选若继续研究，结构上应显式允许“市场极端状态 × BUY/SELL”的交互，而不是给现有 P2 随意调分。它必须重新预登记，并仍需未来未使用数据验证。

本轮不修改 W13、不接入看板、不启动采集。
