# W13：概率型信号强度通过开发段走步筛查，尚未获准上线

日期：2026-09-29。预登记：[W13_PREREG.md](../notes/W13_PREREG.md)。脚本：[w13_score.py](../code/w13_score.py)。

## 结论

把强度定义为“下一根收盘入场、30 根后方向收益为正的概率”，而不是把指标任意加权。两个固定候选在开发段按月向前预测时均通过预登记门槛；按最低 Brier loss 的选择规则，加入触发类型的 **P2** 胜出，冻结为未来验证候选。

**本轮不接入 `watch/`。** 所有可用历史区间都已在旧研究中被查看过，本轮只有因果走步筛查，没有从未使用的独立验证段。分数不能称为已验证胜率，更不能用于自动下单。

更重要的是，数据没有支持夸张的强弱区间：开发段走步预测主要只有约 45–53 分。50 才表示方向胜率 50%；低于 50 的信号即使相对别组更好，也不应被包装成“强信号”。

## 固定方法

- P1：价位密度三档 × `D+ / D- / D?`。
- P2：P1 再乘完整触发组合；单元少于 200 个非零结果时退回同期 P1。
- 每个概率使用 Jeffreys 后验均值 `(wins + 0.5) / (n + 1)`。
- 2025-12 至 2026-02 只训练；2026-03 起逐月预测，每个月只能使用严格更早月份。
- 标签为 `d1f30 > 0`；零收益不进入二项胜负，但进入收益斜率。
- Brier 改善按每日平均误差相对同期滚动全局概率配对；胜率与毛收益斜率的标准误按交易日聚类。

## 开发段走步结果

预测覆盖 2026-03 至 08，共 113 个交易日、198,320 个非零胜负样本；BUY 91,632，SELL 106,688。

| Brier loss | 0.248821 | **0.248793** |
| 滚动基准 Brier | 0.249119 | 0.249119 |
| 每日 Brier 改善 t | +5.71 | +5.55 |
| 胜率斜率：分数每升 1 点 | +1.140 点 | +0.999 点 |
| 胜率斜率 t | 8.53 | 9.26 |
| `d1f30` 毛收益斜率 | +1.223 bp/点 | +0.986 bp/点 |

表中“每日 Brier 改善 t”把 loss 差的负向改善改写为正数便于阅读；脚本原始量为 P1 `−5.71`、P2 `−5.55`。

P2 的 Brier 只比 P1 低 `0.000028`，幅度很小。P2 是按预登记规则机械胜出，不能据此宣称触发类型具有很大的额外价值；独立验证若失败就不部署，不回头改选 P1。
