# RG1 解释：绝对方向质量与相对对照增量不是同一问题

2026-09-26。依据 [RG1 预登记](RG1_PREREG.md)、[运行记录](RG1_RUN_RECORD.md) 与 [首次机器报告](../reports/rg1_asset_transfer.json)。本文是在结果已见后的解释，不是修改预登记、追加候选或第二次验证。正式结论仍为 **`ASSET_TRANSFER_NOT_PASSED`**。

只重新汇总已生成的 118 条事件及其原始固定 peer 标签；未重跑信号、读取其它 ETF 价格、计算新时钟／窗口收益，也未按结果增加过滤。

## 1. 已经得到什么证据

118 条提示全部有正股 30 分钟标签，覆盖 99 个活跃日期；66 正、51 负、1 零。方向命中率 55.93%，平均正／负幅度比 1.898，PF 2.456，均值 +22.95bp，登记的日期聚类单侧下限 +1.20bp；两半均值分别 +16.97／+29.81bp。它们支持一个有限判断：这三个资产、这个固定事件与窗口中，反转方向的终点标签表现为正，绝非“所有观察均无方向价值”。

但 paired 只有 64 条，覆盖 54.24%，增量 +3.44bp，下限 −2.09bp。覆盖和增量下限两项未过，不能改判晋级、撤掉 paired 门槛或说原 DS2 已获挽救。低覆盖是证据不足；负下限是不足以确认正增量，都不等于证明真实增量为零或为负。

这仍是看过 DS2／跨期限描述后提出的反向假设，且资产迁移共享旧市场日期。本轮区间没有修复全部历史搜索、资产选择和时间依赖问题；+1.20bp 的 raw 下限不是“扣除任何成本后仍可靠”的保证。正股终点标签也没有给出期权价差、时间价值、IV、成交价或实际 0DTE 挂牌身份。

## 2. 固定 matched cohort 的会计分解

每条 matched 事件先把其原 peer 标签等权平均，再对 64 条事件等权汇总；不能把全部 peer 链接直接平均，因为部分事件有两个 peer。48 条有一个 peer，16 条有两个；这 80 个链接不等于 80 个独立对照。

| 原有队列／标签 | 数量 | 所在日期数 | 均值 bp |
|---|---:|---:|---:|
| 全部事件自身 | 118 | 99 | +22.9523 |
| matched 事件自身 | 64 | 46 | +21.3830 |
| 同 64 条事件的逐事件 peer 均值 | 64 | 同上 | +17.9477 |
| 同 64 条事件的自身减 peer | 64 | 同上 | +3.4353 |
| unmatched 事件自身 | 54 | 54 | +24.8123 |

原始数值满足：

```text
matched 自身均值 = 21.3830 = 17.9477 + 3.4353 bp
全部自身均值 = (64/118) × 21.3830 + (54/118) × 24.8123 = 22.9523 bp
```

未四舍五入计算的逐事件差值与存档 `paired_lift` 完全一致；两项均值恒等式误差均小于 `1e-12 bp`。matched 与 unmatched 的日期有一天重叠，所以日期数不应相加。

54 条 unmatched **全部因为当时没有合格 peer**，不是自身未来标签缺失，也不是有 peer 后缺少其未来窗口。不得把这 54 条补成零增量、认为其中没有方向信息，或因为它们均值较高就新建“只做无 peer”版本。是否能匹配本身取决于当天其它资产的开盘状态，因此不能把 64 条看作 118 条的随机子样本；也不能用全部 raw 均值减 matched control 均值来声称总体增量。

## 3. 是否只是共同市场冲击

matched 中，控制标签均值 +17.95bp 与事件自身 +21.38bp 同为正；64 条中有 50 条自身与逐事件控制均值同号且非零，12 条异号，2 条至少一方为零。这与“同日、同钟点、相近早盘状态的资产共同回吐”一致，说明不能把全部自身方向变动归功于 20 日边界。

但这不是市场冲击的因果归因，也不是所谓“解释了 84% 波动”：这里比较的是条件均值，未估计共同因子或方差分解。当前对照还存在三项限制：

- 只有三个行业 ETF，同一市场日期反复出现，行业、波动率与市场暴露并不完全相同；本次没有新增市场基准或 beta 模型。
- peer 也经过活动度及原方向 opening drive 门禁，所以它反映的可能是广泛早盘回吐，而非无条件市场漂移。
- 登记允许 peer 本身也触发 G20。两边可能共享同一种边界结构；增量弱不能单独证明边界结构没有作用。

因此，可以说“共同条件下的回吐占 matched 均值的重要部分，尚未证实 RG1 有独特横截面增量”；不能说“已证明全部来自市场冲击”，更不能说“所以不存在上游绝对方向用途”。对用户的上游方向任务，绝对方向质量是相关证据；对宣称关键位机制增加了信息，matched 增量是另一层证据。**两种用途应区分，但本轮事先承诺的联合门槛必须照守。**

## 4. 一个最小后续研究草案，不在此执行

建议是“固定 RG1 的前瞻方向质量与共同状态对照”，不是继续调突破阈值，也不是把本次失败重新命名为通过。

只保留现有三只、同一 G20 首事件、反转方向、活动条件与 +30 分钟标签；在另行冻结的未来日期区间一次性汇总，不用已暴露至 09/24 的记录冒充新验证。事前分别写清两个问题：

1. **绝对方向问题**：原 RG1 提示后是否仍有正的方向化均值、可接受的胜率／幅度比与频率。raw 作为该问题的主证据，样本量、日期数、经济幅度及区间要求须重新明确冻结；这不改变 RG1 的旧联合判决。
2. **结构增量问题**：在每次同钟点，以另两只中通过原活动／drive 门禁、但该时点不满足原 G20 结构者作固定对照；新增的只是对照定义，不筛改 RG1 事件。另固定记录 SPY 的同钟点同方向标签，beta=1 差值只描述市场共振，不称因果 Alpha。名单先于未来标签，无对照照记；不为了覆盖率再扩池或改匹配条件。

这样的结果可区分“绝对方向可重复，但普通同状态资产也回吐”“对市场基准仍有差值，但不超过普通同状态对照”“边界事件还有额外增量”。它仍不是随机实验。若非 G 对照更加稀疏，结构问题应判证据不足，而不是降低门槛。

具体期限与统计要求须在任何新增标签前正式登记，固定到期才汇总，不看到盈利就提前停止。现有三只约八年仅 118 次，短期前瞻很可能样本不足；应接受这个时间成本，不承诺数周就能确认。此草案未授权或启动后台采集，没有新 API 请求、额度或代码实现。
