## 旧 OR 研究动机与边界

旧研究用盘前信息预测全天方向，以及 S28 在 09:45 排多空名单，都没有得到可靠的成本后结果。区间方法提供的是可观察的触发点和失效位置：区间外确认才考虑，退回中点则退出，避免必须在每天开盘时选边。但区间固定不等于方向确定；假突破、错过直接趋势、确认后剩余空间不足仍会让策略失败。

正股上的 `2R` 目标不是期权 2:1 盈亏比。期权的时间价值、隐含波动变化和价差都影响结果，因此OR1离线评测直接使用已有真实期权分钟成交；OR2/OR3仅作正股方向诊断，不能拿正股涨跌折算期权收益。

## 数据和到期日

“135 / 35 / 45”可作为描述某些标的挂牌习惯的简称，程序不按星期几猜测当日 0DTE。盘中先查 OpenD 到期日，再查当天真实期权链；历史只认已冻结的 `expiry == trade_date` 合约。挂牌日与假期安排会变化，参见 [Cboe 当期周权名单](https://www.cboe.com/available_weeklys/)（2026-09-25 核对）。OpenD [期权链文档](https://openapi.futunn.com/futu-api-doc/quote/get-option-chain.html) 明示不支持查询已过期链，不能承诺事后补齐历史期权样本。

| 来源 | 本轮用途 | 限制 |
|---|---|---|
| OpenD | 当天到期日、期权链、正股分钟行情、期权快照、交易日历；本地真实期权回放 | 依赖已有行情权限；盘中扫描只用订阅 K 线，不请求历史 K 线 |
| Yahoo / 腾讯 | 沿用 [已有日线交叉核验工具](../../archive/us_preopen_bias/code/verify_daily.py) | 本轮没有新增下载器；日线核验不能替代美股期权分钟成交或历史 bid/ask |

当前 `scan/capture` 合约选择先固定开盘价最近的标准挂牌行权价，同距取较低；再要求该档 CALL/PUT 唯一、可用且为100股合约。缺腿、暂停或重复不改选更远一档。之后按信号方向取一边；不是信号时刻重新选 ATM，也不搜索事后收益最好的合约。历史数据来自已有 [DATA](../../../docs/DATA.md) 登记的 custody Release，复用其哈希与到期日校验；旧V5没有保存与当前入口同等完整的标准/100股/唯一双腿链证据，不能倒推其全部通过这些新增条件。详细边界见 [身份审计](OPTION_IDENTITY_COVERAGE.md)。

## 使用

仓库根目录运行；离线只需要标准库，盘中需要已安装的 `futu-api` 和 OpenD。

```bash
# 四个候选一起做本地诊断；输出文件必须不存在
python3 -m studies.us_opening_range.replay \
  --dataset data/custody-0dte-v5 \
  --dataset data/custody-eval-2026-09-18-v2 \
  --out /tmp/or1-diagnostic.json

# 常规交易时段内单次只读扫描；此候选只是调用示例，不代表胜出
/opt/futu-opend/venv/bin/python -m studies.us_opening_range.scan \
  --symbols SPY,QQQ,AAPL,NVDA,TSLA,AMD --candidate OR30_retest

python3 -m unittest discover -s studies/us_opening_range/tests
```

OR2 仅可运行登记的旧开发数据，不会自动读取新ETF或今天期权留出；输出含按日期重抽下限和预设筛选门槛，但无论得分如何都不能授予独立验证通过：

```bash
python3 -m studies.us_opening_range.context_replay --out /tmp/or2-diagnostic.json
```

OR4复现只接受预登记旧数据，并同时校验09-18的manifest身份及CHECKSUMS行情指纹：

```bash
python3 -m studies.us_opening_range.pricing_replay --out /tmp/or4-diagnostic.json
```

新增 `capture` 是盘后一次性保存工具：只用当前订阅 K 线，不调用历史 K 线接口，不装定时任务；最多30标的，实际仍受剩余订阅额度约束，错误明确记录。仅允许美东当天、收盘后20分钟起调用，目录必须不存在。正股检查全日390/210根；期权允许稀疏成交，不宣称具备完整分钟或历史盘口。

```bash
/opt/futu-opend/venv/bin/python -m studies.us_opening_range.capture \
  --symbols SPY,QQQ,IWM --out data/new-unpublished-capture
```

2026-09-25 已按事前26标的池有限采集52张真实双边合约，通过校验后保持未评测；全部本次订阅已释放，历史请求0。仅有一天，不能据此达成独立期权验证门槛。数据已发布为 `or-alpha-20260925-v1`，不在 Git。

扫描最多 20 个标的，查完退出。需要定期查看时由用户自行调用，未安装定时任务。只关闭自身行情连接，OpenD 的短时订阅额度释放遵循服务端限制。

扫描状态：`WAIT` 表示区间/确认尚未满足；`HISTORICAL` 表示信号已过时或已触发退出；`SKIP` 给出无当日到期、价差过宽、行情过时等原因；`ERROR` 是数据/接口错误；`OBSERVE` 是通过当前检查的研究观察项。后者只按价差从小到大排序，不代表胜率排名。买卖两侧价格和数量必须有效，快照更新时间不超过 60 秒，价差/中间价不超过 10%；信号年龄不超过 5 分钟，最新正股分钟不能滞后超过 2 分钟。快照更新时间并非买卖两侧各自的更新时间，不能保证能按显示价成交。

盘中可用性筛选没有历史 bid/ask 可供重放，因此离线候选收益**不包含**扫描的价差/报价年龄过滤效果；两者共用方向信号，不能宣称完整交易流程已经回测验证。

## 回放与结果边界

本轮实际准入数据合计 21 个交易日、77 个标的日（154 张双边合约）；多数个股只覆盖少量日期，SPY 占比高。V6.1 中追加的 09-16 样本缺开盘 ATM 标记和收盘时间，被严格校验拒绝，因此使用仍有效的 V5 加 09-18 双边数据；运行前更正保留在预登记末尾。这些数据此前已多次研究，全部只用于诊断；文件名中的 validation 不能恢复其样本外资格。结果见 [诊断报告](../reports/RESULTS_CN.md)。

回放逐标的日读取，仅保留当日正股和两张期权 K 线；不加载全市场全历史矩阵。每个候选都保留不交易的标的日，分别统计每笔成交收益、全部标的日等权收益和先按日平均再对日期等权的收益。这些均不是账户复利回报。

成交口径：信号/退出决策之后 1–2 分钟内第一根有成交量的期权 K 收盘价，按该分钟振幅 25% 作不利滑点，每边 $0.65/张；另报 50% 滑点压力。未成交保留为 0，缺失可执行退出按期权价值归零并收取已执行入场手续费，单独计数。这是成交 OHLCV 估算，不是实际历史盘口成交价。CSV 的 `close_time` 统一是带美东时区的收盘时间，开盘区间首根 09:31；重复、乱序或不完整的正股分钟拒绝。

若以后继续端到端期权研究，仍须先冻结规则、登记新数据身份和选择／验证日期。OR1 CLI 固定输出 `DIAGNOSTIC`，没有正式选择、验证锁或自动授予 ACCEPT。12个新ETF正股历史及1条已知SPY到期链的[历史分钟可用性测试](OPTION_HISTORY_PILOT.md)均已完成并发布；成功下载不代表补齐独立期权验证。本轮上游信号无需先完成这一整套交易检验，但不能借此宣称期权盈利。
