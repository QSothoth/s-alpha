**1. 盘中模式**
- `scan run <市场> --provisional`：只取一次快照，7 个系统共用，不写盘；结果单独存成 `out/<市场>_<日期>_provisional_<HHMM>.json`，看板上标明“盘中临时”。
- 卖出包括跟踪线离场。市场未开盘、已收盘、快照日期不对、昨收对不上时拒绝运行。
- 打印各阶段耗时，三个市场各量一次；合计跑不进 10 分钟，先报瓶颈再提方案。
- `scan diff <市场> <日期>`：对照临时结果和收盘后的正式结果，分成一致、收盘后消失、尾盘漏掉三类，并给出成交价差。
- 单测覆盖：只用快照时刻已知的数据、不写盘、只取一次快照、各种拒绝情况、diff 分类。
