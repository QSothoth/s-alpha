**不能改的口径**（docs/TRADER_PROTOCOL_CN.md）
- 数据：冻结 Release `trader-data-v1`、评测区间 2024-01-02 → 2026-10-16、比对只在 frozen 下跑；不拉新数据。
- 引擎现有字段的含义不变；所有已登记系统的多头结果必须逐位不变（`compare run us,hk` 前后对比）。
- 门禁四项照用：数据、不看未来、成交价在当日区间内、胜率 ≤ 35%（多空合计的已平仓交易）。如果某位交易员的空头按原话本身胜率就高、合计超过 35%，不要改门禁，写清楚交给我判断。

**空头特有的设定**（预登记里写明，报告里标注）
- 只在美股研究空头。港股只有指定证券能沽空，我们没有这份名单；A 股融券受限。港股、A 股只报“不适用”，不调参。
- 借券：数据里没有可借数量和费率，一律假设能借到，并给引擎加一个默认关闭的借券成本字段（按持仓市值每日计提，先用年化 3%），先写执行时点单测，默认关闭时所有现有结果不变。小盘、热门股做空会被高估，报告里单列“价格 < 10 美元或 20 日成交额 < 2000 万”的空单盈亏。
- 空头止损在上方：入场当日高点（原话另有规定的照原话），宽度下限 1%；跳空高开越过止损按开盘价出。
- 反向 ETF（Clement 的 SQQQ、SOXS）和做空 SPY（Minervini）需要 ETF 数据，不在 trader-data-v1 里：先做个股版本；确实需要时停下来问我是否补 ETF 数据。

**逐人做**（顺序：Martin → Qullamaggie → Oliver Kell → Christian Flanders → Clement Ang → Mark Minervini；Minervini 是 B 级，只做基线）
- 起点：systems.py 里他当前登记的版本（多头配置不动）+ 按原话的空头环节。空头形态写进他的研究模块（`studies/<id>/replicate.py` 的 setups / build），和多头一样按日 K 掩码、只用当时可知的数据，先写触发日和执行时点单测。
- 环节：空头选股池 → 空头形态 → 入场与止损 → 空头离场（分批、跟踪线、持有期）→ 空头仓位与市况开关（多空顺序：当天先开多再开空，沿用 Martin R53 的 short_last 思路）。
- 每人先做两组对照，写进 `studies/<id>/reports/SHORTS_CN.md`：
  - 只做空的账户：收益、回撤、笔数、胜率、平均赚亏、持有期、同池随机做空的安慰剂（同一天、同样止损宽度）；
  - 多空合计 vs 只做多：总收益、回撤、分年，以及大盘下跌时段（股票池等权指数在 50 EMA 下方的日子、按月）的表现。空头的价值主要看它在下跌时段补了多少，不只看全段收益。
- 轮次按 trader-replication 的规则：先预登记（`notes/rounds/S*.json` + `PREREG_S*.md`），每轮 ≤ 5 个候选，跑完不改，失败照记，进否定登记表；候选只来自他的原话或逐笔诊断，不做网格搜索；报数前核对头部空单的日期和价格。
- 选择：在门禁通过、多头行为不变（多头笔数、持有期、胜率不变）的前提下，看多空合计的账户（分年、回撤、下跌时段）是否比只做多好；改善不能只来自一年。证据不足时回退到更接近原话的版本。
- 预算：每人空头最多 15 轮；轮次没用完、差距没定位之前不停。写检查点时说明差距在哪一层（规则、执行、数据缺口如借券和 ETF）。
