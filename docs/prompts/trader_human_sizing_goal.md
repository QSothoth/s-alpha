/goal 在“像人能做的交易”约束下，重新优化已登记的交易员系统：不加融资，但允许按把握分档定仓位，让账户靠少数重仓的好交易接近他们公开的收益，而不是靠几十只同时持仓和高频进出。每位交易员的新版本先在研究里过预登记轮次和门禁，再由我决定是否登记。

**硬约束**（每个候选都必须满足，不满足的候选直接作废，不进比较）
- 不融资：任何时刻多头市值 + 空头市值 ≤ 100% 净值（`max_gross ≤ 1.0`），不产生融资利息。
- 同时持仓 ≤ 10 只（多空合计），每天新开 ≤ 3 笔（多空合计），每年开仓 ≤ 250 笔。
- 单只仓位上限可以分档，最高 50% 净值；仓位档最多 3 档（例如试探 / 标准 / 重仓）。
- 同一只票止损或卖出的当天不再买回。
- 上面的数字是研究者取值，取整，不调。报告里每个候选都要列：最大同时持仓、平均同时持仓、最大总敞口、每年笔数、每天最多新开笔数。

**为什么这样改**（2026-10-20 对冻结版本的拆解，美股 trader-data-v1）
- Flanders 2024 年 +19%，他 +434%：用他公布的胜率和赚亏倒推，他 2024 年平均仓位约 32%，2025 年约 9%；我们两年都是 12–13%，所以只有 2025 年对得上。台账里 NVDA（1% 止损，150–220% 仓位）和 SMCI（约 50%）两笔占了他 2024 年约八成利润。融资这部分不复刻，但“少数票重仓”可以在 100% 以内做。
- Flanders R15 实际 85% 是 EP 单；他台账里有一半是 VCP、回踩、power play，R15 里没有这些形态。
- Martin 在交给引擎前就把每天截到 4 笔，截断后的 2032 个信号里有 1030 个是已持有的票，名额被浪费掉。另外，R74 的总敞口是 280%，违反新约束。
- Clement 赢单拿 10–14 天，他是 3 天；总敞口 200%、同时持仓约 15 只，违反新约束。
- 各人共有的问题：收盘买、当日低点止损，11–26% 的交易跳空穿过止损，亏损单平均 −1.2R 到 −1.5R。

**1. H0 基线**（只测量，不调参）
- 每位交易员把当前登记版本原样套上硬约束：总敞口压到 100%；同时持仓、每天新开、每年笔数按上限截断；其余不变。这就是 H0。
- 登记表记下每人从“登记版本”到 H0 损失了多少，先说清楚现在的收益有多少来自融资和持仓数量。
- 以后每轮都和 H0 比，不和原登记版本比。

**2. 逐人优化**
- 顺序：Christian Flanders → Clement Ang → Martin Luk（这三位有数据期内的公开成绩）→ Oliver Kell → Qullamaggie → Marios Stamatoudis。Mark Minervini 是 B 级，只做 H0。
- 候选只来自他的原话或台账 note 列，例如：
  - 他说过的重仓条件（EP 的质量、突破前的收紧、强势龙头）；
  - 他说过的加仓方式（新买点、持仓盈利后加）；
  - 补上他用过但我们没有的形态（Flanders 的 VCP、回踩、power play）；
  - 他自己的持有期（Clement 的 3 天）。
- 名额紧了以后，“选哪几只”比“开多少只”重要。排序优先用他的原话，不要用事后看哪个排序赚钱来挑。
- 仓位档不能为单笔拟合，不能写“NVDA 那种就重仓”。重仓条件要按整份台账的机制定义，并报告它在全部交易里触发了多少次、多少笔赚钱。

**3. 选择与验证**
- 选择段 2024-01-02 → 2025-12-31，美股。2026 段已被 V1 / V2 用过：只报告、不作判断，独立检验只剩冻结后的前向记录。不拉新数据，不扣历史 K 线额度。
- 接受一个候选，以下条件都要满足：
  - 满足硬约束，门禁四项全过；
  - 跑赢同池随机入场中位数（安慰剂同样套硬约束和仓位档）；
  - 有公开成绩的人：两年分年收益离他的对数差都比 H0 小；没有的人：选择段收益比 H0 高，回撤不明显变差；
  - 行为门槛不比 H0 差：实际买到他的有日期多头、胜率、平均赚 / 亏、赢家持有期。持仓更集中是这次的目的，不算行为变差，但要报告前 10% 交易的利润占比。
- 按逐人接受口径：对某人合理，且让成绩更贴近他宣传的，就落到他身上，不需要多数人一起变好。
- 照常给港股、A 股结果，但只在美股上选。

**每轮规则**
- 先预登记（`studies/<id>/notes/rounds/H*.json` + `PREREG_H*.md`），每轮 ≤ 5 个候选，跑完不改，失败照记，没带入的进否定登记表。
- 参数取整数或常见值，不做网格搜索。证据不足时，回退项选更接近原话的版本。
- 报数前核对头部交易：日期、价格、当时的仓位档和总敞口。
- 预算：每人最多 10 轮。轮次没用完、差距没定位到是哪一层（仓位、形态、排序、执行、数据）之前不停。
