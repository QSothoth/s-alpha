**1. 横向诊断（不改系统）**
- 7 人统一跑漏斗和三层对照，把漏掉的交易归到同一套环节：股票池门槛、形态定义、入场与止损、市况、名额与排序、离场、仓位。
- 按“涉及人数 × 漏掉的 R（他的票 + 我们的执行）”排出共同缺口，写进 notes 再动手。线索：沿用看板的流动性门槛、收盘买时的止损宽度上限、EP 定义。

**2. 每轮验证一个共同机制**
- 预登记机制、依据、每人取值（在原话范围内）、接受规则；每轮 ≤ 3 个候选，跑完不改。
- 实现为共享开关，默认关闭，已登记系统逐位不变（compare run us,hk 前后对比）；先写执行时点单测。
- 每个候选跑全部 7 人，只用选择段 2024-01-02 → 2025-12-31、只调美股；出横向表：每人收益、回撤、安慰剂排位、行为差距、买到他的票，以及汇总（几人变好、几人变差、最大两笔的利润占比）。
- 接受规则：≥ 4 / 7 人变好，没有人回撤明显变差，行为差距最多 +0.02（从第一轮起固定），改善不能只来自单笔或单一年份。只帮一两个人的记为“个别”，不并入公共基线；失败记否定表。

**3. 落到个人，验证一次**
- 每人只按选择段结果和原话决定是否启用，形成新版本 R* / S*。
- 验证段 2026-01-01 → 2026-10-16 每人只评一次：门禁全过，收益、回撤、下跌时段不差，行为不变差，才交给我决定是否替换；没赢的照记“未提升”。
