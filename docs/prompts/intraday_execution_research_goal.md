调研：美股期权（含 0DTE）日内“自动下单 + 自动离场”的现成方案与合理目标。只做资料调研，不写代码、不跑回测、不采集数据。

## 背景（一段话）

用户自己定选股和方向，想要一个代替盯盘的工具：智能买、智能卖（时间段内必成交），可能再加一种“买入后自动挂卖”的往返单。我们在 40 天 0DTE 数据上试了两版择时剧本、约 50 种离场，全部没有稳定胜过 “−50% 止损 / +300% 止盈”，而且入场信号是占位的。需要从外部判断：这个目标和做法是否合理，业界是怎么做的。

## 要回答的问题

1. **现成产品**：IBKR（Adaptive、Arrival Price、Bracket/OCO）、富途/moomoo（条件单、跟踪止损、附加单）、Schwab/thinkorswim、tastytrade、Option Alpha（SmartPricing、0DTE bot）等，对期权提供哪些自动买入、离场、挂价方式？哪些由券商服务器执行（断线也有效）？
2. **挂价与成交**：期权从中间价逐步追到对手价，业界做法和公开数据如何？能省多少价差？0DTE 有什么不同？
3. **离场**：0DTE / 短线期权交易者实际用什么离场方式（固定百分比、时间止损、按正股价位、分批、跟踪）？有没有可信证据说明哪种更好，或者离场优劣主要取决于入场？
4. **评测方法**：入场质量未知、样本只有几十天时，离场规则能否被有效比较？业界怎么评执行质量（如 implementation shortfall、价差捕获）？
5. **富途 OpenAPI**：美股期权支持哪些订单类型（止损、跟踪、触价、附加/OCO），能否按正股价格触发？
6. **目标是否合理**：给出判断，把以下三件事分开说，各自能期望什么、该用什么尺子：
   - 执行省钱（挂价、成交）；
   - 纪律与风控（到点成交、止损必执行、上限）；
   - 靠择时或离场赚超额。

## 往返单（新单型）要调研的点

买入成交后自动挂上卖出（止损 / 止盈 / 到时平仓，任一成交即撤其余）。整理业界的同类单（bracket、OTOCO），对比它们的参数、触发依据（期权价还是正股价）、跳空和滑点处理，以及 0DTE 的特殊处理，作为我们设计时的参照。
