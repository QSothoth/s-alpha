## 验证手段

- **达标**（三条都要）：每个有成绩的年份收益与他的对数差 ≤ 0.3；公开的行为指标在他的 ±30% 内；跑赢同池随机入场中位数。
- **样本**：只在 2024-01-02 → 2025-12-31 上选。2026 已用过一次，照报但标“已用过的验证段”。Sam、Evan 的 2023 只作行为对照。
- **每轮**：比较时列出首轮版本、当前主线和他的目标；新规则先写执行时点单测，报数前核对头部交易。
- **本任务的坑**：非动量流派不用“胜率 ≤ 35%”门禁；`min_2024_2025` 在两年选择段上恒为 −9，先查选择器能不能用。
