# 统一版本、交易 mode 与组合信号的评价

2026-10-14，按用户对版本命名及强信号用途的澄清记录。本文区分已实现的版本入口、研究中的组合动作与未改变的账户执行边界。

## 策略名称、版本与 mode

对外使用「日内期权择时 / V6.6 / 自由」或「日内期权择时 / V6.6 / 兜底」。策略名称说明做什么，V6.6 是整体基线版本，mode 说明是否必须完成当日交易。后续 V6.7 等版本必须同时包含两个 mode 的冻结配置与报告，不能用两个独立递增的版本号代表两种 mode。

| 整体基线版本 | mode | 行为 | 当前底层历史配置 |
|---|---|---|---|
| V6.6 | `selective`（自由） | 无信号可不入场；入场后日内卖出 | `zero_dte_timing_v6.6` |
| V6.6 | `required`（兜底） | 有入场截止兜底、日内退出兜底 | `open_hold_v3` |

CLI 已支持 `--strategy-version V6.6 --strategy-mode selective|required`，用于 `evaluate`、`dryrun` 和 `run`；两项必须同时给出，不能与旧 `--strategy` 混用。`custody strategies` 的 `versions` 字段列出各 mode 对应 ID、SHA256 和资格；评测报告记录统一版本与 mode。旧 ID 入口仍有效，默认配置未变。`open_hold_v1/v2/v3` 是历史保证入场策略，不是三个 mode；v2 只作为分析兜底效果的历史对照。现有策略文件和 SHA256 不改名覆盖，历史评级原样保留。统一版本显示不能把某一 mode 的 accepted 状态传播给另一 mode，更不能让整个组合自动获得 live 资格。

查看与评测示例（`<新目录>` 须替换为未使用的输出目录）：

```bash
python3 -m custody strategies
python3 -m custody evaluate --strategy-version V6.6 --strategy-mode selective --dataset data/custody-0dte-v6.1 --out <新目录>
```

切换必须交易模式只把 `selective` 改成 `required`；V6.6 版本号不变。

同一版本的两个 mode 可以有不同的买卖配置，但差异必须显式记录，不能假装只加一个入场开关。改变任一 mode 的交易行为都需要形成新的整体版本并评测两个 mode。Watch 的信号研究属于另一项能力，不沿用期权交易策略的版本号。

`dryrun/paper/live` 是执行环境；`round_trip/buy_only/sell_only` 是执行权限。它们与本页的策略 mode 分开。这里讨论的是默认 `round_trip` 日内完整交易；显式单边权限仍优先，`buy_only` 不会因 required 而自动卖出，`sell_only` 不会因此买入。每个已选定交易计划最多一买一卖；账户层每天只能选一个计划的约束不能通过把多个标的 case 汇总来替代，运行时名额尚未因此变更。

## 普通信号、组合信号与持仓动作

普通 B/S 全部保留。组合达到事先固定条件时，可以产生独立的强 B/S 候选；名称或加粗不证明收益优势，仍需相应用途的验证。触发必须只用当时可见信息，不能等后来形成组合后，把之前的普通 B/S 回填成当时已经很强。

B/S 描述正股方向。B 对 CALL 有利、对 PUT 不利；S 对 PUT 有利、对 CALL 不利。它们不是无条件的“买入/卖出期权”指令，尤其强 S 不能一律理解成应当卖掉 PUT。

| 当前交易状态 | 强信号可能承担的用途 | 应比较的结果 |
|---|---|---|
| 空仓且当天未交易 | 在既定方向和合约上提供新的入场触发，或影响对普通信号的等待 | 完整交易净收益、入场延迟、错过机会、误入场损失、参与率 |
| 已持同向仓位：CALL 遇强 B / PUT 遇强 S | 提供继续持有或调整非硬性退出的证据 | 相同入场下额外拿到的净收益、额外回撤、利润回吐、持有时长 |
| 已持反向仓位：CALL 遇强 S / PUT 遇强 B | 提供提前退出的证据 | 相同入场下减少的损失、提前卖出错过的收益、净卖出价改善 |
| 当天已完成卖出 | 继续显示用于观察 | 不增加第二次交易、不在回测中虚构加仓或反手 |

这些是待检验的用途，不是已经启用的交易规则。硬性风险退出和尾盘退出不因等待组合而延期；required 的入场兜底不等待强信号。上游已指定方向，组合不能擅自改成买另一张期权。

## W28/W29 测到了什么、没有测到什么

W28 检验原标注的双 3 分钟确认子集；W29 检验五种独立组合事件。共同主指标是信号后下一根收盘进入、再过 30 根收盘退出的正股方向收益，按方向等权、交易日聚类。这是统一固定持有期限下的事件预测检验，没有模拟实际持仓状态，也没有使用真实期权买卖过程。

因此，旧结论准确范围是「这些候选没有通过预登记的事件预测/入场用途门槛」，不是「所有组合对持仓管理均无价值」。原报告及失败结论不改写，不能换一个目标后宣布原候选已通过。持有与退出用途需要新假设、新预登记及尚未用于该验证的证据。

W29 的强事件时点多数不同于原标注时点，直接均值差还混合了时段、行情阶段、信号选择的差异。它是筛查证据，不是加入组合后对同一笔交易的因果收益提升。

## 后续如何公平比较

1. **先定用途及动作，再评测组合。** 预登记是用来买入、继续持有还是提前卖出，并冻结周期、窗口、冷却、失效条件和退出处理；每轮最多五个候选，不事后从多个用途与多个期限里挑最好看的数字。
2. **完整交易作主比较。** 相同标的、方向、合约、日期和成本，两条因果回放路径：A 采用该 mode 原规则，B 保留普通规则并加入候选组合的具体动作。所有 case 纳入，没有组合、没有入场、未成交和卖出后才出现组合的情况都留下。入场或退出发生分歧时，各自按已经冻结的规则继续回放，不能事后混用两条路径的好结果。
3. **按用途做归因。** 单独研究持有/退出时，可在组合出现前采用完全相同的入场和持仓路径，到当时才分支比较“继续原规则”与“组合触发的动作”。研究新入场时，则比较从当天开始的完整策略，保留等待造成的错失和兜底入场。不能只拿后来出现强信号的成功片段给普通信号加分。
4. **评价目标随用途不同。** 入场看延迟与错误入场；持有看多拿收益与新增回撤；退出看避免损失与过早卖出。未来有利/不利波幅、命中率等仅作机制诊断，不以事后最高价当成交，也不能用更漂亮的诊断数字掩盖最终净损益变差。
5. **最终经济标准保持一致。** 都看扣费滑点后的完整期权收益、风险与完成率，并按交易日配对比较差值和不确定性。required 单列是否完成一买一卖；selective 保留未入场零贡献。CALL/PUT 分侧，两个 mode 分开与各自基线对照，不靠其中一个表现好就宣称全版本通过。
6. **时间损耗进入卖出权衡。** 继续持有强势仓位可能多拿趋势，也可能多承担时间价值流失；提前退出可能减少亏损，也可能错失后续上涨。用真实期权价格结算净效果，时间价值残余变化只作诊断，不重复扣除假定 theta。

普通信号与强信号可以承担不同任务，但不能给强信号更宽松的最终盈利要求以获得通过。具体晋级门槛、同一交易计划的选择方式、候选动作和一次性验证段必须在下一轮计算前另行冻结，不能把本页当作自动实施或统计保证。
