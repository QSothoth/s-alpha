# 日 K 技术面评估

把已知标的的最近行情变成有依据的观察结论，配合用户已有的投资逻辑；人决定是否介入。不需要为了提供描述性参考先做 alpha 研究，也不能将这些描述写成收益保证。

只考虑做多。下行 Cycle、向下 BOS/CHoCH 和负 CMF 保留为风险信息，只用于暂不买入、取消多头计划或评估已有多头退出；不生成做空入场、空头止损、融券或看跌期权方案。未提供持仓时默认评估新开多仓，不能把“不买”写成要求卖掉已有持仓。

工程为 `/opt/opend-us-options`，沿用根及 `studies/AGENTS.md`。可以独立调用，也可以承接 opportunity-research 的候选、理由、时间尺度与失效条件；没有投资逻辑也能完成技术评估，但不要自行补出基本面结论。

## 运行

核对标的名称与市场代码，每次最多五只，不扫全市场。已有明确代码即可按需取数，不另问取数许可；不启动后台或持续采集。

```bash
cd /opt/opend-us-options
/opt/futu-opend/venv/bin/python -m studies.daily_technical.assess US.AAPL HK.00700 SH.600519
```

沪深 A 股默认腾讯公开前复权日线，美港默认 OpenD 最近日 K，港股有腾讯备用；OpenD 仍需已有行情权限，但脚本不会调用消耗历史 K 线额度的接口或购买数据。默认每只 300 根，仅接纳已完成日 K。无 OpenD 时，沪深/港股可用系统 Python 加 `--source tencent`。接口错误或数据不足时报告缺口，不编造技术面，不改用付费接口。

支持单标的 `--csv PATH --csv-adjustment qfq` 离线运行。只在确认输入确为前复权时声明 qfq；默认未知。详细数据口径、公式、阈值、CLI 和局限见[运行说明](references/TECHNICAL_CN.md)，解释具体形态或异常时按需阅读。

## 怎样判断

先查看 `data` 的来源、截止日、复权和覆盖，再读 `review.warnings`。`check_data_first` 或 `error` 时不能把残留数值包装成当前可介入结论。比较多个市场时明确各自最后完成的交易日，不冒充同一时刻报价。

- **Cycle 为主**：先描述启动、回踩、整理突破、延伸或破位。名称是 Oliver Kell **Cycle of Price Action**；脚本是日 K 近似，`candidate` 不代表原版完整多周期确认。
- **SMC 补充结构和价位**：解释确认高低点、BOS/CHoCH、扫高低点及未填补 FVG。摆动点延迟两根确认；不把影线说成机构操纵、不把 FVG 说成必回补、也不把 discount 当成低估。
- **CMF/MFI 补充量价**：CMF 的方向是否支持价格，MFI 是否偏热/偏冷；它们都不是实际资金净流入。超买不等于卖、超卖不等于买。
- **回到机会**：技术形态不能代替业务逻辑、估值、催化日期和持有期限。几个指标同源，不能累计成独立证据或编造胜率。保留冲突，不为了原先看好而忽略破位，也不因一项偏弱就抹掉长期逻辑。

## 给人的结果

先下结论，再给计划，不能用“可进一步审视介入”代替答案。默认以日线波段、新开多仓评估，并明确这只是技术面建议；持有期限不同则调整解释。每只包含：

1. **现在买不买**：技术面支持现在考虑买入 / 条件成立才买、现在不买 / 暂不买、尚无合格买点 / 数据不足。列明数据日期、参考收盘价、币种，以及一条支持和一条反证。允许明确推荐买入或不买，由人最终决定，不以此为由回避判断。
2. **买入条件与价格**：说明是整理突破还是回踩再转强，列触发条件、计划入场范围与不再追价的上限。区分已经确认的信号和未来条件；日线收盘确认后的入场最早是下一交易时段，不能假设能按已过去的收盘或盘中低点成交。EMA/FVG/超卖区域本身不是买点。
3. **错了在哪退出**：列初始多头止损价、所依据的突破日低点/前一日低点/整理低点，明确触价退出还是收盘确认；两者不能混写。只凭日 K 不能断言当日入场与止损的先后顺序，跳空也可能使实际亏损超过预算。若止损依赖尚未出现的确认 K，写出计算规则并标记“尚未可执行”，不能编造该 K 的低点。
4. **空间是否值得**：先列最近有依据的上方阻力，再列后续阻力或跟踪退出方法。用计划入场、止损和阻力计算每股风险及潜在收益风险比；入场区间按最不利的上沿计算。不能跳过近处阻力只选远目标美化比例，也不能把压力位当必达盈利目标。不把任意 2R 或固定止损百分比冒充 Kell 原规则。
5. **什么情况取消**：入场前结构破坏、跳空超出追价上限、数据/事件改变时取消或重算。新日 K 完成后重新评估，旧计划不是长期挂单指令。没有合格买点就明确“不买”，给重新评估的价格和结构条件，不为凑齐表格编一个买区。

价格须来自脚本实测价位或可解释的计算；注明动态均线、缓冲、四舍五入等模型选择。区分脚本测量、原方法原则和本次模型提出的条件计划。`review.stance` 是分析起点，不是最终买卖裁决；脚本仍计算指标，以上交易计划由模型结合结构生成，没有自动下单。基本面或事件信息缺失时说明未覆盖，不自行补出结论。

## 原方法如何落到纯多头计划

Kell 原方法包含入场和风险管理，并非只有阶段名称。参考其[原始风险管理讲义](https://traderlion.com/wp-content/uploads/sites/2/2021/12/STM-Webinar4-RiskManagementSellCriteria.pdf)第 6、10–11、20 页：突破交易以突破日或前一日低点设置初始止损；上涨再次确认后，止损可抬到近期整理下方；趋势中可参考 10/20 EMA 跟踪退出。结合 [EMA Crossback 说明](https://traderlion.com/technical-analysis/trading-the-ema-crossback/)，回踩均线后要有支撑和重新转强，不能仅凭触及均线就买。

当前脚本是日线近似，不具备原版完整多周期确认；`candidate` 不是已确认买点。SMC 辅助定位结构，CMF/MFI 辅助检查量价，最终要能回答“为什么现在入场、错在哪里”，而不是把指标同向数量变成买入评分。
