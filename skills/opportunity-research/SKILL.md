# 从异常到投资假设

帮助用户发现值得进一步验证的机会。人决定研究方向、是否参与和风险额度；AI 收集证据、挑战假设并整理下一步。灵感来自 Leto Bao 的研究方法，公开案例不构成这套方法有效或可复制其收益的证明。仅在需要追溯方法来源时读 [公开资料汇总与证据笔记](references/leto-bao/REPORT_CN.md)，该归档截至 2026-10-13，不能替代当前检索。

在 `/opt/opend-us-options` 工作时沿用根和 `studies/AGENTS.md`。本 skill 是研究入口，不授权交易、后台采集或消耗新的历史 K 线额度。相对链接按 skill 的真实路径解析。

## 怎样研究

从用户给的一个异常或问题开始；没有线索时，沿用当前会话的关注范围做一次有限的近期检索，默认最多给 3 条线索，可以没有合格机会。也没有关注范围时，先与用户确定一个行业；本轮无法取得近期资料时，明确未执行检索，只给优先补证步骤。不先扫全市场，不为凑数扩张研究。

1. **异常是否真实、持续？** 核对发生与披露日期，寻找可比较的历史基准、其他渠道或同类产品。区分广泛的供需变化与促销、汇率、单店库存、一次性事件。新闻转载不算独立证据。
2. **谁能把变化变成利润？** 沿客户需求 → 瓶颈 → 供应商 → 收入、成本和利润追一条最短证据链。查收入暴露、竞争替代、产能扩张和议价能力；行业受益不等于每家公司受益。从公司披露核实具体标的，不能靠名字或主题联想补链。
3. **价格已经反映了多少？** 对照当前估值、已披露业绩与指引、可取得的市场预期和近期股价反应。说清市场可能漏掉了什么；无法证明预期差就保留为待查，不把好公司或强需求自动当成便宜机会。13F 可作滞后的辅助证据，不能冒充实时资金流或必经确认。
4. **怎样证伪，多久兑现？** 主动找最强反例，写出足以推翻假设的可观察事实、下一个验证节点及预期时间尺度。财报、价格或订单证据只支持到哪里就说到哪里；缺关键证据时给一个最便宜的下一步，停止继续堆材料。

实时事实须用当前可用的搜索、公司公告/财报或行情工具查证，优先原始来源；标明来源日期和数据截止时间。事实、推断、待查分开写，来源不可访问就说明缺口，不填造数值或概率。先取少量必要资料；需要回测才读[失败经验](../../studies/archive/us_0dte_picks/FAILED_TRIALS.md)，按项目规范预登记，避免换名字重做失败机制。

## 给人的结果

默认每个机会一张短卡，解释足以让用户判断即可：

- **想法**：异常 → 利润受益者 → 市场可能漏掉什么，一句话。
- **证据与反证**：最关键的 2–3 条带日期来源；最强反例或缺口。
- **时间与失效**：预计何时兑现、下一次核查什么、什么事实会推翻它。
- **结论**：放弃 / 待查 / 值得观察，以及唯一优先的下一步。

保留失败和不选的理由。用户要求保存或继续跟踪时，沿用原记录追加日期与变化，不事后改写旧判断；普通讨论直接在对话输出，不自动建数据库或定时任务。

形成具体观察候选后，若需要判断近期是否适合介入，调用独立的 [daily-technical-review](../daily-technical-review/SKILL.md)，传递代码、机会理由、兑现时间与失效条件。它按需读取日 K，提供 Cycle、SMC 和 Money Flow 的技术参考；不要求先证明 alpha，不替代上述机会证据，也不把技术形态当作买入许可。

## 与期权交易衔接

先判断机会成立的时间尺度，再讨论工具。数周到数月的逻辑不能直接交给当天或最近到期期权；不能因为小账户买不起合适合约就换成更虚值、更短期限。涉及实际期权时核对真实到期、买卖价、价差、乘数、IV、费用和一张合约的全额权利金风险；核对不齐只给观察结论。

只有用户决定参与，且标的、期限和权限符合现有能力时，才交给 [near-expiry-session](../near-expiry-session/SKILL.md) 建立交易计划，带上方向、理由、失效条件和时间窗口。该流程目前只支持固定候选池内的最近到期会话；不适配的中长期机会保留为研究候选，不能绕过资格检查，也不能把研究许可当作实盘许可。
