# 跨股票共性：口径与数据边界

2026-10-29 的展示功能。聚合描述各规则账户的行为，不增加交易条件，不修改策略，也不代表多人共性有更高胜率。

## 从哪些记录计算

同一市场、同一报告的当前股票持仓与已记录动作。分别保留持多、持空、开多、开空、加多、加空、减多、减空、平多、平空；卖 Put、未执行候选、涨停跳过不参加。当前持仓已经包含仍持有的新开仓，统计总人数时按交易员 ID 去重。

跨股票关系必须涉及至少两位不同交易员与两只不同股票。共同新开、共同加仓、共同退出还要求同一交易日、同方向，分开统计；减仓可以参加共同退出，重复分批只计一位交易员。某组只有一只股票时，仍可进入原有的个股共性区。

组内多空并存、新开与反向持仓、退出与持有并存均要求不同交易员、不同股票。它们表示同组股票上的行为差异，不能解释成交易员对同一股票持相反判断。新开加入老持仓要求另一人的当前持仓开仓日更早。

## 聚合维度

| 维度 | 计算依据 | 边界 |
|---|---|---|
| 行业、概念 | 日报已有行业字段及本地已有 OpenD 行业 / 概念缓存 | 不调用外部分类源，不按公司名猜标签；缓存没有标签生效日，不当作历史时点分类 |
| 入场形态 | 账本中的 `setup`，沿用看板现有名称映射 | 持仓表示其入场形态，不表示今天再次触发 |
| 成交量 | 当日成交量 / 前 20 个完整交易日平均量；≥2 倍为放量，≤0.5 倍为缩量 | 分母不含当日；缺一天有效量则缺失；盘中见下节 |
| 价格位置 | 最新价 ≥前 252 个交易日最高价的 95% | 需要完整 252 日有效最高价；不含今天的高点 |
| 相对强弱 | 最新价相对 20 个交易日前收盘价的变化 | 严格高于有效股票池 80% 分位 / 低于 20% 分位；并列边界不算，全池横盘不会全部成为强势组 |
| 波动 | 前 20 个完整交易日平均 `(high / low − 1)` ≥4% | 使用复权后价格；要求完整有效窗口 |
| 流动性 | 前 20 日平均成交额低于同市场有效股票池 20% 分位 | 只表示池内相对位置，各市场本币分别计算，不跨币种相加 |
| 仓位集中 | 单只股票占其所属模拟账户的仓位 ≥20% | 同账户同方向持仓批次合并；不同账户仓位不相加 |
| 止损距离 | 多头 `(价格−止损)/价格`、空头 `(止损−价格)/价格` 在 0～3% | 持仓用最新有效估值，新开用快照价或记录入场价；过期估值不参加；只读既有硬止损，不改跟踪线 |

这些固定门槛用于解释和展示，不是优化后获得的交易参数。当前量价特征只描述报告当日持仓与当日动作，不套用到多日报告中较早的动作。

同市场有效股票池为当日有成交、前 20 日成交额有效且为正的存量名单；美股另需最新原始股价 ≥1 美元、前 20 日均额 ≥200 万美元。每个量价标签都单列自身有效样本数，以及其中满足标签的股票数。例如“满足 / 有效池”是背景普遍程度，不是交易成功概率。行业与概念没有完整的全池覆盖分母，不据此推断相对集中程度。

## 美股开盘后 1 小时

沿用现有 `confidence.robust_board` 的筛选结果：新动作只取五种情形都成立的单子；持仓仍是中位量情形的模拟持仓。二者在展示上分开，不把未保留的动作混进新信号。

新增量价聚合在 `intraday.run` 中、情形筛选完成后计算，读取最初的真实快照面板，**不读取模型推演的全天量**。盘中量能显示“截至快照的累计量 / 前 20 日整日均量”；只有累计量已经达到 2 倍才标记。它不是同时间量比，不外推全天，也不把尚未完成的量标成缩量。

旧早盘 JSON 没有保存原始成交量时，只展示可由原记录与已有标签确定的共性。不能拿后来完整日 K 或情形预测量补缺。新结果保存实际量、历史均量、比值、快照时间及原始面板摘要。

## 怎样收拢首页

1. 先按组内方向或持有 / 退出差异、有当日动作、不同交易员数、不同股票数排序，最后按标签文字确定顺序；收益不参加排序。
2. 参与明细完全相同的组，按交易员、股票、阶段、方向、日期合并标签；各标签的数值与定义仍保留。
3. 首页按行业、概念、交易状态、风险特征的顺序各选一组，缺项由其余组补足，最多四组。每个阶段独立显示人数 / 股数与部分成员，示例优先覆盖不同交易员与股票；展开可看全部成员及实际数值。相同股票可以属于不同维度，组间不能直接相加。
4. HTML 与 Markdown 保留全部分组和判定依据；图片显示精简摘要与覆盖率。美股早盘仍是一张图，原有入场、离场信号不因加入共性而截掉。

## 工程入口与核对

- [`aggregation.py`](../../../studies/trader_screens/aggregation.py)：标准库实现的分组、去重、关系判定、排序和证据；读取已有分类缓存，不联网。
- [`context.py`](../../../studies/trader_screens/context.py)：复用已有行情面板，按最多 252 日窗口生成标量特征，不构造股票间矩阵，不重新回放策略。
- 新日报在 `scan.run` 保存 `presentation.aggregation`；盘中在 `intraday.run` 用原始快照计算后覆盖情形结果的展示特征。
- `scan board` 与本机图片 `build_post` 可补充旧日报的展示字段：只在当前本地数据摘要与原报告一致时读取本地面板，且不写面板缓存。摘要不符则保留缺失。这个步骤不刷新数据。
- 本机日报输出 `aggregation.json`，包括各市场的特征、分类缓存路径与 SHA256、覆盖率、完整分组及参与明细；原有逐股 `comparison.json` 保持独立。
- 美股开盘后 1 小时仍发布单图；本地同目录另存可展开的 `board.html` 和完整 `aggregation.json`，可核对未列在图片摘要中的组与成员。

数据边界仍为已有 OpenD、美股 / 港股存量数据，以及 A 股新浪与存量数据。新增数据源、运行时 mock 配置与后台采集需先征得用户同意；本功能没有增加这些内容。
